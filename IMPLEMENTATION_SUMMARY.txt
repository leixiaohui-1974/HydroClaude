🚀 使用方式
================================================================================

方式1: 命令行（最常用）
  python3 hydro_engine.py config.json
  python3 hydro_engine.py config.json --verbose
  python3 hydro_engine.py config.json --validate

方式2: 生成模板
  python3 hydro_engine.py --template steady_canal
  python3 hydro_engine.py --template gate

方式3: Python API
  from core import ConfigParser, SimulationEngine, OutputManager
  config = ConfigParser().parse('config.json')
  results = SimulationEngine(config).run()
  OutputManager(config, results).save_all()

💡 关键设计创新
================================================================================

1. 通用数据模型
   所有场景抽象为：时间 × 空间 × 变量
   无需为不同场景定制数据结构
   
2. 元数据驱动
   结果自带完整描述（单位、范围、统计等）
   Web展示根据元数据自动调整
   
3. 组件化展示
   Web页面由独立组件组成
   根据场景类型自动装配组件
   
4. 配置即文档
   JSON配置文件清晰记录所有参数
   可纳入Git版本控制
   易于分享和重现
