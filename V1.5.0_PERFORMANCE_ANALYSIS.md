## 2️⃣ Dependency Analysis

### Large Dependencies (>100KB uncompressed)

#### 🚨 Critical: Plotly.js (4.5MB / 73.9% of bundle)

**Package**: `plotly.js@2.27.1`
**Size**: 4,558 kB uncompressed, 1,345 kB gzipped
**Impact**: HIGH - Dominates bundle size
**Used For**: 3D visualization, time-series charts, heatmaps

**Optimization Opportunities**:
1. ⭐ **Use plotly.js-dist-min** (~50% size reduction)
2. ⭐ **Use plotly.js/lib/core + specific modules** (custom bundle, ~70% reduction)
3. Consider lazy-loading 3D visualization tab
4. Consider alternative for simple 2D charts (e.g., Chart.js, Recharts)

**Example Custom Bundle**:
```javascript
// Instead of full plotly.js:
import Plotly from 'plotly.js-dist-min';

// Or custom build with only needed modules:
import Plotly from 'plotly.js/lib/core';
import Scatter from 'plotly.js/lib/scatter';
import Surface from 'plotly.js/lib/surface';
// Add only modules you need
```

**Estimated Savings**: 2-3 MB (44-66% reduction)

## 3️⃣ Code Splitting Analysis

### ✅ Excellent Code Splitting Strategy

**Status**: ✅ **EXCELLENT**

The application uses **lazy loading** for major features:

```typescript
// App.tsx
const SimulationWorkspace = lazy(() => import('./features/simulation/SimulationWorkspace'));
const ModelingWorkspace = lazy(() => import('./features/modeling/ModelingWorkspace'));
```

**Benefits**:
- ✅ Modeling workspace (68KB) loads only when needed
- ✅ Simulation workspace (324KB) loads only when needed
- ✅ Reduces initial page load by ~392KB
- ✅ Users only download what they use

**Initial Load** (without features):
- HTML + CSS + Core JS ≈ 400-500 KB (gzipped)
- Much better than loading all 1.9 MB at once

**Lazy-Loaded Features**:
1. ModelingWorkspace: 67.97 kB → 22.44 kB (gzipped)
2. SimulationWorkspace: 323.76 kB → 107.31 kB (gzipped)

## 🔟 Optimization Recommendations

### Priority 1: Critical (High Impact, Medium Effort)

#### 1.1 Optimize Plotly.js Bundle ⭐⭐⭐

**Current**: Full plotly.js (4.5 MB)
**Target**: plotly.js-dist-min or custom build (1.5-2 MB)
**Savings**: 2-3 MB (44-66% reduction)
**Effort**: Medium (requires import changes)

**Implementation**:
```javascript
// Option A: Use minified dist
import Plotly from 'plotly.js-dist-min';

// Option B: Custom bundle (best)
import Plotly from 'plotly.js/lib/core';
import Scatter from 'plotly.js/lib/scatter';
import Surface from 'plotly.js/lib/surface';
import Heatmap from 'plotly.js/lib/heatmap';
// Only include modules you actually use
```

**Expected Improvement**:
- Bundle size: 6.2 MB → 3.5-4 MB (-45-56%)
- Load time (4G): 3.5s → 2s (-43%)
- Parse time: 1s → 0.5s (-50%)

---

#### 1.2 Lazy Load 3D Visualization Tab ⭐⭐

**Current**: Plotly loaded on SimulationWorkspace mount
**Target**: Load only when "3D View" tab is clicked
**Savings**: Defers 1.3 MB (gzipped) until needed
**Effort**: Low

**Implementation**:
```typescript
const Plot3D = lazy(() => import('./components/Plot3D'));

// In tab content:
{activeTab === '3d' && (
  <Suspense fallback={<Spin />}>
    <Plot3D data={data} />
  </Suspense>
)}
```

**Expected Improvement**:
- Initial load: 1.9 MB → 0.6 MB (-68%)
- Users who never use 3D never download Plotly
