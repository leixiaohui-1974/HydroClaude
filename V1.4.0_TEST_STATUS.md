## Known Issues

### 1. Button Accessibility (High Priority)

**Problem**: Buttons with only icons cannot be found by accessible name.

**Example**:
```typescript
// AnimationController buttons use Tooltip titles
<Tooltip title="上一帧">
  <Button icon={<StepBackwardOutlined />} />
</Tooltip>
```

**Impact**: 50+ tests fail trying to find buttons by name.

**Solution Options**:
a) ✅ **Recommended**: Add `aria-label` to icon-only buttons
```typescript
<Button
  icon={<StepBackwardOutlined />}
  aria-label="上一帧"
/>
```

b) Alternative: Use test-ids (less preferred)
```typescript
<Button data-testid="step-backward-button" />
```

c) Alternative: Query by icon type or position (brittle)

### 2. Missing matchMedia Mock (Fixed ✅)

**Status**: Resolved
**Solution**: Added `window.matchMedia` mock in `setup.ts`

### 3. Undefined Value Errors

**Problem**: Some tests encounter undefined values calling `.toFixed()`

**Example Error**:
```
TypeError: Cannot read properties of undefined (reading 'toFixed')
```

**Cause**: Mock data structure mismatch with component expectations

**Solution**: Verify mock data completeness in test files

### 4. Multiple Element Matches

**Problem**: Some queries find multiple elements with same text

**Example**:
```
Found multiple elements with the text: /动画控制/i
```

**Cause**: Text appears in multiple places (Card title + content)

**Solution**: Use more specific queries:
```typescript
// Instead of
screen.getByText(/动画控制/i)

// Use
screen.getByRole('heading', { name: /动画控制/i })
```
