🚀 快速开始

【方式1】快速测试 (1分钟)
  cd tests/e2e
  python quick_test.py

【方式2】分类测试 (按需选择)
  python test_web_e2e.py --category basic       # 基础流动
  python test_web_e2e.py --category structures  # 水工结构
  python test_web_e2e.py --category slope       # 不同坡度

【方式3】完整测试 (30分钟)
  run_full_test.bat 10         # Windows
  ./run_full_test.sh 10        # Linux/Mac

【方式4】查看结果
  # HTML报告
  reports/test_report_*.html
  
  # 分析结果
  python analyze_results.py
  
  # CSV导出
  reports/test_analysis_*.csv
