## 🔍 性能分析

### 执行时间分布

```
稳态求解:   0.025 - 0.127s  (取决于网格)
非稳态短时: ~1.5s           (60s物理时间)
非稳态中时: ~15s            (600s物理时间)
```

### 影响性能的因素

**1. 网格密度**
- 201点 → 1001点: 执行时间增加 ~5倍
- 线性关系

**2. 结构物数量**
- 0个 vs 3个结构物: 执行时间基本相同
- 结构物数量对性能影响很小

**3. 渠道长度**
- 10km vs 50km: 执行时间基本相同
- 取决于网格点数，不取决于物理长度

**4. 时间步长**
- 更小的dt → 更多时间步 → 更长执行时间
- 线性关系

编辑 `run_benchmarks.py`，添加新的基准测试函数：

```python

    """
    自定义基准测试
    """
    print("\n[X/Y] 基准测试：我的测试")

    # 设置参数
    L = 15000.0
    nx = 301
    # ...

    # 运行测试
    start = time.time()
    # ... 运行代码 ...
    elapsed = time.time() - start

    # 返回结果
    return BenchmarkResult(
        name="my_test",
        description="我的测试",
        execution_time=elapsed,
        # ...
    )
```

然后在 `run_all_benchmarks()` 中添加：

```python
benchmarks = [
    # ... 现有基准 ...
    self.benchmark_my_test,  # 添加新基准
]
```

## ❓ 常见问题

### Q1: 为什么我的性能低于基准？

**可能原因**:
1. 硬件差异（CPU、内存）
2. Python版本不同
3. NumPy版本或配置
4. 其他后台进程占用资源

**解决方案**:
- 关闭其他程序
- 使用优化的NumPy（OpenBLAS/MKL）
- 升级硬件

### Q2: 如何提高性能？

**优化策略**:
1. 减少网格点数（在精度允许的范围内）
2. 增大时间步长（在稳定性允许的范围内）
3. 使用更快的硬件
4. 考虑并行计算（未来功能）

### Q3: 基准测试失败怎么办？

**排查步骤**:
1. 检查依赖是否安装完整
2. 查看错误信息
3. 尝试单独运行某个基准
4. 报告问题（提供错误日志）
