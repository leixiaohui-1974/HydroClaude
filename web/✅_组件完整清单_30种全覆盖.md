## 🔍 详细功能清单

### 1. 闸门系统（5种）

```
✅ SluiceGate (滑动闸门)
   - 自由流/淹没流
   - 流量系数Cd=0.6
   
✅ RadialGate (径向闸门)
   - Cd自适应调整 ⭐
   - 开度优化
   
✅ VerticalLiftGate (垂直提升)
   - 智能流态识别 ⭐
   - 孔流/堰流/过渡流
   
✅ RollerGate (滚轮闸门)
   - 大跨度适用
   
✅ FlapGate (翻板闸门)
   - 自动翻转
```

### 2. 泵站系统（1种）

```
✅ PumpStation
   - 单泵/并联/串联
   - 4种控制模式：
     * Manual (手动)
     * Auto-Level (水位)
     * Auto-Flow (流量)
     * Schedule (时间表)
   - 泵特性曲线
   - 效率计算
```

### 3. 阀门系统（7种）

```
✅ ButterflyValve (蝶阀)
   - 线性特性
   
✅ BallValve (球阀)
   - 快开特性
   
✅ GateValve (闸阀)
   - 线性特性
   
✅ GlobeValve (截止阀)
   - 抛物线特性
   
✅ CheckValve (止回阀)
   - 单向流动
   
✅ NeedleValve (针阀)
   - 精细调节
   
✅ ConeValve (锥阀)
   - 快开类型
```

### 4. 水轮机系统（3类型）

```
✅ Francis (混流式)
   - 中等水头: 50-500m
   - 效率: 93-95%
   - 最常用
   
✅ Kaplan (轴流式)
   - 低水头: 5-70m
   - 效率: 91-93%
   - 可调桨叶
   
✅ Pelton (冲击式)
   - 高水头: >200m
   - 效率: 88-92%
   - 部分负荷性能好
```

### 5. 河道/渠道/管道系统（5种）⭐新增

```
✅ River (天然河道)
   - 天然断面
   - Manning计算
   
✅ Canal (人工渠道)
   - 矩形/梯形断面
   - 正常水深
   
✅ Pipe (压力管道)
   - 圆形断面
   - 满流/非满流
   
✅ Tunnel (隧洞)
   - 引水隧洞
   - 沿程损失
   
✅ Penstock (压力钢管)
   - 水电站专用
   - 水击计算
```

### 6. 水库/湖泊/池系统（3种）

```
✅ Reservoir (水库)
   - 特征水位
   - 容积曲线
   - 调度规则
   - 洪水演算
   
✅ Lake (湖泊)
   - 天然湖泊
   - 水量平衡
   
✅ Storage Basin (调蓄池)
```
