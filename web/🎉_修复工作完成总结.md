## 💡 经验教训

### 什么有效 ✅
1. **独立进程方案**: subprocess比复杂的路径设置更可靠
2. **诚实分析**: 承认问题比掩盖问题更有价值
3. **截图证据**: 直观的视觉证据比文字描述更有说服力
4. **渐进式修复**: 先修最致命的问题(P0)，再修其他问题

### 什么无效 ❌
1. **动态修改sys.path**: 在FastAPI BackgroundTasks中不起作用
2. **设置环境变量**: PYTHONPATH在worker进程中失效
3. **安装为包**: pip install -e 在某些情况下仍然失败
4. **过度优化**: 试图修复所有问题反而延误核心问题修复
