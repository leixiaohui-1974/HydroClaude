## 🧪 详细测试内容

### 测试 1: 后端服务健康检查

**目标**: 验证后端服务正常运行

**步骤**:
1. 发送 GET 请求到 `/health`
2. 检查响应状态码 (应为 200)
3. 验证返回数据格式

**预期结果**:
```json
{
  "status": "healthy",
  "service": "HydroClaude Web API",
  "version": "1.0.0",
  "timestamp": "2025-11-15T..."
}
```

### 测试 2: 中文名称仿真

**目标**: 验证系统对中文的完整支持

**测试配置**:
```python
{
  "name": "均匀流测试_中文环境",
  "description": "这是一个包含中文描述的测试用例...",
  "config": {
    "width": 10.0,
    "length": 1000.0,
    "n_cells": 100,
    "manning_n": 0.025,
    "slope": 0.001,
    ...
  }
}
```

**步骤**:
1. 提交包含中文的仿真任务
2. 轮询任务状态 (最多30秒)
3. 获取计算结果
4. 验证指标符合预期

**预期结果**:
- 任务成功提交
- 中文名称正确保存和显示
- 仿真成功完成
- 质量守恒误差 < 0.001%
- 收敛状态为 True

### 测试 3: API列表功能

**目标**: 验证任务列表查询

**步骤**:
1. 发送 GET 请求到 `/api/v1/simulations`
2. 检查返回的任务列表
3. 验证数据格式

**预期结果**:
- 返回状态码 200
- 列表包含之前提交的任务
- 中文名称正确显示

## 🐛 问题排查

### 常见问题速查表

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 乱码 | 编码设置错误 | 运行 `chcp 65001` |
| 连接失败 | 后端未启动 | 检查 http://localhost:8000/health |
| 模块未找到 | 依赖未安装 | `pip install -r requirements.txt` |
| 端口占用 | 8000端口被占用 | `netstat -ano \| findstr :8000` |
| 超时 | 防火墙拦截 | 检查防火墙设置 |

### 调试步骤

1. **检查环境**
   ```cmd
   python --version
   pip list | findstr fastapi
   ```

2. **查看日志**
   - 后端日志: 启动窗口
   - 测试日志: 测试脚本输出

3. **手动测试API**
   ```cmd
   curl http://localhost:8000/health
   ```

4. **验证编码**
   ```cmd
   chcp
   echo %PYTHONIOENCODING%
   ```
