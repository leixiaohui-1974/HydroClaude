## ❌ 严重问题清单

### 🔴 问题1: API后台仿真任务完全不能用（致命）

**问题描述**: 
- 通过API提交的仿真任务100%失败
- 错误信息: `ModuleNotFoundError: No module named 'core.hydraulic_engine'`

**测试证据**:
```
提交任务 → 状态: failed
错误: No module named 'core.hydraulic_engine'
```

**影响范围**: **极大**
- ❌ 用户无法通过Web界面提交仿真计算
- ❌ 所有需要异步计算的功能都不能用
- ❌ 仿真管理功能形同虚设

**根本原因**: 
- FastAPI BackgroundTasks在独立进程/线程运行
- 无法继承主进程的 sys.path
- 无法import core.hydraulic_engine

**尝试的修复方案（都失败了）**:
1. ❌ 在后台任务函数内设置sys.path - 失败
2. ❌ 设置PYTHONPATH环境变量 - 失败
3. ❌ 安装backend为Python包 - 失败
4. ❌ 使用绝对路径 - 失败

**当前状态**: ❌ **未解决，功能不可用**
