## ❌ 未通过的案例

### Test 2: 溃坝（干床）
**状态**: ❌ **失败**

**原因**: HydroClaude核心求解器对干床场景的数值处理问题
- 在t≈4-9s时出现NaN
- 原始validation案例也失败
- 不是Web封装的问题

### Test 3: 溃坝（有水深）
**状态**: ❌ **失败**

**原因**: 数值不稳定（t≈3s）

### Test 4: 有坡度恒定流
**状态**: ❌ **失败**

**原因**: 触发Well-Balanced警告
- 坡度导致虚假水流
- 需要启用Hydrostatic Reconstruction
- 核心求解器的已知限制
