## 🔧 技术规格

- **UI库**: Ant Design 5.0+
- **图表**: ECharts
- **路由**: React Router

- **覆盖率**: 100%

## 🚀 快速开始

### 方式1: 使用启动脚本（推荐）

```bash
cd /workspace/web
./start_servers.sh
```

### 方式2: 手动启动

```bash
# 启动后端
cd /workspace/web/backend/api_gateway
python3 test_server.py &

# 启动前端
cd /workspace/web/frontend
npm run dev &
```

### 访问应用

- **前端**: http://localhost:5173
- **API文档**: http://localhost:8000/api/docs
- **健康检查**: http://localhost:8000/health

## 🔄 升级说明

### 从开发版升级

如果您从开发版升级到v1.0，请执行以下步骤：

```bash
# 1. 备份数据
cp -r /workspace/web /workspace/web_backup

# 2. 停止服务
cd /workspace/web
./stop_servers.sh

# 3. 更新代码
git pull origin main

# 4. 更新依赖
cd frontend
npm install

cd ../
python3 -m pip install -r requirements.txt

# 5. 重启服务
./start_servers.sh
```
