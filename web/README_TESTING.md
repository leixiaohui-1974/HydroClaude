## 🎯 详细测试场景

### 场景1: 简单明渠流动 (5分钟)

**目标**: 创建一个基本的均匀流模型

**步骤**:
1. 打开建模工作台
2. 创建模型:
   - 上游边界 (流量=50 m³/s)
   - 矩形明渠 (宽10m, 长1000m, 坡度0.001)
   - 下游边界 (水深=5m)
3. 验证模型
4. 运行仿真 (时长30秒)
5. 查看结果:
   - 水深应该均匀分布，约5m
   - 流量应该恒定为50 m³/s
   - 质量守恒误差应 < 0.001%

**预期结果**: ✅ 仿真成功，水深和流量稳定

---

### 场景2: 带闸门的渠道 (10分钟)

**目标**: 测试闸门控制功能

**步骤**:
1. 创建模型:
   - 上游边界 (流量=100 m³/s)
   - 明渠1 (500m)
   - 平面闸门 (开度50%)
   - 明渠2 (500m)
   - 下游边界 (开放边界)
2. 运行仿真 (时长60秒)
3. 观察结果:
   - 闸门上游水深应高于下游
   - 闸门处流速应增大

**预期结果**: ✅ 闸门效果明显，水深和流速变化符合物理规律

## 🔧 故障排除

### 问题1: 服务无法启动

**症状**: 运行`./start_servers.sh`后显示错误

**解决方案**:
```bash
# 检查端口占用
lsof -i :8000
lsof -i :5173

# 杀死占用进程
pkill -f "main.py"
pkill -f "vite"

# 重新启动
./start_servers.sh
```

---

### 问题2: 前端显示空白页

**症状**: 浏览器打开后页面空白

**检查**:
1. 按F12打开开发者工具
2. 查看Console标签，检查错误
3. 查看Network标签，确认资源加载

**解决方案**:
```bash
# 重新安装依赖
cd /workspace/web/frontend
rm -rf node_modules
npm install

# 重启前端
pkill -f vite
npm run dev
```

---

### 问题3: API请求失败

**症状**: 创建仿真时显示错误

**检查**:
```bash
# 测试后端
curl http://localhost:8000/health

# 查看后端日志
tail -50 /tmp/hydroclaude_backend.log
```

**解决方案**:
```bash
# 重启后端
pkill -f "main.py"
cd /workspace/web/backend/api_gateway
python3 main.py
```
