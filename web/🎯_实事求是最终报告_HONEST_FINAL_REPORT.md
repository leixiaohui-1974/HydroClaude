## 🔍 问题根因分析 - 技术深度

### 问题1: FastAPI BackgroundTasks的进程隔离

**技术细节**:
```python
# main.py 中
@app.post("/simulations")
async def create_simulation(
    request: SimulationRequest,
    background_tasks: BackgroundTasks
):
    # 这里的sys.path是正确的 ✅
    background_tasks.add_task(run_simulation_task, task_id, config)
    # 但这里启动的任务在独立上下文中 ❌
```

**根本原因**:
- uvicorn使用多进程或多线程处理请求
- BackgroundTasks可能在子进程中执行
- 子进程不继承父进程的sys.path修改
- 环境变量PYTHONPATH也可能未正确传递

**需要的解决方案** (未实施):
1. 使用Celery等专业任务队列
2. 将计算引擎作为独立服务
3. 使用multiprocessing.Pool手动管理进程
4. 将backend打包为wheel并安装到site-packages
