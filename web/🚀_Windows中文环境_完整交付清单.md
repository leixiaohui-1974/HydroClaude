```python
    sys.stdout = io.TextIOWrapper(
        sys.stdout.buffer,
        encoding='utf-8',
        errors='replace',
        line_buffering=True
    )

# 3. 批处理配置
chcp 65001  # UTF-8代码页
```

### 任务轮询

```python
max_wait = 30  # 最多等待30秒
for i in range(max_wait):
    time.sleep(1)
    status = get_status(task_id)
    
    # 显示进度
    progress_bar = "█" * (i % 10) + "░" * (10 - (i % 10))
    print(f"\r  进度: [{progress_bar}] 状态: {status}", end='')
    
    if status in ['completed', 'failed']:
        break
```

## 🐛 已知问题和限制

### 问题1: 后台任务模块导入

**现象**: 
```
error: "No module named 'core.hydraulic_engine'"
```

**影响范围**: 
- FastAPI BackgroundTasks中的仿真任务
- 不影响直接Python调用

**临时解决方案**:
1. 确保`PYTHONPATH`包含backend目录
2. 使用测试脚本验证API功能
3. 可直接调用引擎进行计算

**长期解决方案**:
- 使用Celery等专业任务队列
- 微服务架构改造

**当前可用性**: 
- ✅ API端点正常响应
- ✅ 引擎直接调用工作
- ✅ 测试脚本可验证功能
- ❌ 后台异步任务需修复

### 限制说明

- 仅支持Windows 10/11
- 需要Python 3.8+
- 需要管理员权限安装依赖
- 防火墙可能需要配置
