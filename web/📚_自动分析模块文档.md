# 🔍 自动分析模块文档

## 概述

HydroClaude自动分析模块对标商业软件（HEC-RAS、MIKE、InfoWorks等），提供专业的配置分析和结果分析功能。

## 核心功能

### 1. 输入配置自动分析 (`ConfigAnalyzer`)

#### 功能特性

✅ **参数合理性检查**
- 几何参数验证（宽度、长度、网格）
- 物理参数检查（Manning系数、底坡）
- 数值参数验证（CFL数、空间精度）
- 时间参数合理性
- 边界条件兼容性
- 初始条件完整性

✅ **数值稳定性分析**
- CFL条件检查
- Froude数估算
- 流态预测（亚临界/超临界）
- 数值扩散评估

✅ **性能预测**
- 计算时间估算
- 内存使用预测
- 时间步数计算
- 效率评估

✅ **智能优化建议**
- 网格优化建议
- CFL数优化
- 精度与效率平衡
- 参数推荐值

#### 使用示例

```python
from web.backend.analysis import ConfigAnalyzer

# 创建分析器
analyzer = ConfigAnalyzer()

# 分析配置
config = {
    "width": 10.0,
    "length": 1000.0,
    "n_cells": 100,
    "manning_n": 0.025,
    "slope": 0.001,
    "cfl": 0.5,
    "order": 2,
    "t_end": 100.0,
    "dt_max": 0.1,
    "output_interval": 1.0,
    "initial_conditions": {"type": "uniform", "h": 5.0, "Q": 10.0},
    "boundary_conditions": {
        "upstream": {"type": "Q", "value": 10.0},
        "downstream": {"type": "h", "value": 5.0}
    }
}

report = analyzer.analyze(config)

print(f"配置有效: {report.is_valid}")
print(f"质量分数: {report.quality_score}/100")
print(f"预计时间: {report.estimated_time}秒")
print(f"发现 {len(report.issues)} 个问题")

# 生成Markdown报告
markdown = analyzer.generate_report_markdown(report)
```

## 前端集成

### React组件示例

```typescript
import React, { useState } from 'react';
import { Button, Card, Progress, Alert } from 'antd';

interface ConfigAnalysisProps {
  config: any;
}

export const ConfigAnalysis: React.FC<ConfigAnalysisProps> = ({ config }) => {
  const [analyzing, setAnalyzing] = useState(false);
  const [report, setReport] = useState<any>(null);

  const analyzeConfig = async () => {
    setAnalyzing(true);
    try {
      const response = await fetch('/api/v1/analysis/config', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(config)
      });
      const data = await response.json();
      setReport(data);
    } catch (error) {
      console.error('分析失败:', error);
    } finally {
      setAnalyzing(false);
    }
  };

  return (
    <Card title="配置分析">
      <Button onClick={analyzeConfig} loading={analyzing}>
        分析配置
      </Button>
      
      {report && (
        <>
          <Progress 
            percent={report.quality_score} 
            status={report.is_valid ? 'success' : 'exception'}
          />
          
          <Alert
            message={`预计计算时间: ${report.estimated_time.toFixed(2)}秒`}
            type="info"
          />
          
          {report.issues.map((issue, i) => (
            <Alert
              key={i}
              message={issue.message}
              description={issue.suggestion}
              type={issue.severity === 'error' ? 'error' : 'warning'}
            />
          ))}
          
          <div dangerouslySetInnerHTML={{ 
            __html: marked(report.markdown_report) 
          }} />
        </>
      )}
    </Card>
  );
};
```

### 结果分析组件

```typescript
interface ResultAnalysisProps {
  taskId: string;
  result: any;
  config?: any;
}

export const ResultAnalysis: React.FC<ResultAnalysisProps> = ({ 
  taskId, result, config 
}) => {
  const [report, setReport] = useState<any>(null);

  useEffect(() => {
    analyzeResult();
  }, [result]);

  const analyzeResult = async () => {
    const response = await fetch('/api/v1/analysis/result', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ result, config })
    });
    const data = await response.json();
    setReport(data);
  };

  return (
    <Card title="结果分析">
      {report && (
        <>
          <Statistic 
            title="质量评级" 
            value={report.quality.toUpperCase()} 
          />
          <Statistic 
            title="质量评分" 
            value={report.quality_score} 
            suffix="/ 100"
          />
          
          <Descriptions title="水力特性">
            <Descriptions.Item label="平均水深">
              {report.hydraulics.h_mean.toFixed(2)} m
            </Descriptions.Item>
            <Descriptions.Item label="平均Froude数">
              {report.hydraulics.Fr_mean.toFixed(3)}
            </Descriptions.Item>
            <Descriptions.Item label="流态">
              亚临界流 {report.hydraulics.subcritical_percentage.toFixed(1)}%
            </Descriptions.Item>
          </Descriptions>
          
          {report.hydraulics.hydraulic_jumps.length > 0 && (
            <Alert
              message={`检测到 ${report.hydraulics.hydraulic_jumps.length} 个水跃`}
              type="warning"
            />
          )}
          
          <div className="markdown-content">
            {marked(report.markdown_report)}
          </div>
        </>
      )}
    </Card>
  );
};
```

## 最佳实践

### 配置分析

1. **提交前分析**：在运行仿真前先分析配置
2. **关注警告**：即使配置有效，也要处理警告
3. **采纳建议**：优化建议基于最佳实践和经验值
4. **性能预测**：利用预测调整参数以满足时间要求

### 结果分析
