## 🚀 使用指南

### 快速开始

#### 1. 在ModelingWorkspace中使用

```typescript
import { StructureToolbox } from './StructureToolbox';

function ModelingWorkspace() {
  const [structures, setStructures] = useState([]);
  
  return (
    <StructureToolbox
      structures={structures}
      onAddStructure={(structure) => {
        setStructures([...structures, structure]);
      }}
    />
  );
}
```

#### 2. 单独使用编辑器

```typescript
import { PumpStationEditor } from '@/features/modeling/components';

function MyComponent() {
  return (
    <PumpStationEditor
      initialConfig={{
        name: "PS-001",
        position: 500,
        numPumps: 2
      }}
      onSave={(config) => console.log(config)}
      onCancel={() => console.log('取消')}
    />
  );
}
```

#### 3. 在Modal中使用

```typescript
<Modal open={showEditor} width={1200} destroyOnClose>
  <GateEditor
    onSave={handleSave}
    onCancel={() => setShowEditor(false)}
  />
</Modal>
```
