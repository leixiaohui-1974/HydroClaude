### 详细问题列表

#### 问题1: 压力管道测试失败
**类别**: 组件功能测试  
**错误**: `'>' not supported between instances of 'NoneType' and 'int'`  
**原因**: Channel.compute_critical_depth对圆形断面可能返回None  
**影响**: 压力管道/隧洞/钢管测试失败（3项）  
**优先级**: 🔴 高  
**修复方案**:
```python
# 在channel.py的compute_critical_depth方法中
# 添加圆形断面的特殊处理
if self.shape == CrossSectionShape.CIRCULAR:
    # 使用数值方法求解临界水深
    return self._compute_critical_depth_circular(flow)
```

#### 问题2: 水轮机测试失败
**类别**: 组件功能测试  
**错误**: `float() argument must be a string or a real number, not 'tuple'`  
**原因**: `compute_optimal_flow()`可能返回tuple而不是float  
**影响**: Francis/Kaplan/Pelton测试失败（3项）  
**优先级**: 🔴 高  
**修复方案**:
```python
# 检查turbine.py的compute_optimal_flow返回值
# 如果返回tuple，解包：
Q_opt, extra_info = turbine.compute_optimal_flow(H)
# 或只返回float：
Q_opt = turbine.compute_optimal_flow(H)[0] if isinstance(result, tuple) else result
```

#### 问题3: 泵站初始化参数
**类别**: 应用场景测试  
**错误**: `PumpStation.__init__() got an unexpected keyword argument 'speed'`  
**原因**: PumpStation初始化不接受speed参数  
**影响**: 城市排水场景测试失败（1项）  
**优先级**: 🟡 中  
**修复方案**:
```python
# 方案1：不传speed参数，使用默认值
pump_station = PumpStation(
    name="Storm-Pump",
    position=500.0,
    pump_curve=pump_curve,
    pump_type=PumpType.SINGLE,
    control_mode=ControlMode.MANUAL
    # 不传speed参数
)

# 方案2：创建后设置speed属性
pump_station.speed = 1.0
```

## 🔧 已修复问题汇总

### 修复1: FlapGate初始化参数
**问题**: `FlapGate.__init__() got an unexpected keyword argument 'height'`  
**原因**: 应使用`gate_length`而不是`height`  
**修复**: ✅ 已修复  
**代码**:
```python
# 修复前
gate = FlapGate(..., height=3.0)

# 修复后
gate = FlapGate(..., gate_length=5.0)
```

### 修复2: Turbine初始化
**问题**: `Turbine.__init__() got an unexpected keyword argument 'rated_power'`  
**原因**: 需要传入`TurbineCharacteristics`对象  
**修复**: ✅ 已修复  
**代码**:
```python
# 修复前
turbine = Turbine(name="...", rated_power=50.0, rated_speed=150.0)

# 修复后
characteristics = TurbineCharacteristics(
    rated_head=100.0,
    rated_flow=50.0,
    rated_power=50.0,
    rated_efficiency=0.93,
    rated_speed=150.0
)
turbine = Turbine(name="...", characteristics=characteristics)
```

### 修复3: Valve初始化
**问题**: `Valve.__init__() missing 1 required positional argument: 'position'`  
**原因**: 漏传position参数  
**修复**: ✅ 已修复  
**代码**:
```python
# 修复前
valve = Valve(name="...", valve_type=..., diameter=...)

# 修复后
valve = Valve(name="...", position=800.0, valve_type=..., diameter=...)
```

### 修复4: OgeeWeir初始化
**问题**: `OgeeWeir.__init__() got an unexpected keyword argument 'crest_elevation'`  
**原因**: 应使用`crest_height`而不是`crest_elevation`  
**修复**: ✅ 已修复  
**代码**:
```python
# 修复前
weir = OgeeWeir(..., crest_elevation=195.0)

# 修复后
weir = OgeeWeir(..., crest_height=195.0)
```
