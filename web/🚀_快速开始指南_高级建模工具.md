## 5分钟上手

### 步骤1: 创建一个简单的泵站

```python
#!/usr/bin/env python3
"""示例: 创建泵站"""

from web.backend.core.structures.pump_station import (
    PumpStation,
    PumpType,
    ControlMode,
    PumpControlRule,
    STANDARD_PUMP_CURVES
)

# 创建泵站
pump = PumpStation(
    name="PS-001",
    position=500.0,
    pump_curve=STANDARD_PUMP_CURVES['medium'],
    pump_type=PumpType.PARALLEL,
    num_pumps=2,
    control_mode=ControlMode.AUTO_LEVEL,
    control_rule=PumpControlRule(
        start_level=5.0,  # 水位5m时启动
        stop_level=3.0,   # 水位3m时停止
        hysteresis=0.2    # 迟滞带0.2m
    )
)

# 测试泵站
print("="*60)
print("泵站测试")
print("="*60)

# 模拟水位变化
for t in [0, 50, 100, 150, 200]:
    water_level = 3.0 + 0.015 * t  # 水位缓慢上升
    
    # 更新控制
    pump.update_control(t, water_level, 2.0, 0.0)
    
    # 获取状态
    status = pump.get_status()
    print(f"时间: {t}s, 水位: {water_level:.2f}m, 运行泵数: {status['running_pumps']}")

print("\n✅ 测试完成！")
```

## 常见问题

### Q1: 后端服务无法启动

**症状**: 
```
ImportError: No module named 'fastapi'
```

**解决**:
```bash
pip install fastapi uvicorn
```

---

### Q2: 前端无法连接后端

**症状**: 
```
Network Error: Failed to fetch
```

**解决**:
1. 确认后端运行在 `http://localhost:8000`
2. 检查前端配置 `frontend/.env.local`:
   ```
   VITE_API_URL=http://localhost:8000
   ```
3. 检查CORS设置 `backend/api_gateway/main.py`:
   ```python
   app.add_middleware(
       CORSMiddleware,
       allow_origins=["http://localhost:3000"],
       allow_credentials=True,
       allow_methods=["*"],
       allow_headers=["*"],
   )
   ```

---

### Q3: Playwright测试失败

**症状**: 
```
playwright._impl._api_types.Error: Browser closed unexpectedly
```

**解决**:
```bash
# 重新安装浏览器
playwright install --with-deps chromium

# 或使用系统浏览器
playwright install chromium --force
```

---

### Q4: 泵站不自动启动

**症状**: 泵站始终不运行

**检查**:
1. 控制模式是否设置为 `AUTO_LEVEL` 或 `AUTO_FLOW`
2. 启动水位/流量条件是否合理
3. 是否调用了 `update_control()` 方法

**示例**:
```python
# ❌ 错误 - 未设置控制规则
pump = PumpStation(..., control_mode=ControlMode.AUTO_LEVEL)
# 没有control_rule，永远不会启动

# ✅ 正确
pump = PumpStation(
    ...,
    control_mode=ControlMode.AUTO_LEVEL,
    control_rule=PumpControlRule(
        start_level=5.0,
        stop_level=3.0
    )
)

# 必须调用update_control
pump.update_control(current_time, water_level, ...)
```

---

### Q5: 闸门流量计算异常

**症状**: 流量为0或异常大

**检查**:
1. 上游水深是否大于闸门开度
2. 开度是否设置正确（单位：米）
3. 流量系数是否合理（0.5-0.8）

**示例**:
```python
# ❌ 错误 - 开度过大
gate = RadialGate(..., opening=100.0)  # 100米？

# ✅ 正确
gate = RadialGate(..., opening=3.0)  # 3米

# ❌ 错误 - 水深小于开度
Q, _ = gate.compute_discharge(h_upstream=2.0, ...)  # 水深2m
# 但开度3m，无法出流

# ✅ 正确
Q, _ = gate.compute_discharge(h_upstream=8.0, ...)  # 水深8m
```

---

### Q6: V型堰流量偏小

**症状**: V型堰流量比预期小

**原因**: V型堰适用于小流量测量

**建议**: 
- 小流量 (< 50 m³/s): 使用V型堰
- 中等流量 (50-200 m³/s): 使用矩形堰或梯形堰
- 大流量 (> 200 m³/s): 使用宽顶堰或溢流堰

**对比**:
```python
# 相同条件 (h=5m, crest=2m, H=3m)
v_notch_weir:     51.56 m³/s  ← 适合小流量
rectangular_weir: 44.17 m³/s
broad_crested:   138.34 m³/s  ← 适合大流量
```
