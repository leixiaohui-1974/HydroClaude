### 4. API验证增强 🆕

实现了三层验证架构：

```python
Layer 1: Field Validation (Pydantic Field)
  ├─ 类型检查
  ├─ 范围验证 (gt, ge, le)
  ├─ 枚举验证 (Literal)
  └─ 必填字段强制

Layer 2: Model Validation (@model_validator)
  ├─ 空间分辨率检查 (dx范围)
  ├─ CFL与精度匹配性
  ├─ 边界条件完整性
  └─ 初始条件验证

Layer 3: Business Logic
  ├─ 物理合理性
  ├─ 数值稳定性
  └─ 资源限制
```

**关键改进**:
- 必填字段（width, length, n_cells, initial_conditions, boundary_conditions）
- 更严格的参数范围（manning_n: 0.001-0.1）
- 交叉字段依赖检查
- 清晰的错误消息

### 限制1: 大流量数值不稳定

**描述**: 流量 > 100 m³/s 时可能出现数值不稳定

**影响**: 中等

**缓解方案**:
- 使用保守配置 (CFL=0.3, order=1)
- 参考 dam_break_stable.json 模板
- 遵循参数选择指南

**长期解决**:
- Phase 10: 自适应CFL
- 更高级的时间积分方案
