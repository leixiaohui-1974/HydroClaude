## 📖 代码示例

### 创建泵站（30秒）

```python
from web.backend.core.structures.pump_station import (
    PumpStation, PumpType, ControlMode, STANDARD_PUMP_CURVES
)

pump = PumpStation(
    name="主泵站",
    position=500.0,
    pump_curve=STANDARD_PUMP_CURVES['large'],
    pump_type=PumpType.PARALLEL,
    num_pumps=3,
    control_mode=ControlMode.AUTO_LEVEL
)

# 自动控制
pump.update_control(t, water_level, ...)
Q = pump.get_total_flow(head_diff)
print(f"流量: {Q:.2f} m³/s")
```

### 创建径向闸门（20秒）

```python
from web.backend.core.structures.advanced_gates import RadialGate

gate = RadialGate(
    name="主闸",
    position=1000.0,
    width=15.0,
    opening=3.5,
    radius=8.0
)

Q, regime = gate.compute_discharge(h_up=10.0, h_down=4.0)
print(f"流量: {Q:.2f} m³/s, 流态: {regime.value}")
```

### 创建V型堰（15秒）

```python
from web.backend.core.structures.advanced_weirs import VNotchWeir

weir = VNotchWeir(
    name="测流堰",
    position=1500.0,
    crest_height=2.0,
    notch_angle=90.0
)

Q = weir.compute_discharge(h_upstream=3.5)
print(f"流量: {Q:.3f} m³/s")
```

## 🐛 常见问题

### Q1: 后端无法启动
**解决**: `pip install fastapi uvicorn`

### Q2: 前端无法连接后端
**解决**: 检查后端是否运行在`http://localhost:8000`

### Q3: Playwright测试失败
**解决**: `playwright install chromium`

### Q4: 泵站不自动启动
**解决**: 检查控制规则和启动条件

### Q5: 闸门流量异常
**解决**: 检查开度和水深参数

**更多问题**: 查看[快速开始指南](🚀_快速开始指南_高级建模工具.md)的常见问题章节
