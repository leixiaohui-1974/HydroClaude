### 1. 泵站模块（Pump Station）

#### 功能特性

✅ **泵站类型**:
- 单泵（Single Pump）
- 并联泵组（Parallel Pumps）
- 串联泵组（Series Pumps）

✅ **泵特性曲线**:
- 多项式表示：Q = a + b*H + c*H²
- 数据点插值（CSV/表格导入）
- 效率曲线定义
- 预定义标准曲线（小型/中型/大型）

✅ **控制模式**:
- 手动控制（Manual）
- 自动水位控制（Auto Level Control）
- 自动流量控制（Auto Flow Control）
- 时间表控制（Schedule Control）

✅ **控制规则**:
- 启动/停止条件
- 迟滞带（Hysteresis）
- 最小运行/停机时间
- 频繁启停保护

### 2. 高级闸门模块（Advanced Gates）

#### 5种闸门类型

| 类型 | 英文名 | 特点 | 应用场景 |
|------|--------|------|----------|
| 🚪 滑动闸门 | Sluice Gate | 最常见，底部出流 | 一般水闸 |
| 🌉 径向闸门 | Radial Gate | 弧形，启闭力小 | 大型水工建筑 |
| ⬆️ 垂直提升闸门 | Vertical Lift Gate | 整体提升，可堰流/孔流 | 船闸、大型水闸 |
| 🎢 滚轮闸门 | Roller Gate | 沿轨道运行，摩擦小 | 大跨度闸门 |
| 🔄 翻板闸门 | Flap Gate | 底部铰链旋转 | 防洪、自动调节 |

#### 技术实现

**1. 径向闸门（Radial Gate）**

```python
from web.backend.core.structures.advanced_gates import RadialGate

radial = RadialGate(
    name="RG-001",
    position=600,
    width=10.0,
    opening=2.5,
    radius=6.0,
    discharge_coeff=0.7
)

Q, regime = radial.compute_discharge(h_upstream=8.0, h_downstream=3.0)
# Q = 250.31 m³/s, regime = FlowRegime.FREE_FLOW
```

**特性**:
- ✅ 流量系数随开度自动调整
- ✅ 自动判断自由流/淹没流
- ✅ 开度角度计算
- ✅ 流量历史记录

**2. 垂直提升闸门（Vertical Lift Gate）**

```python
vertical = VerticalLiftGate(
    name="VG-001",
    position=700,
    width=10.0,
    opening=3.0,
    gate_height=12.0
)

Q, regime = vertical.compute_discharge(h_upstream=8.0, h_downstream=3.0)
# 自动识别: 孔流、堰流、或过渡流
```

**智能流态识别**:
- 小开度 (< 0.5*h1): 孔流公式
- 大开度 (> 0.8*h1): 堰流公式
- 中等开度: 自动插值

### 3. 高级堰模块（Advanced Weirs）

#### 6种堰类型

| 类型 | 英文名 | 流量公式 | 特点 |
|------|--------|----------|------|
| 📐 尖顶堰 | Sharp-Crested | Q = 1.84 * b * H^1.5 | 测流精度高 |
| 📏 宽顶堰 | Broad-Crested | Q = 1.7 * b * H^1.5 | 大流量适用 |
| 🔺 V型堰 | V-Notch | Q = 1.4 * tan(θ/2) * H^2.5 | 小流量测量 |
| ▭ 矩形堰 | Rectangular | Q = 1.7 * b * H^1.5 | 最常见 |
| ⏢ 梯形堰 | Trapezoidal | Q = 1.86 * b_eff * H^1.5 | 补偿端部收缩 |
| 🌊 溢流堰 | Ogee | Q = 2.1 * L * H^1.5 | 大坝溢洪道 |

**1. V型堰（V-Notch Weir）**

```python
from web.backend.core.structures.advanced_weirs import VNotchWeir

    crest_height=2.0,
    notch_angle=90.0  # 90° V型堰
)

Q = v_notch.compute_discharge(h_upstream=5.0)
# Q = 51.56 m³/s
```

**特性**:
- ✅ 标准90° / 60° / 120° V型
- ✅ 自定义任意角度
- ✅ 高精度流量测量
- ✅ 适合小流量

```typescript
      <Button onClick={() => setShowEditor(true)}>
        添加泵站
      </Button>
      
      {showEditor && (
        <PumpStationEditor
          onSave={(config) => {
            // 保存到后端
            api.post('/structures/pump', config);
            setShowEditor(false);
          }}
          onCancel={() => setShowEditor(false)}
        />
      )}
    </>
  );
}
```
