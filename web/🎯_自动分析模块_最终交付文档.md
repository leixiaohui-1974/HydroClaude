### ModelingWorkspace.tsx集成步骤

如果想在建模工作区添加"分析配置"功能，请按以下步骤手动修改：

#### 步骤1: 添加导入

在文件顶部添加：
```typescript
import { ConfigAnalysis } from '@/features/analysis';
```

#### 步骤2: 添加状态

在组件内添加状态变量：
```typescript
const [showConfigAnalysis, setShowConfigAnalysis] = useState(false);
const [simulationConfig, setSimulationConfig] = useState<any>(null);
```

#### 步骤3: 添加分析函数

添加配置分析处理函数：
```typescript
const handleAnalyzeConfig = () => {
  // 验证模型
  const errors = validateModel(currentModel);
  if (errors.length > 0) {
    Modal.error({
      title: '模型验证失败',
      content: (
        <div>
          <p>请修正以下错误后再分析：</p>
          <ul>
            {errors.map((error, index) => (
              <li key={index}>{error}</li>
            ))}
          </ul>
        </div>
      ),
    });
    return;
  }

  // 检查模型是否可转换
  if (!canConvertToSimulation(currentModel)) {
    message.error('当前模型无法转换为仿真配置');
    return;
  }

  // 转换并显示分析
  const config = convertModelToSimulationConfig(currentModel);
  setSimulationConfig(config);
  setShowConfigAnalysis(true);
};
```

#### 步骤4: 添加分析按钮

在工具栏中添加按钮（在"运行仿真"之前）：
```typescript
<Tooltip title="分析配置（推荐）">
  <Button
    icon={<CheckCircleOutlined />}
    onClick={handleAnalyzeConfig}
    disabled={isEmpty}
    style={{ borderColor: '#52c41a', color: '#52c41a' }}
  >
    分析配置
  </Button>
</Tooltip>
```

#### 步骤5: 添加分析弹窗

在组件返回的JSX末尾，`</Layout>`之前添加：
```typescript
{/* Config Analysis Modal */}
<Modal
  title="🔍 配置智能分析"
  open={showConfigAnalysis}
  onCancel={() => setShowConfigAnalysis(false)}
  footer={[
    <Button key="close" onClick={() => setShowConfigAnalysis(false)}>
      关闭
    </Button>,
    <Button
      key="run"
      type="primary"
      icon={<PlayCircleOutlined />}
      onClick={() => {
        setShowConfigAnalysis(false);
        handleRunSimulation();
      }}
    >
      继续运行仿真
    </Button>
  ]}
  width={1000}
  style={{ top: 20 }}
>
  {simulationConfig && (
    <ConfigAnalysis
      config={simulationConfig}
      autoAnalyze={true}
      onAnalysisComplete={(report) => {
        if (!report.is_valid) {
          message.warning('配置存在问题，建议修正后再运行仿真');
        } else if (report.quality_score < 70) {
          message.info('配置质量可以优化，建议参考分析建议');
        } else {
          message.success('配置质量良好，可以运行仿真');
        }
      }}
    />
  )}
</Modal>
```

### 问题1: API返回404

**症状**: 前端调用分析API返回404  
**原因**: 后端服务未启动或路由未正确加载  
**解决**:
```bash
# 1. 检查后端是否启动
curl http://localhost:8000/api/v1/analysis/health

# 2. 重启后端
cd /workspace/web/backend/api_gateway
python3 main.py

# 3. 验证路由
curl http://localhost:8000/api/docs  # 查看API文档
```

### 问题2: 前端组件不显示

**症状**: "🔍 自动分析" tab不显示  
**原因**: 导入路径错误或组件未正确导出  
**解决**:
```bash
# 1. 检查文件是否存在
ls /workspace/web/frontend/src/features/analysis/

# 2. 检查导入语句
# 应该是: import { ResultAnalysis } from '@/features/analysis';

# 3. 重启前端
cd /workspace/web/frontend

```

**症状**: 点击分析后一直显示Loading
