## 📖 5分钟教程 - 创建第一个仿真

### 步骤1: 打开建模工作台

系统默认打开**"建模工作台"**标签页。

界面说明：
- **顶部工具栏**: 文件操作、编辑、验证、运行按钮
- **左侧面板**: 组件库（可切换显示/隐藏）
- **中间画布**: 拖拽建模区域
- **右侧面板**: 属性编辑（可切换显示/隐藏）

### 步骤2: 创建简单的明渠模型

#### 2.1 添加上游边界
1. 在左侧组件面板找到**"边界条件"**分类
2. 拖拽**"流量边界"**到画布左侧
3. 在右侧属性面板设置：
   - 名称: 上游流量
   - 边界类型: flow (流量)
   - 值: 50 m³/s
   - 位置: upstream (上游)
4. 点击**"更新"**按钮

#### 2.2 添加明渠
1. 在左侧组件面板找到**"明渠"**分类
2. 拖拽**"矩形明渠"**到画布中间
3. 在右侧属性面板设置：
   - 名称: 主明渠
   - 宽度: 10 m
   - 长度: 1000 m
   - 坡度: 0.001
   - 曼宁系数: 0.025
   - 网格数: 100
4. 点击**"更新"**

#### 2.3 添加下游边界
1. 拖拽**"水深边界"**到画布右侧
2. 设置属性：
   - 名称: 下游水深
   - 边界类型: depth (水深)
   - 值: 5 m
   - 位置: downstream (下游)
3. 点击**"更新"**

#### 2.4 连接组件
1. 鼠标移动到**上游边界**节点右侧的连接点
2. 按住鼠标左键，拖拽到**明渠**节点左侧
3. 释放鼠标，创建连接
4. 同样方式连接**明渠**到**下游边界**

### 步骤3: 验证模型

1. 点击顶部工具栏的**"验证"**按钮（带勾号图标）
2. 系统执行以下验证：
   - ✅ 拓扑检查（无孤立节点、无循环）
   - ✅ 参数验证（所有值在有效范围内）
   - ✅ 边界条件完整性
   - ✅ 物理一致性
3. 如果验证通过，显示：**"模型验证通过!"**

**验证失败？**
- 查看错误提示中的详细信息
- 根据💡建议修复问题
- 重新验证

### 步骤4: 运行仿真

1. 点击顶部工具栏的**"运行仿真"**按钮（绿色播放图标）
2. 系统显示配置摘要对话框：

```
仿真名称: 未命名模型

渠道参数:
- 长度: 1000 m
- 宽度: 10 m
- 坡度: 0.001
- 曼宁系数: 0.025
- 网格数: 100

时间参数:
- 仿真时长: 100 s
- 最大时间步长: 1 s

初始条件:
- 类型: 均匀流
- 初始水深: 5 m
- 初始流量: 0 m³/s

边界条件:
- 上游: 流量 = 50 m³/s
- 下游: 水深 = 5 m
```

3. 确认配置无误，点击**"确定"**
4. 系统创建仿真任务，显示任务ID

### 步骤5: 查看仿真结果

1. 点击顶部的**"仿真管理"**标签页
2. 系统显示仿真配置表单和结果区域
3. 查看仿真结果：
   - 水深分布图
   - 流量分布图
   - 时间演化动画

## 🎓 高级功能

### 保存和加载模型

#### 导出模型
1. 点击**"导出"**按钮
2. 模型保存为JSON文件
3. 文件名: `{模型名称}.json`

#### 导入模型
1. 点击**"导入"**按钮
2. 选择之前导出的JSON文件
3. 模型自动加载到画布

### 撤销和重做

- **撤销**: Ctrl+Z 或点击撤销按钮
- **重做**: Ctrl+Y 或点击重做按钮
- 支持50步历史记录

### 调整视图

- **切换组件面板**: 点击"组件"按钮
- **切换属性面板**: 点击"属性"按钮
- **画布缩放**: 鼠标滚轮
- **画布平移**: 鼠标中键拖拽或Shift+左键拖拽

## 🔧 故障排除

### 前端无法启动

**问题**: `npm run dev` 失败
**解决**:
```bash
cd /home/user/HydroClaude/web/frontend
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### 后端API连接失败

**问题**: 前端显示API错误
**检查**:
```bash
# 确认后端运行
curl http://127.0.0.1:8000/api/v1/engine/info

# 应返回引擎信息
```

**解决**: 启动后端服务
```bash
cd /home/user/HydroClaude
python -m web.backend.main
```

### 验证失败

**常见错误**:

1. **"存在孤立节点"**
   - 确保所有节点都已连接
   - 检查连接线是否正确

2. **"明渠宽度必须大于0"**
   - 检查参数值
   - 确保在有效范围内（见下方参数范围）

3. **"缺少上游边界条件"**
   - 添加上游边界节点
   - 正确连接到明渠

### 仿真创建失败

**问题**: 点击"运行仿真"后报错
**检查清单**:
- [ ] 后端服务运行中
- [ ] 模型已通过验证
- [ ] 包含至少一个明渠节点
- [ ] 边界条件设置正确

## 📊 参数范围参考

### 明渠参数

| 参数 | 单位 | 最小值 | 最大值 | 推荐值 |
|------|------|--------|--------|--------|
| 宽度 (width) | m | 0.1 | 1000 | 10 |
| 长度 (length) | m | 1 | 100000 | 1000 |
| 坡度 (slope) | - | 0.0001 | 0.1 | 0.001 |
| 曼宁系数 (manning_n) | - | 0.01 | 0.1 | 0.025 |
| 网格数 (n_cells) | - | 10 | 10000 | 100 |
| 初始水深 | m | 0 | - | 5 |
| 初始流量 | m³/s | 0 | - | 0 |

### 闸门参数

| 参数 | 单位 | 最小值 | 最大值 | 推荐值 |
|------|------|--------|--------|--------|
| 开度 (opening) | % | 0 | 100 | 100 |
| 宽度 (width) | m | 0.1 | 100 | 5 |

### 边界条件参数

| 类型 | 说明 | 单位 | 范围 |
|------|------|------|------|
| flow (流量) | 指定流量边界 | m³/s | > 0 |
| depth (水深) | 指定水深边界 | m | > 0 |
