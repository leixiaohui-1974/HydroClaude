## 🔧 技术实现

### 管道流动核心算法

```python
# Manning公式
V = (1/n) * R^(2/3) * S^(1/2)
h_loss = S_f * L

# Darcy-Weisbach公式
h_loss = f * (L/D) * V²/(2g)

# Hazen-Williams公式
h_loss = 10.67 * Q^1.852 / (C^1.852 * D^4.87) * L
```

### 管网求解核心算法

```python
# Hardy-Cross迭代法
1. 初始化节点水头
2. 计算管段流量
3. 检查节点流量平衡
4. 修正管段流量
5. 重复直到收敛
```

### 复杂系统核心算法

```python
# 时间步进仿真
for t in time_steps:
    # 1. 更新组件状态
    for component in components:
        component.update(dt)
    
    # 2. 流量传递
    for connection in connections:
        transfer_flow(from_comp, to_comp)
    
    # 3. 记录状态
    save_state(t)
```

### 调度优化核心算法

```python
# 基于规则的启发式调度
for demand in forecast:
    # 决策泵数
    num_pumps = ceil(demand / pump_capacity)
    
    # 峰谷电价
    if peak_hours:
        electricity_price = 1.0
    else:
        electricity_price = 0.5
    
    # 成本计算
    cost = energy * electricity_price
```
