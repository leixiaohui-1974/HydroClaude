```batch
@echo off
chcp 65001 >nul                    # UTF-8代码页
set PYTHONIOENCODING=utf-8         # Python输入输出
set PYTHONUTF8=1                   # 强制UTF-8
```

**Python启动器**:
```python
# Windows流重定向
sys.stdout = io.TextIOWrapper(
```
