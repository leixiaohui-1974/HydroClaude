## 🔍 调试技巧

### 如果"运行仿真"按钮不可点击

**检查1**: 模型是否为空
- 按F12打开开发者工具
- 在Console中输入：
  ```javascript
  // 检查当前模型状态
  console.log(window.app?.modelState)
  ```

**检查2**: 按钮的disabled属性
- 在Elements标签中找到"运行仿真"按钮
- 查看是否有 `disabled="true"` 属性
- 如果有，说明前端判断模型不满足运行条件

**检查3**: 查看按钮的onClick事件
- 在Elements标签中右键点击按钮
- 选择 "Show function definition"
- 查看点击事件的代码逻辑

### 如果API调用失败

**检查Network标签**:
1. 打开F12 → Network标签
2. 点击"运行仿真"按钮
3. 查看是否有 `/api/v1/simulations` 请求
4. 检查请求状态码：
   - 201: 成功 ✅
   - 400: 请求参数错误
   - 500: 服务器错误

**查看请求详情**:
- 点击请求查看 Headers、Payload、Response
- 如果有错误，Response会包含错误信息
