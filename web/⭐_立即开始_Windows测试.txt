🚀 三步启动测试
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【步骤 1】启动后端服务器
   
   方法一（推荐）：
   1. 进入 web/backend 目录
   2. 双击运行: 启动后端_Windows.bat
   
   方法二：
   cd web/backend
   启动后端_Windows.bat

   等待看到：
   ✅ 服务器启动成功
      - API文档: http://localhost:8000/api/docs


【步骤 2】运行自动化测试

   ⚠️ 保持步骤1的窗口运行！
   
   1. 新开一个cmd或PowerShell窗口
   2. 运行：
   
   cd web
   python Windows中文环境测试脚本.py

   测试会自动：
   - 检查后端健康状态
   - 提交中文名称的仿真任务  
   - 等待计算完成
   - 验证结果
   - 显示统计报告

🐛 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题1: 中文乱码
解决: 
  chcp 65001
  或使用 启动后端_Windows.bat（已自动配置）

问题2: 模块未找到
解决:
  cd web/backend
  pip install -r requirements.txt

问题3: 端口被占用
解决:
  netstat -ano | findstr :8000
  taskkill /PID [进程ID] /F

问题4: 无法连接后端
检查:
  1. 后端是否运行
  2. 访问 http://localhost:8000/health
  3. 防火墙设置
