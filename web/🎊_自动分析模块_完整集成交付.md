## 🚀 使用指南

### 快速开始

#### 1. 启动后端服务

```bash
cd /workspace/web/backend/api_gateway
python3 main.py
```

**预期输出**:
```
INFO:     HydroClaude Web API Starting...
INFO:     Database initialized successfully
INFO:     Uvicorn running on http://0.0.0.0:8000
```

#### 2. 启动前端服务

```bash
cd /workspace/web/frontend
npm install  # 首次运行
npm run dev
```

**预期输出**:
```
VITE ready in 1234 ms
➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
```

#### 3. 访问系统

打开浏览器访问: `http://localhost:5173`

### 完整测试流程

#### 测试1: 配置分析

1. 进入"建模工作区"
2. 创建或加载一个配置
3. （未来功能）点击"分析配置"按钮
4. 查看质量评分和建议

#### 测试2: 结果分析

1. 运行一个仿真
2. 等待仿真完成
3. 进入"仿真管理"页面
4. 查看结果详情
5. **切换到"🔍 自动分析" tab**
6. 查看：
   - 质量评级
   - 水力特性统计
   - 守恒性检查
   - 可视化建议

#### 测试3: 从案例库运行

1. 进入"案例库" tab
2. 选择一个测试案例
3. 点击"Run"运行
4. 等待完成后查看分析报告
