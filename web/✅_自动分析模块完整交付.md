### Python使用示例

```python
from web.backend.analysis import ConfigAnalyzer, ProfessionalResultAnalyzer

# 配置分析
analyzer = ConfigAnalyzer()
report = analyzer.analyze(config)
print(f"质量分数: {report.quality_score}/100")

# 结果分析
result_analyzer = ProfessionalResultAnalyzer()
result_report = result_analyzer.analyze(result, config)
print(f"质量评级: {result_report.quality.value}")

# 生成报告
markdown = result_analyzer.generate_markdown_report(result_report)
result_analyzer.export_json(result_report, 'report.json')
```

### 前端API调用示例

```typescript
// 配置分析
const configResponse = await fetch('/api/v1/analysis/config', {

  body: JSON.stringify(config)
});
const configAnalysis = await configResponse.json();

// 结果分析
const resultResponse = await fetch('/api/v1/analysis/result', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ result, config })
});
const resultAnalysis = await resultResponse.json();
```
