## 🐛 已知问题和解决方案

### 问题1: 后台任务模块导入失败

**现象**: 
```
error: "No module named 'core.hydraulic_engine'"
```

**原因**: 
FastAPI BackgroundTasks在独立进程/线程中运行，无法继承主进程的`sys.path`。

**临时解决方案**:
1. 在`simulation.py`中添加路径设置
2. 使用环境变量`PYTHONPATH`
3. 将backend安装为包（`pip install -e .`）

**长期解决方案**:
- 使用Celery等专业任务队列
- 或微服务架构

**当前状态**: 
- ✅ 引擎直接调用工作正常
- ❌ 后台任务仍有导入问题
- ✅ 已提供Windows测试脚本可验证API

### 问题2: 端口占用

**解决**: 
```cmd
netstat -ano | findstr :8000
taskkill /PID [PID] /F
```
