# HydroClaude Web 示例模型

本目录包含预配置的示例模型，可以直接导入到建模工作台进行测试和学习。

---

## 📁 示例列表

### 1. 简单明渠模型 (`simple_channel.json`)

**难度**: ⭐ 入门级

**描述**: 最基础的水力学模型，包含上游流量边界、一段明渠和下游水深边界。

**组件**:
- 上游流量边界: 50 m³/s
- 矩形明渠: 10m宽 × 1000m长
- 下游水深边界: 5 m

**适用场景**:
- 学习基本建模流程
- 测试系统功能
- 理解边界条件设置

**预期结果**:
- 仿真时间: ~100s
- 水流达到稳定状态
- 水深沿程分布

---

### 2. 闸门控制模型 (`gate_control.json`)

**难度**: ⭐⭐ 中级

**描述**: 包含闸门控制的复杂模型，演示多段明渠和闸门调控。

**组件**:
- 上游流量边界: 80 m³/s
- 上游明渠段: 12m宽 × 500m长
- 控制闸门: 75%开度
- 下游明渠段: 12m宽 × 500m长
- 下游水深边界: 4.5 m

**适用场景**:
- 学习闸门控制
- 研究水位调节
- 多段明渠连接

**预期结果**:
- 闸门前后水位差
- 流速变化
- 回水曲线

## 🚀 使用方法

### 方法1: 通过UI导入

1. 打开 HydroClaude Web (http://localhost:5173/)
2. 切换到"建模工作台"标签
3. 点击顶部工具栏的**"导入"**按钮
4. 选择示例文件（如 `simple_channel.json`）
5. 模型自动加载到画布

### 方法2: 复制文件

```bash
# 将示例文件复制到工作目录
cp /home/user/HydroClaude/web/examples/simple_channel.json ~/my_model.json

# 在UI中导入
```

## 📊 预期结果参考

### simple_channel.json

**稳态结果** (t=100s):

| 位置 | 水深 (m) | 流速 (m/s) |
|------|----------|-----------|
| 上游 (x=0) | ~5.2 | ~0.96 |
| 中游 (x=500) | ~5.0 | ~1.00 |
| 下游 (x=1000) | ~5.0 | ~1.00 |

**说明**: 由于坡度较小，水流基本达到均匀流状态。

### gate_control.json

**稳态结果** (闸门开度75%):

| 位置 | 水深 (m) | 流速 (m/s) |
|------|----------|-----------|
| 闸门上游 | ~6.5 | ~1.03 |
| 闸门位置 | ~5.5 | ~1.21 |
| 闸门下游 | ~4.8 | ~1.39 |

**说明**: 闸门产生水位差，下游流速增加。

## 🔧 故障排除

### 导入失败

**错误**: "无效的模型文件格式"

**检查**:
1. 确认文件是有效的JSON
2. 包含必需字段: `id`, `name`, `nodes`, `edges`
3. 节点和边的ID匹配

### 验证失败

**错误**: "模型存在验证错误"

**解决**:
1. 检查所有参数在有效范围内
2. 确保边界条件完整
3. 验证拓扑连接正确

### 仿真失败

**错误**: "创建仿真任务失败"

**检查**:
1. 后端服务是否运行
2. 模型是否已验证
3. API连接是否正常
