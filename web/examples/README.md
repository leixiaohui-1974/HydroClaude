# HydroClaude Web - 示例模型

本目录包含用于测试和演示的示例模型。

## 📁 模型列表

### 1. simple_canal_model.json ✅
**简单明渠模型** - 用于快速测试基础功能

**组件：**
- 上游流量边界 (Q = 100 m³/s)
- 矩形明渠 (L=2000m, B=10m, S=0.001)
- 下游水深边界 (h = 5.0 m)

**用途：**
- 测试基础建模功能
- 验证导入导出
- 快速仿真测试

**预期结果：** ✅ 通过所有验证

---

### 2. invalid_model_for_testing.json ❌
**验证测试模型** - 包含多种验证错误

**预期错误：** 孤立节点、无效参数等

**用途：** 测试验证器功能

---

### 3. canal_with_gate_model.json ✅
**明渠+闸门控制模型** - 复杂系统示例

**组件：** 5个节点，4条边，包含闸门控制

**用途：** 测试复杂模型和闸门组件

---

## 🚀 使用方法

1. 打开 HydroClaude Web (http://localhost:5173)
2. 切换到"建模工作台"标签
3. 点击"导入"按钮
4. 选择示例模型文件
