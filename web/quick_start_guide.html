1 检查系统状态

首先确保后端服务正常运行：

# 检查后端服务
curl http://localhost:8000/health

# 或在浏览器中访问
http://localhost:8000/health
✅ 预期响应：
{"status": "healthy", "timestamp": "2025-11-17 13:30:00"}

如果服务未运行，使用以下命令启动：

cd /workspace/web
bash manage_servers.sh start

3 运行第一个仿真

使用完整演示应用运行您的第一个仿真：

  • 打开 完整演示应用
  • 从左侧选择一个组件（推荐：泵站）
  • 在右侧配置参数（使用默认值即可）
  • 点击"运行仿真"按钮
  • 查看结果和性能指标
💡 提示： 所有组件都预设了合理的默认参数，您可以直接运行，然后再调整参数观察变化。
4 尝试批量仿真

使用批量仿真工具进行参数扫描：

  1. 打开 批量仿真工具
  2. 选择仿真类型（如：泵站）
  3. 在批量参数框中输入： 
    流量=5,10,15,20
扬程=10,15,20
  4. 点击"生成批量任务"
  5. 点击"运行批量仿真"
  6. 等待完成后查看对比结果
  7. 导出CSV数据进行进一步分析
✅ 成功标志： 系统会自动生成 5×3=15 个任务组合，并依次执行，最终显示对比表格。
5 使用API进行集成

如需在自己的程序中调用，可使用REST API：

# Python示例
import requests

# 运行泵站仿真
response = requests.post(
    'http://localhost:8000/api/structures/pump',
    json={
        'pump': {'flow_rate': 10, 'head': 15, 'num_pumps': 2},
        'upstream': {'water_level': 5},
        'downstream': {'elevation': 20},
        'operation': {'duration': 100}
    }
)

result = response.json()
print(result)

? 常见问题

Q1: 无法连接到后端服务？

A: 请确保后端服务已启动。运行 bash manage_servers.sh status 检查状态。

Q2: 仿真结果不准确？

A: 检查输入参数是否合理。参考示例数据或查看API文档中的参数说明。

Q3: 如何查看详细日志？

A: 运行 bash manage_servers.sh logs backend 查看后端日志。

Q4: 支持哪些水工组件？

A: 系统支持23种组件，包括泵站、水轮机、闸门、堰、阀门、调压井、渠道、水库等。
