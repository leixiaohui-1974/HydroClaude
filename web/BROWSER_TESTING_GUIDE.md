## 🚀 快速启动

### 1. 启动后端服务

```bash
# 方法1: 直接启动
cd /workspace/web/backend/api_gateway
python3 main.py

# 方法2: 后台运行
cd /workspace/web/backend/api_gateway
nohup python3 main.py > backend.log 2>&1 &

# 验证后端运行
curl http://localhost:8000/health
```

**后端地址**: http://localhost:8000  
**API文档**: http://localhost:8000/api/docs

### 2. 启动前端服务

```bash
# 进入前端目录
cd /workspace/web/frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

**前端地址**: http://localhost:5173

### 3. 打开浏览器

在浏览器中访问: **http://localhost:5173**

## 🔧 故障排除

### 后端无法启动
```bash
# 检查端口占用
lsof -i :8000
# 杀死占用进程
kill -9 <PID>
```

### 前端无法启动
```bash
# 清理node_modules
rm -rf node_modules package-lock.json
# 重新安装
npm install
```

### 数据库错误
```bash
# 重置数据库
cd /workspace/web/backend
python3 manage_db.py --reset
```

### 浏览器缓存问题
- Chrome: Ctrl+Shift+Delete → 清除缓存
- Firefox: Ctrl+Shift+Delete → 清除缓存
- 或使用隐私模式/无痕模式
