  (1) 创建求解器

  (2) 初始化

      h_init = compute_steady_uniform_flow(Q_target, B, S0, n)
      solver.set_initial_depth(h_init)
      solver.set_initial_flow_rate(Q_target)

  (3) 求解
      result = solver.solve_steady_state(Q_target=10.0, convergence_tol=0.1)

  (4) 验证
      from utils.result_validator import quick_validate_steady_state
      validator = quick_validate_steady_state(solver, result, Q_target, name="场景名")

  (5) 绘图
      from utils.plot_helper import PlotHelper
      plotter = PlotHelper()
      fig = plotter.plot_profile(x, h, xlabel="距离", ylabel="水深")

【10. 常见问题】

  Q: 仿真不收敛？
  A: 1. 使用 compute_steady_uniform_flow 初始化
     2. 设置 convergence_tol=0.1
     3. 增加节点数 nx=101

  Q: 流量误差过大？
  A: 1. 检查是否使用 HydrostaticCanalSolver
     2. 确保初始化正确
     3. 增加 max_iterations

【11. 水力学公式速查】

  均匀流（Manning）:
    Q = (1/n) * A * R^(2/3) * S0^(1/2)

  Froude数:
    Fr = v / sqrt(g*h)
    Fr < 1: 缓流
    Fr = 1: 临界流
    Fr > 1: 急流

  临界水深（矩形断面）:
    h_c = (Q^2 / (g * B^2))^(1/3)

  比能:
    E = h + v^2/(2g) = h + Q^2/(2gA^2)
