## 🎯 Key Files by Functionality / 按功能分类的关键文件

**Frontend**:

- `web/frontend/src/features/control-systems/ControlSystemPanel.css`

- MPC Controller setup

**Usage**:
```tsx

<Route path="/control" element={<ControlSystemPanel />} />
```

### 2. Water Quality (水质模拟)

**Frontend**:
- `web/frontend/src/features/water-quality/WaterQualityPanel.tsx`
- `web/frontend/src/features/water-quality/WaterQualityPanel.css`

**Features**:
- DO/BOD configuration (Streeter-Phelps)
- Nutrient transport (N, P, Algae)
- Eutrophication assessment
- Water quality standards

**Usage**:
```tsx
import WaterQualityPanel from './features/water-quality/WaterQualityPanel';
<Route path="/water-quality" element={<WaterQualityPanel />} />
```

### 3. Parameter Optimization (参数优化)

**Frontend**:
- `web/frontend/src/features/optimization/ParameterOptimizationPanel.tsx`
- `web/frontend/src/features/optimization/ParameterOptimizationPanel.css`

**Features**:
- 5 optimization algorithms (GA, PSO, SCE-UA, DE, DREAM)
- 5 objective functions (NSE, RMSE, MAE, KGE, Multi)
- Parameter sensitivity analysis
- Convergence monitoring

**Usage**:
```tsx
import ParameterOptimizationPanel from './features/optimization/ParameterOptimizationPanel';
<Route path="/optimization" element={<ParameterOptimizationPanel />} />
```
