# HydroClaude 新增测试案例规划

## 1. 1D Preissmann 求解器新增测试 (`test_preissmann_advanced.py`)

目前已有测试：均匀流、基本边界条件、M1回水曲线、大CFL稳定性。
计划新增：
1. **洪水演进 (Flood Routing)**：输入一个上游流量过程线（如正弦波），验证波峰的衰减和延迟，检查质量守恒。
2. **超临界流稳定性 (Supercritical Flow)**：设置大坡度（如 S0=0.05），验证 LPI（局部偏惯性）因子是否能有效抑制数值振荡，保持稳定。
3. **水跃模拟 (Hydraulic Jump)**：上游超临界流，下游设定较高水深，验证求解器是否能捕捉到水跃位置并保持动量守恒。
4. **水位-流量关系边界 (Rating Curve Boundary)**：下游采用 $Q = a h^b$ 的边界条件，验证非线性边界的处理能力。

## 2. 2D HLLC 求解器新增测试 (`test_2d_solver_advanced.py`)

目前已有测试：1D溃坝对比、封闭域质量守恒、干湿边界推进、静水平衡。
计划新增：
1. **二维径向溃坝 (Radial Dam Break)**：中心高水位，四周低水位，验证波前的二维对称性。
2. **抛物线地形上的稳态流 (Flow over a Bump)**：验证源项（床面坡度）与通量梯度的精确平衡（C-property），特别是跨临界流（Transcritical flow）。
3. **抛物线碗中的震荡 (Thacker's Bowl)**：具有解析解的二维干湿边界震荡问题，验证干湿边界处理的绝对精度和无耗散性。
4. **复杂地形适应性**：在一个包含多个随机坑洼的地形上进行降雨产流测试，验证模型在极端复杂干湿交替地形下的鲁棒性（不出现 NaN）。
