## 🔬 验证指标体系

### 级别1: 基础验证 (自动化)

**流量守恒** (最重要)
```
误差阈值: < 1.0%
计算方法: |Q_computed - Q_target| / Q_target * 100
验证范围: 所有案例
```

**Manning方程** (理论基础)
```
误差阈值: < 5.0%
计算方法: 用计算水深反推流量，与目标对比
验证范围: 无结构案例
```

**Froude数** (流态判断)
```
计算方法: Fr = v / sqrt(g*h)
验证条件: 
  - 陡坡应 > 1.0 (超临界)
  - 缓坡应 < 1.0 (亚临界)
验证范围: 所有案例
```

---

### 级别2: 中级验证 (半自动)

**边界条件** (数值稳定性)
```
验证项:
  - 上游边界合理
  - 下游边界合理
  - 无震荡
```

**能量方程** (物理守恒)
```
验证项:
  - 无结构时能量递减
  - 结构处能量损失
  - 总能量守恒
```

**结构水力学** (专业准确性)
```
闸门: Q = Cd * B * a * sqrt(2*g*h)
堰流: Q = Cd * B * H^1.5
误差阈值: < 10%
```

---

### 级别3: 高级验证 (人工)

**物理合理性**
```
- 水面线形态
- 壅水曲线
- 临界流位置
- 水跃发生
```

**工程经验**
```
- 水深范围合理

- 边界影响范围
```
