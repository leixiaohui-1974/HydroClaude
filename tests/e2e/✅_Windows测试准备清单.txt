📋 测试前准备清单

  ☐ Windows 10/11 (64位)
  ☐ 系统语言: 简体中文
  ☐ 区域设置: 中国 (zh-CN)

  ☐ Git已安装 (可选)
     验证: git --version
  
  ☐ Chrome或Edge浏览器已安装

【Python依赖】
  ☐ 进入测试目录

     命令: cd webapp
  
  ☐ 安装依赖

  ☐ 验证安装
     命令: npm list react vite antd

【测试案例】
  ☐ 检查案例文件存在

【Web应用】

     命令: cd webapp && npm run dev
  
  ☐ 验证可访问

  ☐ 检查中文界面

🚀 快速开始

【终端1 - 启动Web应用】

  1. 打开命令提示符(CMD)或PowerShell
  
  2. 进入webapp目录
     cd <项目路径>\webapp
  
  3. 启动开发服务器
     npm run dev
  
  4. 等待提示
     ➜ Local: http://localhost:5173/
  
  5. 保持此窗口打开

【终端2 - 运行测试】

  1. 打开新的命令提示符
  
  2. 进入测试目录
     cd <项目路径>\tests\e2e
  
  3. 选择测试方式:
  
     方式A - 快速测试 (1个案例, 1分钟)
       python quick_test.py
     
     方式B - 分类测试 (20个案例, 5分钟)
       python test_web_e2e.py --max-cases 20
     
     方式C - 完整测试 (111个案例, 30分钟)
       run_full_test.bat 111
  
  4. 等待测试完成
  
  5. 查看报告
     自动打开HTML报告
     或手动打开: reports\test_report_*.html

🧪 测试选项

【选项1: 快速验证】
  目的: 验证环境和框架
  案例数: 1个
  时间: ~1分钟
  命令: python quick_test.py

【选项2: 分类测试】
  目的: 按类别测试
  案例数: 20个/类
  时间: ~5分钟/类
  
  命令示例:
    python test_web_e2e.py --category basic_flow
    python test_web_e2e.py --category structures
    python test_web_e2e.py --category network

【选项3: 批量测试】
  目的: 测试指定数量
  案例数: 自定义
  时间: ~0.5分钟/案例
  
  命令示例:
    python test_web_e2e.py --max-cases 10
    python test_web_e2e.py --max-cases 50

【选项4: 完整测试】
  目的: 全面验证
  案例数: 111个
  时间: ~30分钟
  命令: run_full_test.bat 111

🔧 常见问题速查

【问题1】Python未安装
  解决: 从 python.org 下载安装 Python 3.8+
  验证: python --version

【问题2】Playwright未安装
  解决: pip install playwright && playwright install chromium
  验证: playwright --version

【问题3】Web应用未运行
  解决: 在另一个窗口运行 cd webapp && npm run dev
  验证: 浏览器访问 http://localhost:5173

【问题4】端口被占用
  解决: 
    查看占用: netstat -ano | findstr :5173
    杀死进程: taskkill /F /PID <PID>

【问题5】中文乱码
  解决: 在脚本开头添加 chcp 65001
  验证: 查看控制台是否显示中文

【问题6】权限不足
  解决: 右键"以管理员身份运行"命令提示符

【问题7】测试案例不存在
  解决: python convert_all_test_cases.py
  验证: ls test_cases\*.json
