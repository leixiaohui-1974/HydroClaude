### 2. 增强验证器 (1个核心文件)

**文件**: `enhanced_validator.py` (~400行)

**功能**: 验证后端引擎的计算正确性

#### 验证项目 (6大类)

**1. 流量守恒** (最重要)
```python
误差阈值: < 1.0%
计算: |Q_computed - Q_target| / Q_target * 100
适用: 所有案例
```

**2. Manning方程** (理论基础)
```python
误差阈值: < 5.0%
计算: 用水深反推流量，与目标对比
适用: 无结构案例
```

**3. Froude数** (流态判断)
```python
计算: Fr = v / sqrt(g*h)
验证: 
  - 陡坡: Fr > 1.0 (超临界)
  - 缓坡: Fr < 1.0 (亚临界)
适用: 所有案例
```

**4. 能量方程** (物理守恒)
```python
验证:
  - 无结构时能量递减
  - 结构处能量损失
  - 总能量守恒
```

**5. 边界条件** (数值稳定性)
```python
验证:
  - 上游边界合理
  - 下游边界合理
  - 无震荡
```

**6. 结构水力学** (专业准确性)
```python
闸门: Q = Cd * B * a * sqrt(2*g*h)
堰流: Q = Cd * B * H^1.5
误差阈值: < 10%
```

---


### 3. 测试脚本更新

**更新**: `test_web_e2e.py`

**新增功能**:
```python
# 集成增强验证器
from enhanced_validator import HydraulicValidator

class WebE2ETester:
    def __init__(self):
        # 创建验证器
        self.validator = HydraulicValidator()
    
    def test_single_case(self, test_case):
        # 运行仿真
        ...
        
        # Web UI验证（原有）
        verification = self.verify_results()
        
        # 水力学验证（新增）
        if self.validator:
            hydraulic_validation = self.validator.validate_result(
                test_case, result_data
            )
            result["hydraulic_validation"] = hydraulic_validation
            result["score"] = hydraulic_validation["overall"]["score"]
        
        return result
```

**结果包含**:
- `verification` - Web UI验证（原有）
- `hydraulic_validation` - 水力学验证（新增）
- `score` - 综合得分 0-100（新增）
