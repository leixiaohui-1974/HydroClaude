## 理论基础

### 能量方程法（HEC-RAS风格）

```
z₁ + h₁ + α₁V₁²/2g = z₂ + h₂ + α₂V₂²/2g + hₑ
```

**优势**:
- 天然适合稳态（无时间离散误差）
- 从下游向上游求解
- 泵站处理简单：E_up = E_down + H_pump

### 静水重构法（Audusse et al. 2004）

```python
# 重构水位（守恒量）
eta_L = h_L + z_L
eta_R = h_R + z_R
z_interface = max(z_L, z_R)

# 重构水深
h_L_star = max(0, eta_L - z_interface)
h_R_star = max(0, eta_R - z_interface)
```

**特性**:
- 良平衡性质：静水平衡时误差 < 机器精度
- 干湿界面自然处理
- 适合长时间演化到稳态

1. 检查numpy/scipy版本
2. 查看详细错误信息
3. 对比预期结果
4. 检查核心修复是否正确应用

### 精度不达标

如果流量误差 > 0.5%:
1. 检查网格是否足够细
2. 验证结构物参数
3. 检查边界条件
4. 查看收敛历史
