# 示例19: 长距离调水工程优化调度

## 概述

本示例演示跨流域长距离调水工程的综合优化调度，包括源水库管理、多级泵站联合优化、输水管道模拟和峰谷电价调度。

## 系统组成

```
[源水库] → [泵站1] → [管道1] → [泵站2] → [管道2] → [泵站3] → [管道3] → [调蓄池] → [目标区域]
   ↓         ↓ 50m      180km      ↓ 60m      200km      ↓ 40m      120km
 200亿m³    200MW                 230MW                 150MW              500万m³
```

## 主要特点

### 1. 大型源水库
- 库容: 200亿m³（类似丹江口水库）
- 水位范围: 140m - 176.5m
- 集水面积: 95,000 km²
- 生态流量: 300 m³/s

### 2. 三级泵站
- **泵站1**: 提升50m, 350 m³/s, 200MW
- **泵站2**: 提升60m, 340 m³/s, 230MW
- **泵站3**: 提升40m, 330 m³/s, 150MW
- 总提升高度: 150m
- 总装机容量: 580MW

### 3. 长距离输水
- 总距离: 500 km
- 管道直径: 3.5m - 4.0m
- 输水能力: 300+ m³/s

### 4. 末端调蓄池
- 容积: 500万m³
- 调蓄能力: 20m水深

## 优化目标

1. **能耗最小化**
   - 峰谷电价错峰调度
   - 泵站联合优化
   - 单位水量能耗 < 0.5 kWh/m³

2. **供水保障**
   - 满足目标需水
   - 供水保证率 > 95%
   - 调蓄池削峰填谷

3. **成本最小化**
   - 利用低谷电价
   - 减少高峰用电
   - 节约电费 > 20%

## 技术要点

### 1. 多级泵站优化
```python
# 根据电价调整泵站流量
if electricity_price > 1.2:
    pump_flow_factor = 0.6  # 高峰减少
elif electricity_price < 0.8:
    pump_flow_factor = 1.0  # 低谷增加
```

### 2. 调蓄池削峰填谷
```python
# 入流 = 泵站出流
# 出流 = 目标需水 + 水位调节
tank_outflow = min(demand, inflow + (level - target) * area / dt)
```

### 3. 沿程损失
```python
# 考虑输水损失（摩阻、漏损）
next_flow = current_flow * 0.98  # 2%损失
```

## 参数说明

### 源水库参数
- `total_capacity`: 总库容（m³）
- `min_level`: 死水位（m）
- `normal_level`: 正常蓄水位（m）

### 泵站参数
- `rated_flow`: 额定流量（m³/s）
- `rated_head`: 额定扬程（m）
- `rated_power`: 额定功率（MW）
- `efficiency`: 效率（0-1）

### 管道参数
- `length`: 长度（m）
- `diameter`: 直径（m）
- `roughness`: 粗糙度

### 调蓄池参数
- `volume`: 容积（m³）
- `area`: 面积（m²）
- `max_level`: 最高水位（m）
