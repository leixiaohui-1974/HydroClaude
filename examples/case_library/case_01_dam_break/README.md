## 🌊 工程背景

### 问题重要性

水坝溃决是水利工程中**最严重的灾害之一**：
- **速度快**: 洪水波传播速度可达10-20 m/s
- **破坏大**: 下游村镇、农田、基础设施
- **预报难**: 需要精确的数值模拟

### 真实案例

**板桥水库溃坝**（1975年，中国河南）:
- 库容: 4.92亿m³
- 溃口宽度: 1100m
- 洪峰流量: 79000 m³/s
- 下游淹没面积: 1万余平方公里

**萨缅水坝溃决**（2022年，巴西）:
- 尾矿坝溃决
- 泥石流速度: >80 km/h
- 死亡人数: 259人

### 工程需求

1. **应急预案**: 洪水到达时间、淹没范围
2. **风险评估**: 不同溃坝情景的影响
3. **疏散决策**: 哪些区域需要立即撤离

## 🔬 物理模型

### 几何模型

```
初始状态（t=0）:
┌──────────┐
│  水库    │ h = 10m
│ ████████ │
│ ████████ │
└────┬─────┘
     │ 坝（瞬时溃决）
     ↓
    空地 h = 0m (干床)
─────────────────────────

溃坝后（t>0）:
      稀疏波
    ╱╲    激波波前
   ╱  ╲    ↓
  ╱    ╲  ▓▓
 ╱  洪水 ╲▓▓▓___________
╱        ╲_______________
          ↑
     湿干界面扩展
```

### 控制方程

**Saint-Venant方程**（一维浅水方程）:

```
∂h/∂t + ∂(hu)/∂x = 0                    (连续性)
∂(hu)/∂t + ∂(hu² + gh²/2)/∂x = ghS₀ - ghSf  (动量)
```

其中:
- `h`: 水深 (m)
- `u`: 流速 (m/s)
- `g`: 重力加速度 (9.81 m/s²)
- `S₀`: 底坡
- `Sf`: 摩阻坡度（Manning公式）

### 初始条件

```python
h(x, 0) = {
    h_upstream = 10.0 m,  x < x_dam
    h_downstream = 0.0 m,  x ≥ x_dam  (干床)
}

u(x, 0) = 0.0 m/s  (静止)
```

### 边界条件

```python
上游: 透射边界（transmissive）
下游: 透射边界（transmissive）
```

### Stoker解析解

对于无摩阻、平底、瞬时溃坝情况，Stoker (1957)给出了解析解：

**解的结构**:
1. **区域1** (`x < x_dam - c_L*t`): 静止上游水
   - `h = h_L`
   - `u = 0`

2. **区域2** (稀疏波):
   - `h = (2*c_L - 2*(x-x_dam)/t)² / (9g)`
   - `u = (2/3)(c_L + (x-x_dam)/t)`

3. **区域3** (`x_dam < x < x_dam + 2*c_L*t`): 均匀流
   - `h = (4/9)*h_L`
   - `u = (2/3)*c_L`

4. **区域4** (`x > x_dam + 2*c_L*t`): 干床
   - `h = 0`
   - `u = 0`

其中 `c_L = sqrt(g*h_L)` 是特征波速。

## 💻 数值方法

### 方法对比

本案例对比**三种数值方法**在溃坝问题上的性能：

#### 1. 原始WENO3（Baseline）

**优点**:
- 三阶精度
- 无振荡（TVD性质）

**缺点**:
- ❌ 干床处不稳定（h可能<0）
- ❌ 激波处有数值过冲
- ❌ 质量守恒较差（>1%）

#### 2. Phase 8.1: 正定性保持WENO3 (PP-WENO3)

**新特性**:
- ✅ 正定性保持: h≥0恒成立
- ✅ 激波无过冲

**方法**:
```python
# Zhang-Shu (2010) 方法
F_pp = θ * F_weno + (1-θ) * F_first_order

θ = min(1, (h - eps) / (h - h_new_weno))  # 限制系数
```

**改进**:
- 激波精度提升
- 数值稳定性增强

#### 3. Phase 8.2: 湿干界面增强WENO3 (WD-Enhanced-WENO3)

**新特性**:
- ✅ 湿干界面检测
- ✅ 界面特殊通量
- ✅ 质量守恒监控

**方法**:
```python
# 三层防护
Layer 1: 检测湿干界面（wet_to_dry, dry_to_wet）
Layer 2: 正定性保持（继承Phase 8.1）
Layer 3: 界面特殊通量（Toro 2001）
```

**改进**:
- 干床处理最优
- 质量守恒最佳（<0.1%）

## 💡 常见问题

### Q1: 为什么使用无摩阻条件？

**A**: 为了与Stoker解析解对比。实际工程可设置`manning_n=0.025`。

### Q2: 如何调整网格分辨率？

**A**: 修改`n_cells`参数：
```python
config = {
    'n_cells': 1000,  # 更精细网格
    ...
}
```

### Q3: 如何模拟真实地形？

**A**: 使用`dam_break_realistic.py`（待实现），可导入DEM数据。

### Q4: 计算时间太长怎么办？

**A**:
1. 减少`n_cells`（如500→200）
2. 缩短`t_end`（如30s→10s）
3. 启用Numba加速：`use_numba=True`
