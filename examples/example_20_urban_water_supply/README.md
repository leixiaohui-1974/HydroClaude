# 示例20: 城市供水管网优化调度

## 概述

本示例演示大中型城市供水系统的综合优化调度，包括多水源联合调度、水处理厂优化运行、高位水池调节和多需水点供水保障。

## 系统架构

```
水源层:
  [地表水库] ----+
  [地下水]   -----+---> [水处理厂] ---> [配水管网] ---> [高位水池] ---> [用户]
  [外调水]   ----+        (3个)                          (4个)

供水能力: 160 m³/s
服务人口: 500万
```

## 优化目标

### 1. 成本最小化
```
min: 取水成本 + 处理成本 + 输配成本
```

优先策略:
- 优先使用低成本水源（地表水）
- 峰谷时段调整（利用水池调蓄）
- 水厂负荷均衡

### 2. 供水保障
- 居民用水优先级最高
- 工业用水可削减
- 商业用水次优先
- 供水保证率 > 98%

### 3. 水质保障
- 不同水源水质加权混合
- 处理厂效率考虑
- 管网水质维护

## 技术要点

### 1. 多水源优化调度
```python
# 按成本排序
sorted_sources = sorted(water_sources, key=lambda s: s.cost)

# 优先使用低成本水源
for source in sorted_sources:
    supply = min(source.capacity, remaining_demand)
    source_supplies[source.id] = supply
    remaining_demand -= supply
```

### 2. 需水模式识别
```python
# 典型日需水变化
pattern = {
    '0-6时': 0.4,    # 凌晨低谷
    '6-9时': 1.3,    # 早高峰
    '9-12时': 1.0,   # 上午
    '12-14时': 1.1,  # 午间
    '14-18时': 0.9,  # 下午
    '18-22时': 1.4,  # 晚高峰
    '22-24时': 0.7   # 夜间
}
```

### 3. 高位水池调节
```python
# 削峰填谷
if demand_peak:
    tank_outflow > tank_inflow  # 补充供水
else:
    tank_outflow < tank_inflow  # 蓄水
```

### 4. 成本计算
```python
# 取水成本
water_cost = sum(supply_i * cost_i * time_factor)

# 处理成本
treatment_cost = sum(flow_j * plant_cost_j)

# 总成本
total_cost = water_cost + treatment_cost + distribution_cost
```
