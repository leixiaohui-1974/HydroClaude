# 示例13：时间尺度自适应仿真报告

## 1. 问题背景

### 1.1 工程背景
水网系统的仿真需求跨越多个时间尺度：
- **秒级**: 水击分析、阀门快关、应急响应
- **分钟级**: 实时调度、MPC控制、SCADA监控
- **小时级**: 运行优化、预测调度、经济分析
- **日级**: 长期规划、水资源管理、季节调度

不同时间尺度需要不同精度的模型，在保证精度的前提下最大化计算效率。

### 1.2 技术挑战
- 高保真模型计算量大，不适合长时间仿真
- 降阶模型精度降低，不适合瞬态分析
- 需要在精度和效率之间找到最优平衡
- 不同模型之间的切换需要保证平滑性

### 1.3 研究目标
展示HydroClaude的多时间尺度建模能力，验证自动模型选择机制的有效性。

## 2. 理论基础

### 2.1 时间尺度分类

| 时间尺度 | Δt范围 | 物理过程 | 模型选择 |
|----------|--------|----------|----------|
| SECOND | 1-60s | 压力波传播、水击 | 高保真FVM/MOC |
| MINUTE | 60-600s | 动态响应、控制 | 传递函数模型 |
| HOUR | 600-3600s | 准稳态过程 | IDZ模型 |
| DAY | >3600s | 长期趋势 | 水量平衡 |

### 2.2 模型选择准则

**准确性准则**:
```
ε_model(Δt) < ε_threshold

其中:
ε_model: 模型误差
ε_threshold: 允许误差阈值
```

**效率准则**:
```
T_computation(Δt) < T_realtime / γ

其中:
γ: 实时因子 (通常 > 10)
```

**自动选择算法**:
```python
def select_model(dt):
    if dt < 60:
        return ModelType.HIGH_FIDELITY  # FVM/Preissmann
    elif dt < 600:
        return ModelType.TRANSFER_FUNCTION
    elif dt < 3600:
        return ModelType.IDZ
    else:
        return ModelType.WATER_BALANCE
```

## 3. 四种模型详解

### 3.1 高保真模型 (dt = 10s)

**控制方程**: Saint-Venant方程
```
∂A/∂t + ∂Q/∂x = 0
∂Q/∂t + ∂(Q²/A)/∂x + gA·∂h/∂x = gA(S₀ - Sf)
```

**数值方法**: 有限体积法 (FVM)
- 空间离散: 50单元
- CFL限制: Δt < Δx/(|v|+c)
- 计算复杂度: O(N·M) (N空间, M时间)

**适用场景**:
- 水击分析
- 阀门快关
- 溃坝模拟

### 3.2 传递函数模型 (dt = 120s)

**数学模型**: 一阶传递函数
```
G(s) = K / (τs + 1)

参数计算:
τ = L/v (时间常数)
K = L/B (增益)
```

**离散化**: 零阶保持器 (ZOH)
```
状态空间:
x[k+1] = A_d·x[k] + B_d·u[k]
y[k] = C_d·x[k] + D_d·u[k]
```

**计算复杂度**: O(M) (仅时间步)

**适用场景**:
- MPC控制设计
- 频率响应分析
- 实时调度

### 3.3 IDZ模型 (dt = 900s)

**数学模型**: 积分-延迟-零模型
```
G(s) = K·exp(-τd·s) / (τ·s)

参数:
τd = L/(v+c) (延迟时间)
τ = L/v (时间常数)
K = L/B (增益)
```

**离散实现**:
```python
# 延迟缓冲区
buffer[k] = input[k]
delayed_input = buffer[k - delay_steps]

# 积分器
integrator += (delayed_input * K / tau) * dt
output = integrator
```

**计算复杂度**: O(1) (常数时间)

**适用场景**:
- 预测控制
- 运行优化
- 经济调度

### 3.4 水量平衡模型 (dt = 3600s)

**数学模型**: 质量守恒
```
dV/dt = Q_in - Q_out + P - E

其中:
V = B·L·h (体积)
P = p·A·dt/3600 (降雨, mm/h → m³)
E = e·A·dt/3600 (蒸发, mm/h → m³)
```

**求解**:
```
V[k+1] = V[k] + (Q_in - Q_out)·Δt + P - E
h[k+1] = V[k+1] / (B·L)
```

**计算复杂度**: O(1)

**适用场景**:
- 长期规划
- 水资源管理
- 径流模拟

## 8. 讨论

### 8.1 模型选择策略

**当前策略** (基于时间步长):
```
优点:
- 简单明确
- 易于实现
- 计算开销低

局限:
- 未考虑物理过程
- 未考虑精度需求
- 固定阈值缺乏灵活性
```

**改进方向**:
1. **动态阈值**: 根据系统状态调整
2. **误差预估**: 估计降阶误差
3. **混合模型**: 空间分区使用不同模型
4. **自适应切换**: 根据梯度自动切换

### 8.2 精度-效率权衡

**Pareto前沿**:
```
           精度
            ↑
高保真 ●    |
传递函数  ● |
IDZ        ●|
水量平衡    ●________________→ 效率
```

**最优选择取决于**:
- 应用场景(控制 vs 规划)
- 精度要求(关键系统 vs 初步分析)
- 计算资源(嵌入式 vs 云平台)
- 实时性要求(在线 vs 离线)

### 8.3 工程应用指南

**推荐原则**:

1. **瞬态分析 (秒-分钟)**:
   - 使用高保真模型
   - 关注峰值、超调、振荡
   - 验证安全性

2. **控制设计 (分钟-小时)**:
   - 使用传递函数或IDZ
   - 关注频率响应、稳定性
   - 快速迭代设计

3. **运行优化 (小时-天)**:
   - 使用IDZ或水量平衡
   - 关注能耗、成本、约束
   - 处理大规模网络

4. **长期规划 (天-月)**:
   - 使用水量平衡
   - 关注趋势、季节性
   - 考虑不确定性
