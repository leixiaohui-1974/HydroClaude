## 技术说明

### 为什么需要加上渠底高程？

在明渠水力学中：
- **水深 (h)**: 从渠底到水面的垂直距离
- **渠底高程 (z)**: 渠底相对于某一基准面的高度
- **水位 (η)**: 水面相对于基准面的高度

**关系式：**
```
η = z + h
```

在有底坡的渠道中，渠底高程 z 沿程变化：
```
z(x) = z₀ - S₀·x
```
其中 S₀ 是底坡，x 是沿程距离。

在有泵站的系统中，泵站处可能有底床高程跳跃（抬高），这在 `solver.z` 中已经包含。

### NumPy 广播技术

使用 NumPy 的广播功能高效计算水位历史：
```python
z_bed = solver.z  # 形状: (nx,)
h_history = ...    # 形状: (nt, nx)
eta_history = z_bed[None, :] + h_history  # 广播: (1, nx) + (nt, nx) = (nt, nx)
```

`z_bed[None, :]` 将一维数组 `(nx,)` 变为二维数组 `(1, nx)`，使其能与 `(nt, nx)` 形状的 `h_history` 进行广播相加。
