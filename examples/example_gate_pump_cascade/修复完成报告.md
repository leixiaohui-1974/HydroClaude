## 三、技术细节

### 3.1 为什么需要加渠底高程？

在明渠水力学中：
- **水深 h**：从渠底到水面的垂直距离
- **渠底高程 z**：渠底相对于基准面的高度  
- **水位 η**：水面相对于基准面的高度

**关系式：** η = z + h

对于有底坡的渠道：
```
z(x) = z₀ - S₀·x
```

对于有泵站的系统，泵站处可能有底床高程跳跃（例如山区调水泵站），这在 `solver.z` 中已经包含。

### 3.2 NumPy 广播技术

使用高效的 NumPy 广播计算水位历史：

```python
z_bed = solver.z           # 形状: (nx,)
h_history = ...            # 形状: (nt, nx)
eta_history = z_bed[None, :] + h_history  # (1, nx) + (nt, nx) = (nt, nx)
```

`z_bed[None, :]` 将一维数组扩展为二维数组 `(1, nx)`，使其能与 `(nt, nx)` 形状的 `h_history` 进行广播运算。
