## 🔧 修复内容

### 问题
用户报告"泵后渠底高程没有抬高"

### 根因
**绘图错误**（非物理模型错误）：
- 绘图时重新计算底床 `z = -S0 * x`，覆盖了泵站跳跃
- 实际数据正确，但图表显示错误

### 修复
```python
# 修复前（错误）
z_bed = -S0 * solver.x  # 重新计算，丢失跳跃

# 修复后（正确）
z_bed = solver.z  # 使用求解器实际数据
```

**影响文件**：
- `examples/example_gate_pump_cascade/gate_pump_cascade_system.py`（第401、449行）
