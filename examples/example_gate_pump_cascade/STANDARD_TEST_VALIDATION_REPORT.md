**关键理解**:

在非恒定流中，**入流≠出流** 是物理正确的！

```
连续性方程: ∂V/∂t = Q_in - Q_out
即: 蓄水速率 = 入流 - 出流
```

- 工况01: 35 - 24.3 = 10.7 m³/s ✓ 渠道蓄水
- 工况02: 55 - 24.3 = 30.7 m³/s ✓ 渠道大量蓄水  
- 工况03: 45 - 24.3 = 20.7 m³/s ✓ 渠道中等蓄水

**这不是误差，这是物理真实的行为！**
