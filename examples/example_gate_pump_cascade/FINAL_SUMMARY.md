### 🔍 质量守恒问题详细分析

#### 问题本质
当前的质量平衡计算方法**只考虑上下游边界流量**：
```
累计流入流出 = ∫(Q_上游 - Q_下游) dt
```

但由于泵站是**内部结构**，它会改变渠道内部的流量分布，导致：
- 泵站上游渠道的蓄水量
- 泵站下游渠道的蓄水量  
- 这两部分的变化不能简单地用边界流量差来计算

#### 正确的方法应该是：
```
上游段: ∫Q_上游 dt - ∫Q_泵入 dt = ΔV_上游段
下游段: ∫Q_泵出 dt - ∫Q_下游 dt = ΔV_下游段
泵站: Q_泵入 ≈ Q_泵出 (泵站本身不蓄水)
全局: ΔV_上游段 + ΔV_下游段 = ΔV_总
```

#### 证据支持
1. **稳态完美守恒**（误差<1e-6）→ 控制方程和求解器正确
2. **CFL条件满足** → 不是数值不稳定
3. **定性趋势合理** → 物理模型正确
4. **只有瞬态质量平衡计算有问题** → 问题在于后处理计算方法
