## 🔬 技术实现

### 核心方法：改进型区域法 v3.0

**关键创新**：使用远上游参考点避免累积误差

```python
# 使用远上游点（idx-15，约3km）作为参考
h_upstream = self.h[idx - 15]

# 直接使用100%额定扬程
h_downstream_target = h_upstream + structure.rated_head * 1.00
```

### 区域设计（15个网格点，约3km）

#### 1. 上游过渡段（idx-2 到 idx-1）
- **长度**：2个点（400m）
- **功能**：平滑过渡到泵站
- **梯度**：渐进到20%扬程
- **实现**：
  ```python
  h_target = h_upstream + alpha * rated_head * 0.20
  ```

#### 2. 泵站中心点（idx）
- **长度**：1个点（200m）
- **功能**：泵站核心区
- **目标**：50%扬程
- **实现**：
  ```python
  h_target = h_upstream + rated_head * 0.50
  ```

#### 3. 下游平台段（idx+1 到 idx+10）⭐ **核心**
- **长度**：10个点（2km）
- **功能**：保持100%扬程效果
- **目标**：恒定水深 = h_upstream + 5.0m
- **实现**：
  ```python
  self.h[pos] = h_downstream_target  # 100%扬程
  ```

#### 4. 下游过渡段（idx+11 到 idx+12）
- **长度**：2个点（400m）
- **功能**：逐渐释放约束
- **梯度**：从100%降至65%
- **实现**：
  ```python
  h_target = h_downstream_target - alpha * rated_head * 0.35
  self.h[pos] = (1 - 0.5) * self.h[pos] + 0.5 * h_target  # 50%约束
  ```

## 🎓 技术洞察

### 关键发现1：参考点选择的重要性

**错误做法**（v1.0）：
```python
h_upstream = self.h[idx - 5]  # 距泵站1km
```
**问题**：idx-5已经受过渡区影响，包含了部分扬程效果

**正确做法**（v3.0）：
```python
h_upstream = self.h[idx - 15]  # 距泵站3km
```
**优势**：远离过渡区，代表真实上游水深

### 关键发现2：补偿系数不是解决方案

**错误思路**：使用85%、95%等补偿系数来"校正"误差

**正确思路**：
1. 找到误差的根源（参考点选择错误）
2. 修正根源问题
3. 直接使用100%额定扬程

### 关键发现3：平台区长度的作用

**太短（<1km）**：浅水方程快速平滑，扬程消失

**合适（2km）**：足够长度保持扬程，又不过度干扰下游

**太长（>5km）**：可能影响下游边界条件

## 📝 使用建议

### 1. 泵站位置选择
确保泵站距离边界至少15个网格点（约3km）：
```python
# 检查
assert pump_position >= 15 * dx
assert pump_position <= length - 15 * dx
```

### 2. 网格分辨率
推荐网格间距：100m-300m
```python
dx = 200.0  # 推荐值
nx = int(length / dx) + 1
```

### 3. 时间步长
满足CFL条件：
```python
dt <= 0.5 * dx / max_wave_speed
# 典型值：dt = 0.5s (dx=200m, c=10m/s)
```

### 4. 参数调整
如需微调扬程（例如补偿摩擦损失）：
```python
# 可在95%-105%范围内调整

```
