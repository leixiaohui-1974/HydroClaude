# 串联闸泵群系统修复总结

## 问题识别 ❌

**原始问题**：
1. 稳态图：泵站处出现巨大水位尖峰（跳跃后立即下降）
2. 非稳态图：泵站后出现倒扣的"U"形水位下降
3. **根本原因**：错误地将泵站建模为"瞬时水位跳跃"

## 物理本质 ✓

**正确理解**：
- ❌ 泵站 ≠ 在平坦渠道上突然抬高水位
- ✅ 泵站 = 克服地形高差，将水从低处抬到高处

**关键关系**：
```
水位 η = 底床高程 z + 水深 h

泵站效果：
- 水位抬升: Δη ≈ H_pump  (扬程)
- 水深不变: Δh ≈ 0
- 底床跳跃: Δz ≈ H_pump  (关键！)
```

## 解决方案 ✅

### v6.0: 底床跳跃法

**实现**：
```python
def _apply_pump_bed_elevation_jump(self):
    """在泵站后，底床高程整体抬高扬程"""
    for idx, structure in zip(self.structure_indices, self.structure_objects):
        if isinstance(structure, PumpStation):
            self.z[idx:] += structure.rated_head
```

**优点**：
1. 物理正确：泵站 = 克服高差
2. 水深不变：符合实际
3. 水位抬升：正确反映扬程
4. 流量守恒：自然满足

## 物理意义

泵站的真实作用：
```
        上游渠道                    下游渠道
    (海拔-5m, h=3m)            (海拔0m, h=3m)
          |                          |
          |    ┌─────────┐          |
          └───→│ 泵站5m  │─────→   |
               └─────────┘          |
                 克服高差
```

**不是**：水在平渠道上突然升高
**而是**：水从低处被抬到高处
