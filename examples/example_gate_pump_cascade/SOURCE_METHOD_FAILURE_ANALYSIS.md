# 源项法失效原因分析

## 观察到的问题

### 稳态求解
- 泵站扬程效果：≈ 0 m（应该是5 m）
- 水位剖面：平滑下降，无跃变

### 非稳态求解
- 泵站扬程效果：≈ 1.5 m（应该是5 m）
- 扬程有部分作用，但强度严重不足

## 根本原因

### 原因1：稳态求解中强制流量守恒覆盖源项效果

在`solve_steady`函数中（第606行）：
```python
# 每次迭代都强制全渠道流量相同
hu_new[:] = Q_target / self.B
```

**问题**：
- 泵站源项在`compute_fluxes_and_sources`中计算后加到动量方程
- 但在`solve_steady`的每次迭代中，这个动量变化被强制覆盖为`Q_target/B`
- 导致泵站源项**完全失效**

### 原因2：源项强度相对时间尺度太弱

源项强度计算：
```python
S_pump = g * h * rated_head / (spread_points * dx)
       = 9.81 * 3.3 * 5.0 / (5 * 200)
       ≈ 0.16 m/s²
```

在一个时间步（dt=0.5s）内产生的动量变化：
```
Δ(hu) = S_pump * dt = 0.16 * 0.5 = 0.08 m²/s
```

对应的速度变化：
```
Δu = Δ(hu) / h = 0.08 / 3.3 ≈ 0.024 m/s
```

**问题**：
- 这个速度变化太小
- 在14400个时间步（7200秒）后累积效果：0.024 * 14400 = 345 m/s（显然不合理）
- 实际上每个时间步的加速度都被后续的动力学平衡掉了

### 原因3：物理建模不当

泵站扬程的物理本质：
- **不是连续加速**（像摩擦力或重力那样）
- **是瞬时能量增加**，表现为水位跃变

类比：
- 摩擦力：连续作用，适合用源项
- 泵站：瞬时抬升，**不适合用源项**

### 原因4：能量-动量转换机制缺失

泵站增加的是**势能**（gh），不是**动能**（0.5u²）：
- 源项法增加的是**动量**（hu）
- 动量增加 → 速度增加 → 水深减小（连续性方程）
- 这与泵站的物理机制相反！

正确的机制应该是：
- 泵站增加能量 → 水深增加（h↑）
- 保持流量守恒 → 速度减小（u↓）

## 正确的实现方法

### 方法：内部边界跃变法

将泵站视为内部边界，施加不连续条件：

**步骤1**：在每个时间步后（或每次迭代后）施加跃变
```python
def _apply_pump_head_jump(self):
    for idx, structure in zip(self.structure_indices, self.structure_objects):
        if isinstance(structure, PumpStation) and structure.is_running:
            # 保持上游水深不变
            h_up = self.h[idx - 1]

            # 强制下游水深 = 上游 + 扬程
            h_down = h_up + structure.rated_head
            self.h[idx + 1] = h_down

            # 保持流量守恒
            Q = self.hu[idx - 1] * self.B  # 上游流量
            self.hu[idx + 1] = Q / self.B  # 下游单宽流量
```

**步骤2**：在稳态求解中，在强制流量守恒**之后**施加
```python
# 在solve_steady的迭代循环中：
hu_new[:] = Q_target / self.B  # 强制流量守恒

# 之后立即施加泵站跃变
self._apply_pump_head_jump()
```

**步骤3**：在非稳态求解中，每个时间步后施加
```python
# 在solve_transient的时间循环中：
h_new, hu_new = self.step_preissmann(dt, ...)
self.h = h_new
self.hu = hu_new

# 施加泵站跃变
self._apply_pump_head_jump()
```

## 为什么这个方法可行

### 物理正确性
- ✅ 直接施加水深跃变（h_down = h_up + ΔH）
- ✅ 保持流量守恒（Q_up = Q_down）
- ✅ 能量守恒：E_down = E_up + g*ΔH

### 数值稳定性
- ✅ 每个时间步只施加一次，不会累加
- ✅ 与浅水方程动力学兼容
- ✅ 对稳态和非稳态都适用

### 实现简洁
- ✅ 代码简单，易于理解
- ✅ 类似闸门处理，逻辑一致
- ✅ 不需要修改通量计算

## 验证标准

修复后应满足：

**稳态**：
- ✅ 上游水深 ≈ 3.3 m
- ✅ 下游水深 ≈ 8.3 m（上游 + 5 m）
- ✅ 水位在泵站处跃变
- ✅ 跃变平滑过渡（2-3个网格内）

**非稳态**：
- ✅ 扬程效果持续为5 m
- ✅ 最终稳态与solve_steady一致
- ✅ 时间演化过程稳定

---

**结论**：源项法不适合泵站扬程建模，应改用内部边界跃变法。
