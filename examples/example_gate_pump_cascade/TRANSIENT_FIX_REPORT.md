## 🔬 技术细节

### Preissmann求解器配置

```python
# 稳态求解
result = solver.solve_steady_state(
    Q_target=Q_initial,
    h_downstream=h_downstream_boundary,
    convergence_tol=0.01,    # 宽松收敛容差
    max_iterations=500,       # 限制最大迭代
    dt=dt,
    verbose=True
)

# 非恒定流时间推进
h_new, hu_new = solver.step_preissmann(
    dt=0.5,                  # 0.5秒时间步
    max_iter=10,             # Preissmann内迭代
    enforce_bc=True,         # 强制边界条件
    Q_in=Q_upstream,         # 上游流量
    h_out=h_downstream,      # 下游水深
    use_pump_mask=False      # 非恒定流关闭泵站掩码
)
```

### 泵站内部边界条件

根据能量方程：
```
E_up + H_pump = E_down
z_up + h_up + H_pump = z_down + h_down

本案例：
  z_up = 0, z_down = 5.0 m
  h_up ≈ 3.3 m
  H_pump = 5.0 m
  
→ h_down = 3.3 + (0 - 5.0) + 5.0 = 3.3 m

结论：底床抬高与扬程相等时，水深基本不变
```

### 数值稳定性保证

1. **CFL条件**: 自动调整时间步长，确保 CFL < 1
2. **松弛因子**: ω = 0.95，增强收敛稳定性
3. **干湿判断**: eps_dry = 1e-6，避免负水深
4. **边界处理**: 每次迭代强制边界条件，避免累积误差
