## 5. 问题诊断

### 5.1 可能原因

1. **底床跳跃导致数值不稳定**
   - 底床突变可能导致静水重构失败
   - 需要在泵站附近使用更细的网格

2. **边界条件处理不当**
   - 泵站位置的内部边界条件可能与底床跳跃冲突
   - 需要特殊处理泵站处的通量计算

3. **缺少流量控制**
   - 泵站应该限制流量为额定流量
   - 当前实现可能未正确施加流量约束

### 5.2 推荐改进

#### 方案A: 平滑过渡（推荐）
```python
# 在泵站附近使用平滑的底床过渡
# 而不是突变跳跃
L_transition = 10 * dx  # 过渡区长度
for i in range(transition_points):
    ratio = i / transition_points
    z[pump_idx + i] += H_pump * smooth_function(ratio)
```

#### 方案B: 增强泵站边界条件
```python
# 在泵站处强制施加流量约束
if idx == pump_idx:
    Q[idx] = min(Q_rated, Q_upstream)
    # 确保流量不为负
    Q[idx] = max(0, Q[idx])
```

#### 方案C: 混合方法
- 稳态：使用底床跳跃
- 瞬态：使用源项方法或平滑过渡

## 8. 附录：关键代码

### 底床跳跃实现

```python
def _apply_pump_bed_elevation_jump(self):
    """应用泵站引起的底床高程跳跃"""
    if not self.structure_indices or not self.structure_objects:
        return
    
    from solvers.gate import PumpStation
    
    for idx, structure in zip(self.structure_indices, self.structure_objects):
        if not isinstance(structure, PumpStation):
            continue
        
        # 泵站后的所有点，底床高程抬高扬程
        self.z[idx:] += structure.rated_head
```

### 物理关系

```
水位 η = 底床高程 z + 水深 h

泵站前: η₁ = z₁ + h₁
泵站后: η₂ = (z₁ + ΔH) + h₂ = z₁ + ΔH + h₁ ≈ η₁ + ΔH

其中: ΔH = 泵站扬程
```
