# 明渠数值求解器问题总结

**日期**: 2025-10-21
**状态**: ❌ 未解决

---

## 问题描述

经过多次尝试，**所有三种数值方法（EXPLICIT、PREISSMANN、HLL）都无法真正收敛到正确的稳态**。

### 观察到的问题

1. **质量不守恒**: 下游流量持续增长或错误
   - EXPLICIT: 下游流量从5增长到12.5 m³/s
   - PREISSMANN: 下游流量从5增长到6.7 m³/s
   - HLL: 下游流量从5增长到9.7 m³/s

2. **锯齿状振荡**: 即使看似"稳定"的方法也有振荡
   - 变异系数达到2-6%
   - 无法达到真正的稳态

3. **边界条件处理**: 可能的根本问题
   - 上游流量边界 + 下游水位边界
   - 当前实现方式可能不正确

---

## 尝试的方法

### 方法1: 显式有限差分（EXPLICIT）
**问题**: 下游流量持续增长，变异系数6.15%

```python
# 连续方程
dQ_dx = (Q_old[i+1] - Q_old[i]) / self.dx
dA_dt = -dQ_dx

# 动量方程
dQ_dt = self.g * A * (self.S0 - Sf - dh_dx)
```

**稳定性措施**:
- CFL < 0.4
- 松弛因子 0.5
- 物理约束

**结果**: ❌ 不收敛

### 方法2: Preissmann隐式格式
**问题**: 水位有奇怪尖峰，流量增长，变异系数2.56%

```python
# 半隐式Crank-Nicolson
theta = 0.5
dQ_dx = theta * dQ_dx_new + (1 - theta) * dQ_dx_old
```

**稳定性措施**:
- 点迭代（10次）
- 松弛因子 0.2-0.3
- dt_eff = 0.3 * dt

**结果**: ❌ 基本收敛但不正确

### 方法3: HLL有限体积法
**问题**: 水位波动，流量增长，变异系数4.93%

```python
# Lax-Friedrichs通量
F_h = 0.5 * (Q_L + Q_R) - 0.5 * lambda_max * (A_R - A_L)
```

**稳定性措施**:
- CFL < 0.3
- 松弛因子 0.4
- 数值粘性

**结果**: ❌ 不收敛

### 方法4: 人工粘性稳定化
**问题**: 下游流量降到0.10 m³/s（错误！）

```python
# 添加人工粘性
d2Q_dx2 = (Q[i+1] - 2*Q[i] + Q[i-1]) / dx²
dA_dt = -dQ_dx + nu * dx * d2Q_dx2
```

**结果**: ❌ 质量严重不守恒

## 根本原因分析

### 可能的问题

1. **边界条件应用方式错误**
   - 上游流量 + 下游水位的组合可能需要特殊处理
   - 当前的外推方法可能不对

2. **数值格式不保守**
   - 离散格式可能不满足守恒性
   - 源项处理可能有误

3. **稳态解不存在或不唯一**
   - 给定的边界条件组合可能导致问题
   - 需要检查理论解

4. **初始条件不合适**
   - 从非稳态初始条件启动导致长期漂移
   - 需要正确的稳态初始化

### 短期方案（应急）

### 中期方案（需要重新设计）

1. **使用经过验证的商业软件数值格式**
   - 参考HEC-RAS、MIKE11等的实现
   - 使用经典的Abbott-Ionescu格式

2. **重新审视边界条件**
   - 可能需要使用上游水位+下游水位
   - 或者上游流量+下游流量
   - 当前的混合边界可能有理论问题

3. **从解析解验证**
   - 先用简单情况（均匀流、恒定流）验证
   - 然后逐步增加复杂度

4. **使用成熟的开源库**

   - 或者Python的水力学库
