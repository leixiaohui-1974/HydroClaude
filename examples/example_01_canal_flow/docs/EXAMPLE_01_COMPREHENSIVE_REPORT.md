### 2.2 边界条件

**上游边界**（x = 0）：
- 类型：流量边界条件
- 数值：Q = 8.0 m³/s（恒定）

**下游边界**（x = 1000 m）：
- 类型：水深边界条件
- 数值：h = 0.8065 m（通过Manning公式计算）

**计算方法**：
```
Manning公式: Q = (1/n) × A × R^(2/3) × S₀^(1/2)
其中: A = B × h, R = A / (B + 2h)
给定 Q = 8.0 m³/s，求解得 h = 0.8065 m
```

**关键改进**：下游水深通过上游流量计算得到，确保边界条件的物理兼容性。这是解决数值振荡的核心措施之一。

## 3. 数值方法说明

### 3.1 EXPLICIT（显式有限差分法）

**离散格式**：
- 时间离散：一阶显式Euler
- 空间离散：中心差分（70%）+ 迎风差分（30%）
- 稳定性条件：CFL < 0.5

**优点**：
- 实现简单
- 计算速度快
- 无需求解线性方程组

**缺点**：
- 时间步长受CFL条件限制
- 稳定性对参数敏感

**关键改进**：
- 混合迎风-中心格式增加数值耗散
- Savitzky-Golay空间滤波消除高频振荡

### 3.2 PREISSMANN（四点隐式格式）

**离散格式**：
- 时间离散：θ加权隐式格式（θ = 0.6）
- 空间离散：四点盒式格式
- 稳定性：无条件稳定

**优点**：
- 无条件稳定（可用较大时间步长）
- 精度高（二阶）
- 在水力学中广泛应用

**缺点**：
- 实现复杂
- 每步需迭代或求解方程组

**实现方式**：
- 使用显式预估 + θ加权校正
- 避免直接求解大型线性方程组

### 3.3 HLL（有限体积法）

**离散格式**：
- 空间离散：有限体积法
- 通量计算：HLL近似Riemann求解器
- 守恒性：严格满足积分守恒

**优点**：
- 物理守恒性好
- 适合间断问题
- 理论基础坚实

**缺点**：
- 计算稍复杂
- 需要估计波速

**Riemann求解器**：
```
左波速: S_L = min(V_L - c_L, V_R - c_R)
右波速: S_R = max(V_L + c_L, V_R + c_R)
HLL通量: F_HLL = (S_R × F_L - S_L × F_R + S_L × S_R × (U_R - U_L)) / (S_R - S_L)
```

#### 9.1.1 Manning方程求解器

```python
def compute_steady_uniform_flow(Q, B, S0, n):
    """
    计算恒定均匀流水深

    Manning公式:
        Q = (1/n) × A × R^(2/3) × S0^(1/2)
    其中:
        A = B × h (矩形断面面积)
        R = A / P = (B × h) / (B + 2h) (水力半径)

    参数:
        Q: 流量 (m³/s)
        B: 渠宽 (m)
        S0: 底坡 (-)
        n: Manning糙率 (s/m^(1/3))

    返回:
        h: 水深 (m)
    """

    def manning_equation(h):
        if h <= 0:
            return 1e10
        A = B * h
        P = B + 2 * h
        R = A / P
        Q_calc = (1.0 / n) * A * (R ** (2./3.)) * (S0 ** 0.5)
        return Q_calc - Q

    # 二分法求解
    h_min, h_max = 0.01, 20.0

    # 检查根的存在性
    if manning_equation(h_min) * manning_equation(h_max) > 0:
        # 使用估计值
        h_est = (Q * n / (B * S0**0.5)) ** (3./5.)
        return max(0.5, min(10.0, h_est))

    # 二分迭代
    while h_max - h_min > 1e-6:
        h_mid = (h_min + h_max) / 2
        if manning_equation(h_mid) * manning_equation(h_min) < 0:
            h_max = h_mid
        else:
            h_min = h_mid

    return (h_min + h_max) / 2
```

#### 9.1.2 Savitzky-Golay空间滤波

```python
from scipy.signal import savgol_filter

def apply_spatial_filter(self, field):
    """
    应用Savitzky-Golay空间滤波器

    参数:
        field: 待滤波的场变量 (nx,)

    返回:
        filtered: 滤波后的场 (nx,)
    """
    # Savitzky-Golay滤波：局部多项式拟合
    filtered = savgol_filter(
        field,
        window_length=11,  # 窗口长度（必须为奇数）
        polyorder=3,       # 多项式阶数
        mode='nearest'     # 边界处理模式
    )

    # 保留边界值（确保边界条件不被改变）
    filtered[0] = field[0]
    filtered[-1] = field[-1]

    return filtered
```

**原理说明**：
- Savitzky-Golay滤波器使用局部多项式拟合
- 相比简单移动平均，能更好地保留信号特征
- 窗口长度11对应约50m的空间范围（dx=5m）
- 多项式阶数3平衡了平滑性和精度

#### 9.1.3 混合迎风-中心格式

```python
# 中心差分（精度高，但无耗散）
dQ_dx_central = (Q_old[i+1] - Q_old[i-1]) / (2 * self.dx)

# 迎风差分（有耗散，但精度低）
if Q_old[i] >= 0:  # 正向流动
    dQ_dx_upwind = (Q_old[i] - Q_old[i-1]) / self.dx
else:  # 负向流动
    dQ_dx_upwind = (Q_old[i+1] - Q_old[i]) / self.dx

# 混合格式（30%迎风 + 70%中心）
upwind_ratio = 0.3
dQ_dx = upwind_ratio * dQ_dx_upwind + (1 - upwind_ratio) * dQ_dx_central
```

**设计理由**：
- 中心格式提供二阶精度
- 迎风格式提供数值耗散（抑制高频振荡）
- 30%的混合比例是实验优化的结果

### 9.3 稳定性判据

为确保数值稳定性，应同时满足：

1. **CFL条件**（必要条件）：
```

```

2. **网格分辨率条件**（充分条件）：

dx / h < 10 （理想值 ≈ 6）
