# 工程案例3: 多闸门协同控制

## 工程背景

某长距离输水渠道，全长12公里，设置3个调节闸门。需要协同控制各段水位，保持在设计范围内，应对流量变化。

### 系统配置

```
上游 ──→ [第1段] ──→ 闸门1(3km) ──→ [第2段] ──→ 闸门2(6km) ──→ [第3段] ──→ 闸门3(9km) ──→ 下游
         监测1.5km              监测4.5km              监测7.5km
```

**渠道参数**：
- 总长度：12 km
- 渠道宽度：15 m
- 渠底坡度：0.0005
- Manning糙率：0.022

**结构物**：
- 闸门1：位于3 km处，宽15 m
- 闸门2：位于6 km处，宽15 m
- 闸门3：位于9 km处，宽15 m

**监测点**：
- 监测点1：1.5 km（第1段中点）
- 监测点2：4.5 km（第2段中点）
- 监测点3：7.5 km（第3段中点）

## 控制目标

维持各段水位在目标值（梯度分布）：
- 第1段：2.5 m
- 第2段：2.3 m
- 第3段：2.1 m

## 扰动场景

**扰动类型**：上游流量阶跃变化
- **时刻**：t = 300s（5分钟）
- **扰动前**：Q = 25.0 m³/s
- **扰动后**：Q = 32.0 m³/s
- **扰动幅度**：+28%

## 控制策略

### 多变量MPC协同控制

**核心思想**：
- 使用MPC实现3个闸门的协同控制
- 在线辨识闸门间的耦合关系
- 优化整体控制性能

**控制器参数**：
```yaml
prediction_horizon: 18    # 预测时域（较长，考虑耦合）
control_horizon: 9        # 控制时域
Q_weight: 3.0            # 状态跟踪权重
R_weight: 1.5            # 控制平滑权重
```

**初始模型**（3状态 × 3控制）：
```
A (状态转移矩阵):
  [0.85  0.10  0.00]    # 第1段主要受自身影响
  [0.05  0.85  0.10]    # 第2段受三段影响（耦合）
  [0.00  0.05  0.85]    # 第3段受第2、3段影响

B (输入矩阵):
  [0.15  0.00  0.00]    # 闸门1主要控制第1段
  [0.05  0.15  0.00]    # 闸门2主要控制第2段
  [0.00  0.05  0.15]    # 闸门3主要控制第3段
```

**矩阵说明**：
- **对角主导**：每段主要受自身状态和对应闸门控制
- **弱耦合**：上下游之间存在弱耦合关系
- **因果性**：下游影响不会逆向传播（三角结构）

## 关键挑战

### 1. 多点耦合
- **问题**：上游闸门调节影响下游水位
- **解决**：MPC显式建模耦合关系，在线辨识

### 2. 时间延迟
- **问题**：扰动传播需要时间（波速 ~2-3 m/s）
- **解决**：MPC预测时域足够长（180秒）

### 3. 约束协调
- **问题**：多个闸门同时受约束
- **解决**：MPC优化问题中显式处理约束

### 4. 计算复杂度
- **问题**：3×3系统，优化变量增多
- **状态**：当前配置可实时运行（< 0.1s/步）

## 参数调节建议

### Q权重（状态跟踪）
- **增大**：更精确的水位跟踪，但可能更激进
- **减小**：允许一定误差，控制更平滑
- **当前值**：3.0（中等，平衡跟踪与平滑）

### R权重（控制平滑）
- **增大**：控制更平滑，减少闸门调节
- **减小**：允许更大控制量，响应更快
- **当前值**：1.5（适中）

### 预测时域（prediction_horizon）
- **增大**：看得更远，但计算量增加
- **减小**：计算快，但预见性不足
- **当前值**：18步（180秒）

### 控制时域（control_horizon）
- **一般规则**：control_horizon ≤ prediction_horizon / 2
- **当前值**：9步（90秒）
