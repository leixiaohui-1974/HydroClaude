# 工程案例5: 水资源优化调度

## 案例概述

**场景**: 城市多源供水系统，需要通过优化泵站调度来平衡供水可靠性和运行成本。

**目标**:
1. 满足下游时变用水需求
2. 最小化泵站电力成本（考虑峰谷电价）
3. 维持合理的系统水位范围

**应用价值**:
- 降低供水系统运行成本15-30%
- 提高供水可靠性和稳定性
- 充分利用峰谷电价差
- 优化水资源配置效率

## 技术方案

### 1. 模型预测控制（MPC）

使用MPC框架进行滚动优化：

**优化目标**:
```
min J = Σ[电价(t) × 功率(t) × Δt + α × (水位误差)²]
```

**约束条件**:
- 泵站容量约束: 3 ≤ Q_pump ≤ 20 m³/s
- 水位约束: 2.3 ≤ h ≤ 2.7 m
- 供水可靠性: Q_pump ≥ 需求

### 2. 峰谷电价策略

**电价分时段**:
- 谷时 (23:00-08:00): 0.3 元/kWh
- 平时 (11:00-18:00, 21:00-23:00): 0.7 元/kWh
- 峰时 (08:00-11:00, 18:00-21:00): 1.2 元/kWh

**优化策略**:
- 谷时期间: 多抽水，提高水位，储水
- 峰时期间: 少抽水，降低水位，释水
- 平衡水位和成本

### 3. 需求预测

**典型城市用水曲线**:
- 早高峰: 7:00-9:00
- 晚高峰: 18:00-20:00
- 低谷: 0:00-5:00

## 工程应用

### 应用场景1: 城市供水系统

**问题**: 电费占供水成本的40-50%

**方案**:
- 利用峰谷电价差优化调度
- 夜间谷时多抽水，白天峰时少抽水
- 年节省电费15-30%

**实施要点**:
- 需要足够的调蓄容量
- 准确的需求预测
- 实时水位监测

### 应用场景2: 农业灌溉系统

**问题**: 灌溉季电费高昂，且用电集中

**方案**:
- 错峰灌溉，利用低谷电价
- 预先蓄水，分散用电
- 降低用电成本20-40%

**实施要点**:
- 灌溉计划灵活调整
- 配套蓄水设施
- 考虑作物需水特性

### 应用场景3: 工业园区供水

**问题**: 用水波动大，泵站频繁启停

**方案**:
- MPC预测性控制
- 平滑泵站运行曲线
- 延长设备寿命，降低维护成本

**实施要点**:
- 需求预测模型
- 泵站变频控制
- 自动化调度系统

## 技术细节

### MPC优化算法

简化的优化决策：

```python
def simple_mpc_optimization(current_state, demand_forecast, price_forecast):
    # 基于电价的权重
    avg_price = np.mean(price_forecast)
    price_factor = 0.5 if avg_price < 0.5 else (1.5 if avg_price > 1.0 else 1.0)

    # 基于水位的调整
    level_error = target_level - current_level
    level_factor = 1.0 + 0.5 * level_error

    # 基于需求的基准
    avg_demand = np.mean(demand_forecast)

    # 综合决策
    optimal_flow = avg_demand * price_factor * level_factor
    optimal_flow = np.clip(optimal_flow, Q_min, Q_max)

    return optimal_flow
```

### 成本计算

```python
# 泵站功率计算
功率 (kW) = ρ × g × Q × H / η / 1000

其中:
- ρ = 1000 kg/m³ (水密度)
- g = 9.81 m/s² (重力加速度)
- Q = 流量 (m³/s)
- H = 扬程 (m)
- η = 效率 (0.75)

# 运行成本
成本 (元) = 功率 (kW) × 电价 (元/kWh) × 时间 (h)
```

## 常见问题

### Q1: 如何设置合适的预测时域？

**答**:
- 一般3-6小时
- 过短: 缺乏前瞻性
- 过长: 预测误差大
- 建议: 与电价时段对应

### Q2: 峰谷电价差多大才值得优化？

**答**:
- 一般峰谷差 > 0.4 元/kWh 就有价值
- 差价越大，节省越明显
- 需考虑储水成本和设备折旧

### Q3: 如何处理突发用水需求？

**答**:
- 预留应急调节容量
- 实时监测，动态调整
- 必要时暂时放弃成本优化，保证供水
