## 案例1: 灌溉渠道优化设计

**工程背景**：
设计一条5公里长的灌溉主干渠，需要满足：
- 输水流量：20 m³/s
- 末端水深：≥ 2.0 m（满足取水要求）
- 渠道坡度：需要优化

**技术要点**：
- 稳态水面线计算
- 临界坡度判断
- 曼宁公式应用

**使用功能**：
- 均匀网格生成
- 稳态求解器
- 结果验证

## 案例2: 防洪调度应急响应

**工程背景**：
汛期上游洪水来临，流量从15 m³/s突增至30 m³/s，需要通过闸门调节确保下游渠段不溢出。

**技术要点**：
- 洪水演进过程
- 闸门开度动态调整
- 水位监测预警

**使用功能**：
- 时变边界条件（阶跃变化）
- 非稳态模拟
- 结构物控制

## 案例3: 多闸门协同控制

**工程背景**：
长距离输水渠道（12 km），设置3个调节闸门（3km, 6km, 9km），需要协同控制各段水位保持在梯度分布（2.5m, 2.3m, 2.1m），应对流量扰动（+28%）。

**技术要点**：
- 多点监测（3个监测点）
- 多变量MPC协同控制（3×3系统）
- 在线模型辨识（自适应）
- 耦合关系建模

**使用功能**：
- 多结构物建模（3个闸门）
- MPC控制器（协同优化）
- 多目标水位控制
- 时变边界条件（阶跃扰动）

**性能结果**：
- MAE: 1.15 m
- 控制平滑，闸门开度梯度递减
- 成功应对+28%流量扰动
