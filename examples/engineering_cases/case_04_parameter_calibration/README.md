# 工程案例4: 参数在线校准

## 案例概述

**场景**: 运行中的渠道系统，糙率因淤积、植被生长等原因发生变化，需要实时校准模型参数以保持预测准确性。

**目标**: 使用增广卡尔曼滤波（Augmented EKF）在线估计糙率参数。

**应用价值**:
- 提高水力学模型长期运行的准确性
- 实时监测渠道状态变化
- 自适应模型参数，减少人工校准工作量

## 技术方案

### 1. 增广卡尔曼滤波（Augmented EKF）

将参数视为"慢变状态"，与物理状态一起估计：

**增广状态向量**:
```
X_aug = [h, hu, n]
```

其中：
- `h`: 水深（物理状态）
- `hu`: 单宽流量（物理状态）
- `n`: 糙率（参数状态）

**参数动力学模型**:
```
n(k+1) = n(k) + w_n
```

其中 `w_n` 是很小的过程噪声，表示参数的缓慢变化。

### 2. 敏感度分析

计算观测值对参数的敏感度：

```
∂z/∂n ≈ (z(n + Δn) - z(n)) / Δn
```

这用于更新步中的卡尔曼增益计算。

### 3. 观测融合

使用多个传感器的水位观测：
- 传感器1: 渠道1/3位置
- 传感器2: 渠道中点
- 传感器3: 渠道2/3位置

## 工程应用

### 应用场景1: 淤积监测

**问题**: 渠道长期运行后淤积，糙率增加

**方案**:
- 实时监测糙率变化
- 当糙率超过阈值时告警
- 触发清淤维护

**代码示例**:
```python

```

### 应用场景2: 季节性变化适应

**问题**: 植被生长导致糙率季节性变化

**方案**:
- 持续跟踪糙率变化
- 自动更新模型参数
- 保持全年预测准确性

### 应用场景3: 模型校准

**问题**: 新建渠道，糙率不确定

**方案**:
- 初始阶段密集观测
- 快速收敛到真实糙率
- 用于后续运行和设计优化

## 技术细节

### 卡尔曼滤波步骤

1. **预测步**:
   ```python
   # 状态预测
   X_pred = f(X_prev) + w
   # 协方差预测
   P_pred = F * P_prev * F^T + Q
   ```

2. **更新步**:
   ```python
   # 卡尔曼增益
   K = P_pred * H^T * (H * P_pred * H^T + R)^(-1)
   # 状态更新
   X_new = X_pred + K * (z - h(X_pred))
   # 协方差更新
   P_new = (I - K * H) * P_pred
   ```

### 敏感度计算

使用有限差分法计算 ∂z/∂n：

```python
delta_n = 1e-6
z_base = measure(n)
z_pert = measure(n + delta_n)
sensitivity = (z_pert - z_base) / delta_n
```

## 常见问题

### Q1: 为什么需要在线参数估计？

**答**:
- 渠道特性随时间变化（淤积、植被、老化）
- 初始参数可能不准确
- 提高长期预测准确性

### Q2: 估计收敛需要多长时间？

**答**:
- 取决于初始误差和观测噪声
- 典型情况：10-20分钟达到<1%误差
- 可通过增加传感器或提高采样率加速收敛

### Q3: 如何选择过程噪声？

**答**:
- 状态过程噪声：根据物理模型不确定性（典型值：0.01）
- 参数过程噪声：很小，表示参数缓变（典型值：1e-5）
- 可通过调优获得最佳性能
