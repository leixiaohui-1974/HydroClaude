# 示例21: 灌区配水优化调度

## 概述

本示例演示大型灌区多水源、多渠系的配水优化调度，包括多种作物轮灌、优先级配水和水量平衡优化。

## 系统组成

```
系统拓扑:
[水库] → [总干渠] → [干渠1/2/3] → [田块]
5000万m³    40m³/s        各15m³/s      1190公顷

作物类型:
  - 水稻: 380公顷 (优先级5, 需水120 m³/公顷/天)
  - 小麦: 310公顷 (优先级4, 需水80 m³/公顷/天)
  - 玉米: 250公顷 (优先级3, 需水70 m³/公顷/天)
  - 蔬菜: 100公顷 (优先级4, 需水100 m³/公顷/天)
  - 果树: 150公顷 (优先级3, 需水60 m³/公顷/天)
```

## 主要特点

### 1. 多作物管理
不同作物有不同的:
- 需水量（70-120 m³/公顷/天）
- 轮灌周期（5-14天）
- 缺水容忍度（0.1-0.3）
- 优先级（3-5）

### 2. 渠系网络
- **总干渠**: 40 m³/s, 15km, 5%损失
- **干渠1**: 15 m³/s, 8km → 水稻+小麦
- **干渠2**: 12 m³/s, 10km → 小麦+玉米
- **干渠3**: 13 m³/s, 12km → 蔬菜+果树

### 3. 配水策略
1. **优先级排序**
   - 优先级5: 水稻（关键作物）
   - 优先级4: 小麦、蔬菜
   - 优先级3: 玉米、果树

2. **轮灌制度**
   - 水稻: 7天轮灌，每天12小时
   - 小麦: 10天轮灌，每天8小时
   - 玉米: 12天轮灌，每天8小时
   - 蔬菜: 5天轮灌，每天6小时
   - 果树: 14天轮灌，每天8小时

3. **缺水分配**
   - 高优先级作物优先满足
   - 考虑缺水容忍度
   - 最小供水量 = 需水量 × (1 - 容忍度)

## 优化目标

1. **供水率最大化**
   - 总供水量 / 总需水量 > 95%

2. **满意度最大化**
   - 综合考虑优先级和缺水情况
   - 平均满意度 > 90%

3. **公平性**
   - 各作物按优先级公平分配
   - 避免某些田块长期缺水

4. **水量平衡**
   - 水库安全运行
   - 不突破死库容

## 技术要点

### 1. 轮灌制度
```python
# 检查是否该轮灌
schedule = schedules[crop_type]
if day % schedule.rotation_days == 0:
    # 该田块需要灌溉
    daily_demand = area * water_demand
```

### 2. 优先级配水
```python
# 按优先级和缺水容忍度排序
sorted_fields = sorted(
    fields,
    key=lambda f: (f.priority, 1 - f.deficit_tolerance),
    reverse=True
)

# 按序分配水量
for field in sorted_fields:
    min_supply = demand * (1 - tolerance)
    allocation = min(demand, remaining_water)
```

### 3. 水量平衡
```python
# 可供水量约束
max_daily_release = min(
    max_release * 86400,  # 最大放水能力
    current_storage - min_storage  # 库容约束
)
```

### 4. 满意度计算
```python
# 缺水量
deficit = max(0, demand - allocation)

# 满意度
satisfaction = (1 - total_deficit / total_demand) * 100
```
