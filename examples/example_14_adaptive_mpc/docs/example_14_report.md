# 示例14：自适应MPC控制报告

## 1. 问题背景

### 1.1 工程背景
水网系统是典型的复杂动态系统，存在以下特点：
- **时变性**: 流量、水位随时间变化
- **不确定性**: 需水量预测误差、泄漏等
- **非线性**: Saint-Venant方程本质非线性
- **参数漂移**: 糙率随淤积变化、阀门老化等

传统固定参数控制器在参数变化时性能下降，需要自适应控制技术。

### 1.2 技术挑战
- 在线参数辨识计算量大
- 辨识精度影响控制性能
- 需要平衡探索与利用
- 鲁棒性与自适应性的权衡

### 1.3 研究目标
展示HydroClaude的自适应MPC能力，验证在线参数辨识的有效性。

## 2. 数学模型

### 2.1 系统动力学模型

**状态空间模型**:
```
x[k+1] = A·x[k] + B·u[k] + w[k]
y[k] = C·x[k] + v[k]

其中:
x ∈ ℝⁿ: 状态向量 (水深、流量)
u ∈ ℝᵐ: 控制输入 (阀门开度)
y ∈ ℝᵖ: 测量输出
w, v: 过程/测量噪声
```

**本例系统**:
```
n = 2 (状态维数)
m = 1 (控制维数)
p = 2 (输出维数)

x = [h, Q]ᵀ (水深、流量)
u = a (阀门开度)
```

### 2.2 MPC优化问题

**目标函数**:
```
min  J = Σ(k=0 to Np-1) [‖x[k] - x_ref‖²_Q + ‖u[k]‖²_R + ‖Δu[k]‖²_S]

s.t.
  x[k+1] = A·x[k] + B·u[k]  (动力学约束)
  x_min ≤ x[k] ≤ x_max       (状态约束)
  u_min ≤ u[k] ≤ u_max       (控制约束)
  Δu_min ≤ Δu[k] ≤ Δu_max   (变化率约束)
```

**权重矩阵**:
```
Q = diag([100, 1])  (状态权重)
R = 0.1             (控制权重)
S = 1.0             (变化率权重)
```

**时域**:
```
Np = 10  (预测时域)
Nc = 3   (控制时域)
```

### 2.3 递推最小二乘(RLS)辨识

**参数化模型**:
```
x[k+1] = Φ[k]ᵀ·θ + ε[k]

其中:
Φ[k] = [x[k]; u[k]]  (回归向量)
θ = [A的列; B的列]    (参数向量)
```

**RLS更新公式**:
```
# 预测误差
e[k] = x[k+1] - Φ[k]ᵀ·θ[k-1]

# 增益矩阵
K[k] = P[k-1]·Φ[k] / (λ + Φ[k]ᵀ·P[k-1]·Φ[k])

# 参数更新
θ[k] = θ[k-1] + K[k]·e[k]

# 协方差更新 (Joseph形式)
I_KΦ = I - K[k]·Φ[k]ᵀ
P[k] = (I_KΦ·P[k-1]·I_KΦᵀ + K[k]·K[k]ᵀ·reg) / λ
```

**关键参数**:
```
λ = 0.98  (遗忘因子)
P[0] = 1000·I  (初始协方差)
reg = 1e-6  (正则化项)
```

## 6. 理论分析

### 6.1 RLS收敛性

**充要条件**:
```
1. 持续激励: 输入信号u[k]充分丰富
2. 遗忘因子: 0 < λ < 1
3. 正则化: reg > 0
```

**本例验证**:
```
1. MPC控制自然提供激励 ✓
2. λ = 0.98 ∈ (0,1) ✓
3. reg = 1e-6 > 0 ✓
```

**收敛速度**:
```
‖θ[k] - θ*‖ ≤ C·λᵏ/(1-λ)

对于λ=0.98:
- 半衰期: t_1/2 ≈ log(2)/log(1/λ) ≈ 34步
- 观测: 35步达到2%误差 ✓
```

### 6.2 MPC稳定性

**名义稳定性** (完美模型):
由于终端约束和递减时域，MPC确保：
```
V(x[k+1]) ≤ V(x[k]) - ‖x[k] - x_ref‖²_Q
→ Lyapunov稳定
```

**鲁棒稳定性** (模型误差):
对于小模型误差 ΔA, ΔB:
```
如果 ‖ΔA‖ + ‖ΔB‖·‖K‖ < ε
则闭环系统仍稳定

其中ε与Q, R相关
```

**自适应MPC**:
随着辨识精度提高，ΔA, ΔB → 0
→ 稳定性裕度增大

### 6.3 性能边界

**最优控制律** (已知模型):
```
u*[k] = -K_LQR·(x[k] - x_ref)

LQR增益: K_LQR = (B'PB + R)⁻¹B'PA
```

**自适应控制律**:
```
u_adaptive[k] = -K_LQR(θ[k])·(x[k] - x_ref)

其中θ[k]是当前参数估计
```

**性能下界**:
```
J_adaptive ≥ J_optimal

差距随参数误差减小而减小
```

## 7. 讨论

### 7.1 自适应MPC优势

**vs 固定MPC**:
1. **鲁棒性**: 适应参数变化
2. **性能**: 收敛到最优
3. **免调参**: 自动适应系统

**vs 离线辨识+MPC**:
1. **实时性**: 在线更新
2. **跟踪能力**: 追踪时变参数
3. **初值鲁棒**: 初值误差自动修正

### 7.2 计算复杂度

**每步计算时间**:
```
MPC优化: O(Np³)  (~10 ms)
RLS更新: O(n²)   (~1 ms)
总计: ~11 ms

实时可行性: 采样周期 >> 11 ms ✓
```

**内存需求**:
```
MPC矩阵: O(Np·n)  (~1 KB)
RLS协方差: O(n²)  (~100 B)
总计: ~1 KB

嵌入式可行 ✓
```

### 7.3 工程应用建议

**实施步骤**:
1. **离线建模**: 获取初始模型

4. **在线部署**: 逐步激活自适应
5. **监控调试**: 跟踪辨识质量

```

权重矩阵Q, R:
- 跟踪优先: Q大, R小

# 参数误差
def parameter_error(A_est, B_est, A_true, B_true):
    error_A = np.linalg.norm(A_est - A_true, 'fro') / np.linalg.norm(A_true, 'fro')
    error_B = np.linalg.norm(B_est - B_true, 'fro') / np.linalg.norm(B_true, 'fro')
    return error_A, error_B

# 跟踪误差
def tracking_error(x, x_ref):
    return np.linalg.norm(x - x_ref)

# 稳态误差
def steady_state_error(x_trajectory, x_ref, last_n=10):
    x_ss = x_trajectory[-last_n:].mean(axis=0)
    return np.linalg.norm(x_ss - x_ref)
```
