## 一、Preissmann求解器修复（第一优先级）

### 1.1 问题诊断

**初始状态**：
- 质量守恒误差：+279%（完全不可接受）
- 项目中5个Preissmann版本，全部失败
- Canal类使用有严重bug的原始版本

**系统测试结果**：
| 版本 | 静水测试 | 主要问题 |
|------|---------|---------|
| 原始版本 | ❌ | +279%质量误差 |
| fixed | ❌ | 矩阵奇异，NaN |
| v2 | ❌ | 矩阵奇异，NaN |
| v3_scaled | ❌ | 矩阵奇异，NaN |
| v4_linear | ⚠️ | 静水通过，动态失败 |

### 1.2 根因分析

发现**5个关键bug**：

#### Bug #1: Q的np.maximum截断（致命）
```python
# 错误代码（原始版本）
Q_new = np.maximum(Q_new, 0.01)  # 强制正流量
```
**后果**：在静水情况下凭空创造流量，导致+279%质量误差

#### Bug #2: 连续方程离散错误
使用中点平均而非分别计算各节点，违反质量守恒

#### Bug #3: 动量方程不完整
缺少旧时刻的对流项，时间离散不准确

#### Bug #4: Jacobian矩阵奇异
在静态平衡点矩阵秩亏，导致求解失败

#### Bug #5: 数值溢出
Q²/A项在大流量时溢出，产生NaN

### 1.3 修复方案

创建`preissmann_solver_corrected.py`，实施6项修复：

1. **移除Q截断** - 允许负流量和零流量
2. **修正连续方程** - 分别计算各节点面积变化
3. **完整对流项** - 新旧时刻θ加权
4. **Tikhonov正则化** - 解决Jacobian奇异（J + λI）
5. **数值保护** - 限制Q最大值，防止溢出
6. **保守松弛因子** - α=0.2，提高稳定性

## 十、经验教训

### 10.1 技术教训

**1. "合理"的修正可能是致命bug**
```python
Q_new = np.maximum(Q_new, 0.01)  # 看似防止负值，实则破坏守恒
```
**教训**：物理直觉比数学技巧重要，Q=0是合法状态

**2. 矩阵奇异不是算法问题**
- 静态平衡点Jacobian本质上奇异
- 需要正则化而非"改进"离散
