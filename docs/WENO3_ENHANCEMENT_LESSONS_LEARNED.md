- **期望**: 质量误差<10%，消除负流量

## 2. 尝试的增强方法

### 2.1 改进的平滑度指示器（Jiang-Shu 1996）

**理论**:
```python
# 标准WENO3
IS = (phi[i+1] - phi[i])^2

# 增强版
IS = (phi[i+1] - phi[i])^2 + dx^2 * (d²phi/dx²)^2
```

**问题**:
- 对于粗网格（dx=10m），dx²=100会极大放大二阶导数项
- 尝试归一化`min(dx, 1.0)^2`后仍不稳定
- 高阶项在激波处可能导致过度惩罚

### 2.2 自适应Epsilon（Henrick 2005）

**理论**:
```python
# 标准
eps = 1e-6  # 固定

# 增强版
eps = 1e-6 * (1 + |phi|_max)  # 自适应
```

**问题**:
- 当数值爆炸后，phi_max→大 → eps→大 → 权重失效 → 进一步失控
- 尝试限制phi_max<100后仍不稳定
- 正反馈循环难以打破

### 2.3 熵修正（Harten-Hyman 1983）

**问题**:
- **未实现！** 只计算了u_L, u_R但从未使用
- 注释说"在HLL内部应用"，但父类HLL flux没有熵修正逻辑
- 这是代码缺陷，非算法问题

## 3. 测试结果对比

| 求解器 | 质量误差 | 负流量 | Fr上游 | 步数 | 时间 | 状态 |
|--------|----------|--------|--------|------|------|------|

| **增强WENO3 v1** | 4.6×10¹⁰% | - | - | 20000 | 15.5s | ❌ 爆炸 |

- 增强版时间步过小（20000步 vs 标准版100步）
- 稍微的改进（v2比v1好100倍）仍然不够，数值本质不稳定

## 4. 根本原因分析

### 4.1 理论vs实践的gap

学术论文中的改进通常基于：
- **理想条件**: 光滑初始条件，精细网格，长时间稳定
- **特定问题**: 激波管、涡流、平滑波传播

MacDonald Test 4的特点：
- **强激波**: 水跃是移动激波，非常强
- **粗网格**: 100单元，dx=10m
- **混合流态**: 超临界→水跃→亚临界
- **无摩阻**: n=0，缺乏耗散稳定机制

### 4.2 算法适用性问题

**不同WENO改进适用场景**：

| 改进 | 适用场景 | 不适用场景 |
|------|----------|------------|
| 高阶平滑度指示器 | 光滑解，精细网格 | ❌ 强激波，粗网格 |
| 自适应epsilon | 多尺度问题 | ❌ 爆炸性增长 |
| 熵修正 | 音速点，弱激波 | ❌ 强激波（需特殊处理） |

MacDonald Test 4恰好命中所有"不适用"条件！

## 5. 经验教训

### 5.1 技术教训

1. **不要盲目组合多个改进**
   - 每个改进单独测试
   - 理解交互效应
   - 增量添加，逐步验证

2. **算法有适用边界**
   - 学术论文的方法不是万能的
   - 理解问题特性比套用公式重要
   - "更复杂" ≠ "更好"

3. **数值稳定性第一**
   - 28%误差但稳定 > 理论优美但爆炸
   - 先稳定，再优化精度
   - 稳定性是前提，精度是目标

4. **粗网格需要特殊考虑**
   - dx相关的项（dx²）需要归一化
   - 粗网格本身限制了可达到的精度
   - 不要期望粗网格+高阶方法→商业软件精度

### 5.2 开发流程教训

1. **单元测试不够**
   - 光滑函数重构测试通过 ≠ 激波测试通过
   - 需要有代表性的集成测试
   - 早期发现数值爆炸

2. **增量开发**
   - 应该先测试标准WENO3
   - 再逐个添加改进
   - 每次确认改进或至少不恶化

3. **性能监控**
   - 步数激增（100→20000）是早期警告信号
   - 质量误差趋势图应该在开发中监控
   - 及时止损，不要一条路走到黑

### 5.3 科学态度

1. **诚实面对失败**
   - 增强版WENO3对此问题失败
   - 承认比掩盖更重要
   - 记录教训帮助未来开发

2. **理论与实践的平衡**
   - 学术论文提供方向，不是保证
   - 实际问题需要实际测试
   - 有时候简单稳定的方法更好

3. **知道何时放弃**
   - 尝试了两个版本修复
   - 根本问题在算法适配性
   - 回到标准WENO3，优化参数是更好选择

## 6. 前进方向

### 6.1 放弃增强版WENO3

**决定**: 对于MacDonald Test 4，不使用增强版WENO3

**原因**:
- 数值不稳定，无法修复
- 算法不适合此类强激波问题
- 投入回报比太低

### 6.2 专注标准WENO3优化

**新策略**:
1. 使用标准WENO3（稳定）
2. 优化参数：
   - CFL调小（0.4 → 0.2）
   - 增加网格分辨率（100 → 200）
   - 调整weno_epsilon
3. 改善初始条件（预形成水跃）
4. 使用更长模拟时间达到稳态

**预期**:
- 质量误差：28% → 10-15%
- 消除部分负流量
- 数值稳定

### 6.3 长期方向

对于水跃这类强激波问题，更好的方法可能是：
1. **混合方法**: WENO3+局部自适应网格加密
2. **Riemann求解器改进**: HLLC替代HLL（但需修复现有HLLC bug）
3. **预处理**: 使用Belanger方程预测水跃位置，局部加密
4. **专用激波捕捉**: Shock-fitting方法

## 8. 对标商业软件的新认识

### 8.1 商业软件的成功不是靠单一算法

Mike11、HEC-RAS等商业软件的MacDonald测试100%通过，不是因为：
- 用了最新的学术算法 ❌
- 有复杂的数学理论 ❌

而是因为：
- **稳健的标准算法** + **精心调优的参数** ✅
- **长时间工程实践** + **大量案例经验** ✅
- **自适应策略** + **问题特定处理** ✅

### 8.2 我们的路径调整

**错误路径**: 追逐最新算法 → 复杂实现 → 数值爆炸

**正确路径**: 稳定算法 → 理解问题 → 参数调优 → 渐进改善
