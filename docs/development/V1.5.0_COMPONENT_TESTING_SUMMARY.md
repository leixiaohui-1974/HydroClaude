## 🔧 测试技术要点

### 1. 避免复杂的UI Mock

**问题：** Ant Design组件的mock非常复杂，容易导致测试不稳定

**解决方案：**
- 不直接渲染React组件
- 测试组件使用的工具函数和业务逻辑
- 测试数据处理流程
- 测试localStorage集成

**优势：**
- 测试更稳定
- 测试运行更快
- 专注于实际业务逻辑
- 易于维护

### 2. localStorage Mock实现

```typescript
const createLocalStorageMock = () => {
  let store: Record<string, string> = {};

  return {
    getItem: (key: string) => store[key] || null,
    setItem: (key: string, value: string) => {
      store[key] = value;
    },
    removeItem: (key: string) => {
      delete store[key];
    },
    clear: () => {
      store = {};
    },
    get length() {
      return Object.keys(store).length;
    },
    key: (index: number) => {
      const keys = Object.keys(store);
      return keys[index] || null;
    }
  };
};
```

### 3. 测试辅助函数

### 4. File API Polyfill

Node.js环境不支持`File.text()`方法，需要添加polyfill：

```typescript
// Polyfill for Node.js
if (!file.text) {
  (file as any).text = async () => content;
}
```
