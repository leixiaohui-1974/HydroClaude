## Critical Path Tests (Priority 1)

### Test 1: Save & Load Model (5 min)

**Purpose:** Verify basic localStorage persistence

**Steps:**
1. Open http://localhost:5173/ in browser
2. Navigate to "建模工作台" (Modeling Workspace)
3. Create simple model:
   - Click "组件" panel to show components
   - Drag 2-3 "渠道" (Channel) nodes onto canvas
   - Connect them with edges
4. Click "保存模型" (Save Model) button
   - ✅ Success message should appear
5. Click "模型库" (Model Library) button
   - ✅ Your model should appear in the list
6. Click "打开" (Open) to reload it
   - ✅ Model should restore correctly

**Console Check:**
```javascript
// Verify model saved:
JSON.parse(localStorage.getItem('hydroclaude_models'))
```

### Test 2: Export JSON (3 min)

**Purpose:** Verify JSON export functionality

**Steps:**
1. With model from Test 1 active
2. Click "导出" dropdown → "导出为JSON"
   - ✅ File should download: `{model_name}.hydro.json`
3. Open downloaded file in text editor
4. Verify structure:
   ```json
   {
     "format": "HydroClaude Model",
     "version": "1.5.0",
     "exportDate": "...",
     "model": {
       "id": "...",
       "name": "...",
       "nodes": [...],
       "edges": [...]
     }
   }
   ```

**✅ Pass Criteria:**
- File downloads successfully
- JSON is valid and pretty-printed
- All model data present

## Quick Smoke Test Script

**Execute in Browser Console:**

```javascript
// 1. Check localStorage access
console.log('Storage available:', typeof localStorage !== 'undefined');

// 2. Check saved models
const models = JSON.parse(localStorage.getItem('hydroclaude_models') || '[]');
console.log('Saved models:', models.length);

// 3. Check storage quota
let used = 0;
for (const key in localStorage) {
  if (key.startsWith('hydroclaude_')) {
    const value = localStorage.getItem(key);
    if (value) used += value.length;
  }
}
console.log('Storage used:', (used / 1024).toFixed(2), 'KB');

// 4. Check model structure
if (models.length > 0) {
  const model = models[0];
  console.log('Sample model:', {
    id: model.id,
    name: model.name,
    nodes: model.nodes?.length || 0,
    edges: model.edges?.length || 0,
    validated: model.validated
  });
}

// 5. Test export utilities (if accessible)
console.log('Testing complete. Check output above.');
```

## Troubleshooting

### Issue: "Cannot save model"
- Check console for localStorage quota errors
- Clear old data: `localStorage.clear()`
- Check browser privacy settings

### Issue: "File doesn't download"
- Check browser download settings
- Try different browser
- Check popup blocker

### Issue: "Import fails on valid file"
- Check file size (must be < 10 MB)
- Verify JSON format matches export structure
- Check version compatibility (must be 1.x.x)

### Issue: "Model Library empty"
- Check localStorage: `localStorage.getItem('hydroclaude_models')`
- Save a model first
- Refresh browser

### Issue: "TypeScript errors in console"
- This shouldn't happen (already fixed)
- Restart dev server: `npm run dev`
- Clear browser cache
