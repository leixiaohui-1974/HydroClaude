# Entropy Fix
if self.entropy_fix:

# Critical Flow Treatment
if self.critical_flow_treatment:

   - `RatingCurveBC` - 水位-流量关系曲线
   - 双向插值：h→Q, Q→h

3. **水工建筑物**
   - `BroadCrestedWeir` - 宽顶堰（Villemonte公式）
   - `SharpCrestedWeir` - 薄壁堰
   - `SluiceGate` - 平板闸门（可调开度）
   - `Orifice` - 圆形孔口

#### 技术特性

**插值和外推**:
- 使用`scipy.interpolate.interp1d`
- 3种外推方式：constant/linear/raise
- 插值时间：~0.1 μs

**流态判断**:
```python
regime = structure.get_regime(h_upstream, h_downstream)
# FlowRegime.FREE 或 FlowRegime.SUBMERGED
```

**求解器集成**:
```python
# 利用已有的callable支持
flood = HydrographBC.triangular(10, 100, 2*3600, 8*3600)
bc = {'type': 'Q', 'value': flood}  # 传入callable
solver.set_initial_conditions(..., bc_left=bc, ...)
```

#### 水力公式

**宽顶堰**:
- 自由出流：`Q = C * B * H^(3/2)`
- 淹没出流：Villemonte修正
- 深度淹没：孔流公式

**平板闸门**:
- 自由出流：`Q = C_d * a * B * sqrt(2*g*H)`
- 淹没出流：`Q = C_d * a * B * sqrt(2*g*ΔH)`
- 收缩系数：C_d ≈ 0.6
