### 背景

Anderson加速是一种先进的固定点迭代加速方法，理论上优于当前使用的Aitken加速（使用更多历史信息）。

### 实现内容

#### 1. Anderson加速核心框架

**文件**: `solvers/anderson_acceleration.py` (316行)

**核心算法**：
```python
class AndersonAcceleration:
    def __init__(self, m=5, beta=1.0, reg=1e-8, restart=True):
        # m: 历史深度
        # beta: 松弛因子
        # reg: 正则化参数
        # restart: 自动重启机制
```

**技术特点**：
- 保持最近m个迭代的历史
- 最小化残差线性组合：min ||F·α||²
- 使用QR分解求解最小二乘问题
- 支持标量和数组输入（修复了兼容性问题）
- 自动重启机制（检测数值不稳定）

## 🔧 优化任务二：牛顿法Jacobian奇异性修复

### 背景

之前实现的牛顿法+多网格求解器遇到Jacobian奇异性问题：
- 问题：稳态Saint-Venant方程 dQ/dx = 0 → Q = constant，系统过约束
- 解决思路：伪瞬态延拓（Pseudo-Transient Continuation, PTC）

### 伪瞬态延拓原理

**核心思想**：
- 添加人工时间导数项：ε·∂Q/∂τ + dQ/dx = 0
- 使Jacobian变为：J + (1/ε)·I，不再奇异
- 从大ε开始，逐渐减小ε到0，收敛到稳态解

**数学形式**：
```
连续性：ε·∂Q/∂τ + dQ/dx = 0
动量：  ε·∂h/∂τ + d(Q²/A)/dx + gA·dh/dx = gA(S₀ - Sf)
```

**Jacobian修正**：
```
∂F_continuity/∂Q_i = 1/ε + 空间导数项
∂F_momentum/∂h_i = 1/ε + 空间导数项
```

### 发现的Bug

**位置**: `physics/steady_saint_venant.py:322-326`

**Bug描述**：
普通节点的连续性方程Jacobian缺少伪瞬态项！

**修复前**（错误）：
```python
# 连续性方程 Jacobian
# F[2*i] = (Q[i+1] - Q[i-1]) / (2*dx)
J[2*i, 2*(i-1)+1] = -1.0 / (2 * self.dx)
J[2*i, 2*(i+1)+1] = 1.0 / (2 * self.dx)
# ❌ 缺少对角项！
```

**修复后**（正确）：
```python
# 连续性方程 Jacobian（带伪瞬态）
# F[2*i] = (Q[i]-Q_prev[i])/pseudo_dt + (Q[i+1] - Q[i-1]) / (2*dx)
J[2*i, 2*i+1] = 1.0 / self.pseudo_dt  # ✓ 添加伪时间项对角元素
J[2*i, 2*(i-1)+1] = -1.0 / (2 * self.dx)
J[2*i, 2*(i+1)+1] = 1.0 / (2 * self.dx)
```

### 测试结果

#### Jacobian秩分析（nx=11, 22个变量）

| pseudo_dt | 矩阵秩 | 理论秩 | 条件数 | 状态 |
|-----------|--------|--------|--------|------|
| ∞ (纯稳态) | 21 | 22 | 1.41e+17 | ✗ 奇异 |
| 1.0 | 21 | 22 | 2.02e+16 | ✗ 奇异 |
| 0.1 | 21 | 22 | 5.03e+17 | ✗ 奇异 |
| 0.01 | 21 | 22 | 6.77e+20 | ✗ 奇异 |

**结果**：即使修复了bug，Jacobian仍然奇异（秩21/22）！

### 根本原因分析

通过详细的Jacobian结构分析（`analyze_jacobian.py`），发现：

**零空间向量**：
```
h_0: -0.980321  ← 上游水深是自由变量！
h_1: -0.193523
h_2: -0.038205
```

**问题诊断**：
```
F[0] = Q_0 - Q_upstream  → 只约束Q_0，不约束h_0
F[1] = 连续性方程       → 只包含Q，不包含h_0
```

**根本原因**：**上游边界条件不完整！**

### 边界条件问题

**当前边界条件**：
- 上游：Q_0 = Q_upstream（1个约束）
- 下游：h_n = h_downstream（1个约束）

**问题**：
- 节点0有2个变量（h_0, Q_0），但只有1个明确的边界条件（Q_0）
- 第二个方程F[1]是连续性，不约束h_0
- **h_0是自由变量，导致系统欠约束！**

**正确的边界条件**（稳态Saint-Venant）：

选项1（超临界流）：
```
上游：Q_0 = Q_upstream
      h_0 = h_uniform（或其他物理约束）
下游：无需指定（信息向下游传播）
```

选项2（亚临界流）：
```
上游：Q_0 = Q_upstream
      ∂h/∂x = S0（均匀流假设，或特征线关系）
下游：h_n = h_downstream
```

选项3（混合）：
```
上游：Q_0 = Q_upstream
      动量方程（使用单向特征线）
下游：h_n = h_downstream
```

### 推荐解决方案

**方案A：直接指定上游水深**（最简单）
```python
def set_boundary_conditions(self, Q_upstream, h_upstream, h_downstream):
    # 上游：指定Q和h
    # F[0] = Q[0] - Q_upstream
    # F[1] = h[0] - h_upstream（替代连续性方程）
    # 下游：h_n = h_downstream
```

**方案B：使用特征线边界条件**（更物理）
```python
# 上游：Q指定，h通过特征线计算
# F[0] = Q[0] - Q_upstream
# F[1] = C+ 特征线方程（Riemann不变量）
```

**方案C：正规化方法**
```python
# 添加一个小的正规化项
# F[1] += epsilon * (h[0] - h_uniform)
# epsilon很小，不影响主要物理
```

- ✅ 修复了Jacobian缺少伪瞬态项的bug
- ✅ 识别了根本问题（上游边界条件不完整）

**教训1：理论 ≠ 实践**
- Anderson加速理论上优于Aitken
- 但实际测试反而更慢
- 结论：简单方法往往更可靠

**教训3：边界条件至关重要**

- 不完整的边界条件导致系统欠约束

**稳定性 vs 速度**：

- 结论：稳定性优先

**通用性 vs 专用性**：
