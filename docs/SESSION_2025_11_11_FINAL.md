## 六、破坏性变更总结

### v1.3.0破坏性变更

#### 1. 必需字段变更

**影响**: 所有API调用

**变更前(v1.2.0)**:
```json
{
  "name": "test"
  // width, length等字段可选，有默认值
}
```

**变更后(v1.3.0)**:
```json
{
  "name": "test",
  "config": {
    "width": 10.0,              // 现在必需
    "length": 1000.0,           // 现在必需
    "n_cells": 100,             // 现在必需
    "initial_conditions": {},   // 现在必需
    "boundary_conditions": {}   // 现在必需
  }
}
```

| 参数 | v1.2.0 | v1.3.0 | 原因 |
|------|--------|--------|------|
| `manning_n` 最小值 | 0.0 | 0.001 | 无摩擦不现实 |

#### 3. 跨字段验证

**新增**:
- CFL-order兼容性检查(order=2时CFL≤0.5)
