## 🚨 第五次失败：网格收敛性异常（最关键发现！）

### 测试结果

| 网格单元数 | dx (m) | 质量误差 | 误差比值 | 理论比值(一阶) |
|-----------|--------|---------|---------|---------------|
| 20        | 50.0   | 61.41%  | -       | -             |
| 40        | 25.0   | 65.39%  | 1.0648  | 0.5           |
| 80        | 12.5   | 67.26%  | 1.0286  | 0.5           |
| 160       | 6.25   | 68.15%  | 1.0133  | 0.5           |

### ⚠️ **异常现象**：

1. **误差单调递增**：61.41% → 65.39% → 67.26% → 68.15%
2. **误差比值>1**：应该≈0.5（一阶收敛），实际>1（发散！）
3. **改善为负**：从n=20到n=160，误差"改善"了-11%（实际恶化）

**这完全违反了数值方法的基本原理！**

### 💡 **关键洞察**：

```
正常数值方法：网格加密 → 误差减小
MacDonald问题：网格加密 → 误差增大！

结论：这不是数值精度问题，而是系统性/结构性错误！
```

## 💭 根本原因分析

### 已排除的原因

经过五次失败，可以**明确排除**：

1. ✗ **源项处理方法** - Interface和Strang都失败
2. ✗ **空间离散精度** - order=2失败
3. ✗ **空间离散格式** - Well-Balanced失败
4. ✗ **网格分辨率** - 加密反而恶化 ← 新发现！
5. ✓ Q边界本身 - 之前测试显示3%误差（可接受）
6. ✓ 时间积分 - TVD-RK2是标准方法

### 剩余可能原因（按可能性排序）

#### 1. **边界条件与内部格式的长时间耦合效应** ⭐⭐⭐ 最可能！

**假设**：Q边界本身没问题（短时间3%误差），但与内部有限体积法的长时间累积产生系统性质量泄漏

**证据**：
- 网格加密→误差增大：更细网格意味着更多时间步，累积更多边界误差
- 所有空间方法改进都失败：说明问题不在空间离散
- 质量误差随时间线性增长：典型的累积效应

**机制（推测）**：
```
每个时间步：
1. 左边界强制Q=2.0（ghost cell）
2. 有限体积法计算通量
3. 边界单元质量更新
4. 质量微小不匹配（~0.1%/步）
5. 长时间累积 → 61%误差

网格加密：
- 更多单元 → 更小时间步（CFL限制）
- 更多时间步 → 更多累积 → 更大误差
```

**为什么之前Q边界测试只有3%误差？**
- 那个测试只运行了短时间
- 或者测试的是瞬时误差，不是累积误差

#### 2. **质量守恒计算本身有bug** ⭐⭐

**假设**：`get_mass_conservation_error()`的计算可能不正确

**需要检查**：
```python
def get_mass_conservation_error(self):
    current_mass = np.sum(self.h * self.dx * self.B)
    error = (current_mass - self.initial_mass) / self.initial_mass * 100
    return abs(error)
```

可能的问题：
- 边界单元的质量是否正确计算？
- ghost cell的质量是否被意外包含？
- dx计算是否一致？

#### 3. **MacDonald问题设置不合理** ⭐

**假设**：这个问题本身可能不适合测试质量守恒

**MacDonald的特殊性**：
- 左边界固定Q=2.0
- 右边界临界水深h=0.7415m
- 非均匀初始条件（线性分布）
- 500s长时间积分

可能的问题：
- 边界条件不compatible（Q+h边界可能过约束）
- 没有稳态解（质量持续泄漏是物理的？）
- 初始条件不合理

#### 4. **有限体积法实现的根本错误** ⭐

**假设**：_compute_rhs或通量计算有bug

**需要检查**：
- 通量守恒性：F_{i+1/2}在相邻单元是否一致？
- 边界通量：左右边界通量是否正确？
- 源项积分：是否引入了质量？（应该只影响动量）

## 📚 文献对照

### Toro (2009) - 数值方法基础

**关于收敛性**：
> "For a consistent numerical method, the error should decrease as Δx^p where p is the order of accuracy."

**我们的结果**：
- 误差随Δx减小而**增大**
- 这违反了一致性（Consistency）要求
- 说明方法在MacDonald问题上**不一致**或**不稳定**

### Godunov方法的质量守恒性

**理论保证**：
> "Finite volume methods are conservative by construction, as long as interfacial fluxes are consistent."

**我们的问题**：
- 即使理论上守恒，实际误差61-68%
- 可能原因：
  1. 边界通量不守恒
  2. 源项引入了质量（bug）
  3. 边界条件处理破坏了守恒性
