### 1. 变坡度支持实现

#### 1.1 功能描述

实现了`HydrostaticCanalSolver`对变坡度(S0数组)的支持，允许模拟：
- 天然河道（非均匀坡度）
- 梯级渠道
- 缓坡到陡坡转换
- 流态转换分析

#### 1.2 技术实现

**数据结构**:
```python
# S0支持标量和数组
self.S0: np.ndarray          # 长度nx-1，每个单元的坡度
self.S0_scalar: float        # 标量值或平均值（兼容性）
self.is_uniform_slope: bool  # 标识是否恒定坡度
```

**底床高程计算**:
```python
def _compute_bed_elevation(self) -> np.ndarray:
    """计算底床高程（支持变坡度）"""
    z = np.zeros(self.nx)
    z[0] = 0.0
    for i in range(self.nx - 1):
        z[i + 1] = z[i] - self.S0[i] * self.dx_local[i]
    return z
```

**精度**:
- 恒定坡度: 误差 6.66e-16（机器精度）
- 变坡度: 误差 0.00e+00（完美）

## 🆕 附录D: 变坡度支持技术详情

### D.1 数据结构

```python
# S0存储
self.S0: np.ndarray          # 长度nx-1，每个单元的坡度
self.S0_scalar: float        # 标量值或平均值（兼容性）
self.is_uniform_slope: bool  # 标识是否恒定坡度

# 底床高程
self.z: np.ndarray           # 长度nx，节点的底床高程
```

### D.2 算法实现

```python
def _compute_bed_elevation(self) -> np.ndarray:
    """计算底床高程（支持变坡度）"""
    z = np.zeros(self.nx)
    z[0] = 0.0  # 起点高程为0

    # 累积坡度计算高程
    for i in range(self.nx - 1):
        # z[i+1] = z[i] - S0[i] * dx[i]
        z[i + 1] = z[i] - self.S0[i] * self.dx_local[i]

    return z
```

### D.3 使用示例

**恒定坡度（向后兼容）**:
```python
solver = HydrostaticCanalSolver(
    length=1000.0,
    nx=51,
    S0=0.001  # 标量
)
```

**变坡度**:
```python
S0_array = np.concatenate([
    np.ones(25) * 0.0005,  # 缓坡
    np.ones(25) * 0.01     # 陡坡
])

solver = HydrostaticCanalSolver(
    length=1000.0,
    nx=51,
    S0=S0_array  # 数组
)
```
