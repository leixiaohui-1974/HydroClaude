### 3.5 MacDonald Test 4: 水跃（已知限制）

**测试目的**: 验证水跃（hydraulic jump）模拟能力

**测试配置**:
```
渠道长度: 1,000 m
渠宽: 10.0 m
无摩阻 (n=0)
上游: 超临界流 (Fr>1)
下游: 亚临界流 (Fr<1)
```

**物理特征**:
- 强激波（水跃）
- 无物理耗散（n=0）
- 混合流态

**测试状态**: ⚠️ **已知限制**

**最优结果** (配置n150_cfl0.4):
```
质量守恒误差: 27.89%
负值水深单元: 12个
Froude数: 1.74 (理论1.73) ✅
Belanger误差: 0.87% ✅
```

**优化历史**:

1. **增强WENO3算法** (2025-10-30):
   - 实现5项改进（自适应epsilon、高阶平滑、熵修正等）
   - 结果: ❌ 数值爆炸（质量误差 4.6×10¹⁰%）
   - 根因: 算法-问题不匹配（设计用于光滑/细网格）
   - 决定: 放弃该方案
   - 文档: `WENO3_ENHANCEMENT_LESSONS_LEARNED.md`

2. **参数优化** (2025-10-30):
   - 系统化扫描4种配置（网格×CFL）
   - 最佳改善: 0.57% (28.46% → 27.89%)
   - 结论: 参数优化无效（<1%改善）
   - 决定: 接受27.89%为算法极限
   - 文档: `MACDONALD_TEST4_PARAMETER_OPTIMIZATION_SUMMARY.md`

**根本原因**:

WENO3+HLL组合对Test 4问题的固有限制：

| 因素 | 描述 | 影响 |
|------|------|------|
| 强激波 | 水深跃变约2倍 | 需要高阶激波捕捉 |
| 无摩阻 | n=0，无物理耗散 | 数值耗散主导 |
| 粗网格 | dx=10m（工程常用） | 激波分辨率不足 |
| 算法阶数 | WENO3 = 3阶 | 激波区降为1阶 |

**商业软件对比**:

商业软件（如HEC-RAS, MIKE）使用：
- 专用激波拟合方法
- Rankine-Hugoniot条件直接求解
- 自适应网格加密
- 数十年工程经验积累

**最终决定**:
- ✅ 接受27.89%为WENO3+HLL的算法极限
- ✅ 停止进一步优化
- ✅ 明确文档化限制
- ✅ 定位为学术/教学工具

   - 质量误差27.89%
   - 算法固有限制
   - 已充分文档化

2. **Well-Balanced特性**:
   - 当前求解器未实现Well-Balanced格式
   - Lake-at-Rest测试显示虚假流动（米级扰动）
   - 影响: 静水/缓流问题精度降低
   - 缓解: 对于MacDonald测试（有流动）影响较小

   - WENO3在激波处降为1阶

   - 影响: Test 4质量守恒较差
