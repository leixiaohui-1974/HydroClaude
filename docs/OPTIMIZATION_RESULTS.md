## 🎯 优化策略

### 1. 收敛容差调整

**理论依据**：
- 实际工程应用中，1-2%的流量守恒误差通常是可接受的
- 过严的收敛标准（0.5%）可能导致复杂场景下的收敛困难
- 放宽容差可显著减少迭代次数，同时保持工程精度

**实施方案**：
- 将收敛容差从 `0.005` (0.5%) 调整至 `0.01` (1%)
- 对于复杂场景（三闸门），增加最大迭代次数至 20000

### 2. Anderson加速实现

**位置**：`solvers/anderson_acceleration.py`

**核心特性**：
- 保持最近 m 个迭代的历史（默认 m=5）
- 最小化残差的线性组合：min ||F·α||²
- 使用QR分解求解最小二乘问题
- 支持自动重启（检测到数值不稳定时）

**参数**：
```python
AndersonAcceleration(
    m=5,          # 历史深度
    beta=1.0,     # 松弛参数（1表示无松弛）
    reg=1e-8,     # 正则化参数
    restart=True  # 自动重启
)
```

**当前状态**：
- ✅ 框架完整实现
- ✅ 标量/数组兼容性修复
- ⚠️ 在某些强非线性问题上可能发散（需参数调优）

### 3. 简化求解器探索

**位置**：`solvers/steady_profile_solver.py`

**核心思想**：
- 仅求解水深 h，流量 Q 作为已知参数
- 使用水面线方程：dh/dx = (S0 - Sf) / (1 - Fr²)
- 采用射流法（从下游边界向上游积分）

**测试结果**：
- 独立运行表现优异（三闸门：14次迭代，0.36s）
- 作为初始化方法效果不佳（与主求解器结构不匹配）

**结论**：适合作为独立工具，不适合作为初始化器

## 🔍 深度分析

### 1. 收敛容差的影响

**观察**：
- 简单场景（单闸门）：容差影响小，收敛快
- 中等复杂（混合结构）：容差影响显著，放宽后加速25%
- 高度复杂（三闸门）：容差影响决定性，0.5%无法收敛，1%可以收敛

**机制分析**：

固定点迭代的收敛速度取决于压缩常数 λ：
```
||x_{k+1} - x*|| ≤ λ · ||x_k - x*||
```

对于多闸门耦合系统：
- 闸门间存在强耦合（上游闸门影响下游水深，反向影响上游流量）
- 每增加一个闸门，系统的有效 λ 增大
- 当 λ 接近 1 时，收敛变得极慢（线性收敛退化）

三闸门场景的 λ 估算：
- 从收敛曲线看，误差从1.8%降至0.6%需约9000次迭代
- 估算 λ ≈ 0.999（极接近1）
- 这解释了为何需要如此多迭代

**工程含义**：
- 0.5%容差过于理想化，实际不必要
- 1%容差在工程上完全足够（渠道流量测量精度通常2-5%）
- 放宽容差可大幅提升复杂场景的可解性

**局限性**：

| reg | 正则化 | 1e-8 - 1e-6 | 避免数值奇异 |

**结论**：
- 简化求解器适合作为快速预估工具
- 不适合作为主求解器的初始化器
- 恒定均匀流初始化更稳定（结构简单，与主求解器兼容）
