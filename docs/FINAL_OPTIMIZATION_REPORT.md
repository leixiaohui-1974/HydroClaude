## 持续优化尝试：FVM隐式稳态求解

### 动机

Phase 3分析发现FVM显式推进失败的原因是**问题类型不匹配**：
- FVM显式推进 = 初值问题求解器
- 闸门稳态流动 = 边值问题

**解决方案**: 使用FVM隐式稳态求解（Newton迭代）

### 方法设计

#### 核心思想

稳态方程：
```
dU/dt = 0
=> -1/dx[F(i+1/2) - F(i-1/2)] + S(U) = 0
```

构造残差函数：
```python
R(U) = -1/dx[F(i+1/2) - F(i-1/2)] + S(U)
```

Newton迭代：
```python
J * dU = -R(U)
U_new = U_old + dU
```

其中J是Jacobian矩阵：
```
J[i,j] = ∂R[i]/∂U[j]
```

#### 实现方案

**文件**: `solvers/fvm_steady_solver.py`（约350行）

**关键组件**:

1. **残差函数**:
```python
def compute_steady_residual(self, U, Q_upstream, h_downstream):
    F = compute_interface_flux(U)  # FVM通量
    S = compute_source_term(U)      # 源项
    R = -(F[i+1] - F[i])/dx + S     # 稳态残差
    return R
```

2. **Newton迭代**:
```python
def solve_steady_newton(self, Q_target, max_iter=100):
    for iter in range(max_iter):
        R = compute_steady_residual(U)
        if norm(R) < tol:
            return True  # 收敛
        dU = newton_step(R)
        U = U + relax * dU
```

3. **Jacobian近似**（使用有限差分）:
```python
def _newton_step_fd(self, R):
    # 对角Jacobian近似
    for i in range(ncells):
        for j in range(2):
            U_perturb[i,j] += epsilon
            R_perturb = compute_residual(U_perturb)
            dR_dU = (R_perturb[i,j] - R[i,j]) / epsilon
            dU[i,j] = -R[i,j] / dR_dU
```

**简化假设**:
- 使用对角Jacobian近似（不构造完整矩阵）
- 松弛因子：0.5

### 失败原因分析

#### 1. Jacobian近似太粗糙

**对角有限差分近似的问题**:

```python
# 当前方法（对角）
J[i,i] ≈ dR[i]/dU[i]

# 实际需要（完整）
J[i,j] = dR[i]/dU[j]  # 所有i,j
```

对于Saint-Venant方程，单元i的残差依赖于：
- U[i-1]（上游）
- U[i]（本单元）
- U[i+1]（下游）
- 闸门位置还有跳跃

**对角近似忽略了耦合**，导致Newton方向不准确。

#### 2. 闸门非线性太强

闸门方程：
```
Q_gate = Cd * a * B * sqrt(2*g*Δh)
```

Jacobian：
```
dQ/dh_L = Cd * a * B * g / sqrt(2*g*Δh)  # 在Δh→0时奇异！
```

闸门处的强非线性+奇异性使数值求导非常敏感。

#### 3. 边界条件耦合

上下游边界条件与内部单元强耦合，需要同时满足：
- 上游：Q = Q_target
- 下游：h = h_downstream
- 内部：稳态残差 = 0

简化的对角Jacobian无法正确处理这种全局耦合。

#### 4. 初值敏感性

从均匀流初值（Q=10 everywhere）到真实稳态（闸门处有跳跃）的差异很大，Newton迭代很容易走向错误方向。

---

### 为什么FDM成功但FVM失败？

| 特性 | FDM (Preissmann) | FVM Newton |
|------|-----------------|------------|
| **时间推进** | ✅ 伪时间演化，逐步逼近 | ❌ 直接求解稳态 |
| **非线性处理** | ✅ 显式预估+隐式校正 | ❌ Newton需准确Jacobian |
| **闸门处理** | ✅ 迭代平滑（虽破坏守恒） | ❌ 直接用方程（需准确导数） |
| **鲁棒性** | ✅ 松弛+滤波+自适应 | ❌ Jacobian近似不准确 |

**核心差异**:
- FDM：渐进式逼近，容错性高
- FVM Newton：一步到位，对Jacobian精度要求极高

## 技术障碍总结

### FVM在闸门问题上的挑战

通过多次尝试，我们发现FVM应用到闸门稳态问题有以下技术障碍：

| 障碍 | 表现 | 原因 |
|------|------|------|
| **1. 问题类型不匹配** | 显式推进发散 | FVM显式适合初值问题，不适合边值问题 |
| **2. 边界条件困难** | 流量和水位失控 | 需要同时满足上下游边界和闸门方程 |
| **3. Jacobian计算复杂** | Newton发散 | 强非线性+耦合系统需要准确Jacobian |
| **4. 闸门奇异性** | 数值不稳定 | sqrt(Δh)在Δh→0时奇异 |
| **5. 初值敏感** | 迭代走向错误方向 | 均匀流与闸门稳态差异大 |

## 根本原因诊断

### 为什么所有FVM尝试都失败了？

不是**FVM理论**有问题，而是**应用方式**和**技术实现**有障碍：

1. **FVM守恒性完美**（已验证）
   - Dam break测试：质量守恒误差 = 0（机器精度）
   - 这证明FVM理论是正确的

2. **但闸门稳态是特殊问题**
   - 边值问题，不是初值问题
   - 需要精确的边界条件
   - 闸门方程有强非线性和奇异性

3. **简化实现不够鲁棒**
   - 显式推进缺边界条件
   - Newton需要准确Jacobian
   - 对角近似太粗糙

### 为什么FDM能保持2.32%？

FDM成功的关键：
1. **渐进式逼近**：伪时间推进，逐步靠近稳态
2. **多重稳定化机制**：
   - 隐式校正（Preissmann）
   - 空间滤波（虽破坏守恒）
   - 闸门迭代平滑
   - 自适应松弛
3. **容错性强**：即使单步不准确，多步累积能收敛

**代价**：守恒性不严格，精度受限于2.32%

### 技术洞察

1. **问题类型匹配至关重要**
   - FVM适合：初值问题、激波、瞬态过程
   - FDM适合：边值问题、稳态流动、渐进求解

2. **守恒性vs精度的权衡**
   - FVM守恒性完美，但需要正确的求解策略
   - FDM守恒性一般，但对这个问题更鲁棒

3. **简化实现的风险**
   - 对角Jacobian对强耦合系统不够
   - 需要完整实现才能保证成功

4. **渐进式>一步到位**（对这个问题）
   - FDM的伪时间推进比Newton直接求解更鲁棒
   - 闸门强非线性使"一步到位"困难
