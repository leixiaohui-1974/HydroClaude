## ✅ 完成的组件

### 1. 节点组件 (Junction)

**文件**: `physics/network/junction.py`

**类型**:
- `TeeJunction` - 三通节点
- `CrossJunction` - 四通节点
- `MultiWayJunction` - 多通节点

**功能**:
- 质量守恒: ∑Q_in = ∑Q_out
- 局部损失计算: h_loss = K × V²/(2g)
- 节点压力/水头计算

**测试结果**:
```
✓ 质量平衡残差 < 1e-6
✓ 局部损失系数经验值正确
✓ 压力更新功能正常
```

---

### 2. 弯头 (Elbow)

**文件**: `physics/network/elbow.py`

**功能**:
- 支持任意转角 (90°, 45°, ...)
- 曲率半径比 R/D (长半径/短半径/尖角)
- 损失系数自动计算: K = K_base × f(θ)

**经验系数**:
| R/D比值 | 基础损失K_base | 90°总损失K |
|---------|----------------|------------|
| ≥1.5 (长半径) | 0.2 | 0.15 |
| 1.0 (短半径) | 0.4 | 0.30 |
| <1.0 (尖角) | 1.0-1.5 | 1.13 |

**测试结果**:
```
✓ 导数精度 < 0.001%
✓ 损失与流速平方成正比 (h ∝ V²)
✓ 不同角度损失系数合理
```

---

### 3. 渐变管 (Reducer/Expander)

**文件**: `physics/network/reducer.py`

**类型**:
- `Reducer` - 渐缩管 (大→小)
- `Expander` - 渐扩管 (小→大)

**损失公式**:
- 渐缩: K = 0.5 × (1 - A₂/A₁)²
- 渐扩: K = (1 - A₁/A₂)² (Borda-Carnot)

**测试结果**:
```
D1=0.5m, D2=0.3m, V=3m/s:
  渐缩损失: 0.094m
  渐扩损失: 0.188m (约2倍)
✓ 渐扩损失大于渐缩（符合理论）
```

---

### 4. 气压罐 (AirVessel) ⭐

**文件**: `physics/network/air_vessel.py`

**功能**:
- 水锤防护核心设备
- 气液两相模型
- 多变过程: P × V^n = const

**动态方程**:
- 气体压缩: P = P₀ × (V₀/V)^n
- 流量计算: Q = A × √(2ΔP/ρ) × sign(ΔP)
- 阻尼系数: dV/dP = -V/(n×P)

**测试结果**:
```
初始: V=10m³, P=5bar, 水位=50%
压力升高→6bar: 流入0.444m³/s
更新后: P=5.59bar, 水位=54.4%
✓ 阻尼系数计算正确
```

---

### 5. 单向阀 (CheckValve)

**文件**: `physics/network/check_valve.py`

**功能**:
- 防止倒流
- 正向流动: K ≈ 3.0
- 反向流动: 完全关闭

**逻辑**:
```
if ΔP > 0:     打开，允许流动
elif ΔP < -P_closing:  关闭，阻止倒流
else:          保持当前状态
```

**测试结果**:
```
正向(ΔP=+100kPa): Q=1.026m³/s, 状态=OPEN
反向(ΔP=-100kPa): Q=0m³/s, 状态=CLOSED
✓ 防倒流功能正确
```

---

### 6. 安全阀 (ReliefValve)

**文件**: `physics/network/relief_valve.py`

**功能**:
- 超压保护
- 设定压力P_set
- 回差控制（防止频繁开关）

**工作特性**:
- P < P_set: 关闭
- P ≥ P_set: 开启泄压
- 泄压流量: Q = Cd × A × √(2ΔP/ρ)

**测试结果**:
```
P_set=6bar, 回差=5%
  P=5bar: 关闭, Q=0
  P=6.5bar: 开启, Q=0.169m³/s
  P=5.8bar: 保持开启（回差作用）
✓ 回差功能防止频繁开关
```


- 气压罐: 压力、水位
- 单向阀: 开/关状态
- 安全阀: 开/关状态 + 回差

## 📈 应用场景

### 1. 泵站管网系统

```
水源 → 泵 → 单向阀 → 管道 → 弯头 → 渐变管 → 用户
           ↓
        气压罐 (水锤防护)
           ↓
        安全阀 (超压保护)
```

### 2. 水电站引水系统

```
水库 → 进水口 → 引水隧洞 → 调压井 → 压力钢管 → 水轮机
                            ↑
                         气压罐
```

### 3. 城市供水管网

```
水厂 → 主管 → 三通 → 支管1
            ↓
         四通 → 支管2
            ↓
         单向阀 → 支管3
```
