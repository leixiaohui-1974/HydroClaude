## 🌟 技术亮点

### 1. **倒虹吸完整实现** ⭐ NEW

```python
# Swamee-Jain摩阻系数（自适应雷诺数）
f = 0.25 / [log₁₀(ε/(3.7D) + 5.74/Re^0.9)]²

# 总损失 = 进口 + 摩阻 + 出口
h_total = K_e×v²/(2g) + f×(L/D)×v²/(2g) + K_ex×v²/(2g)
```

**示例**（150m×Ø2m×2孔河流穿越）：
- 流量：17.61 m³/s @ 1m水头差
- 损失分解：进口20% + 摩阻40% + 出口40%
- 空化检查：无风险（裕度233kPa）✅

### 2. **调压井动力学** ⭐

```python
# Thoma公式（涌浪周期）
T = 2π√(L_tunnel × A_tank / (g × A_tunnel))

# 质量平衡
A × dZ/dt = Q_tunnel - Q_turbine
```

**实测**：5km隧洞 + Ø12m调压井 → T = 213秒 (3.5分钟) ✅

### 3. **PID抗饱和** ⭐

```python
if output > output_max:
    output = output_max
    if error > 0:  # 停止同向积分累积
        self.integral -= error * dt
```

防止积分项无限增长导致超调。

### 4. **瞬态仿真**（甩负荷）⭐⭐

```python
# 发电机转动方程
J × dω/dt = T_turbine - T_load - T_friction
```

## 📚 关键公式汇总

### 水力学

```python
# 溢洪道
Q = Cd × B × H^(3/2)
Q_submerged = Q_free × (1 - (h_down/H)^1.5)^0.385  # Villemonte

# 倒虹吸
h_total = K_e×v²/(2g) + f×(L/D)×v²/(2g) + K_ex×v²/(2g)
f = 0.25 / [log₁₀(ε/(3.7D) + 5.74/Re^0.9)]²  # Swamee-Jain

# 调压井
T = 2π√(L×A_tank/(g×A_tunnel))  # Thoma
A × dZ/dt = Q_in - Q_out

# 水轮机
P = η(Q,H,y) × ρ × g × Q × H
ns = n × √P / H^(5/4)  # 比转速 (P单位: kW)
```

### 控制理论

```python
# PID控制
u(t) = Kp×e + Ki×∫e dt + Kd×de/dt

# 永态调差
bp = 1 / Kp

# 伺服响应
dy/dt = (y_cmd - y) / T_servo
```

### 机电动力学

```python
# 发电机
J × dω/dt = T_turbine - T_load - T_friction
J = GD² / 4

# 转矩-功率
T = P / ω,  ω = 2πn/60
```
