## 技术实施细节

### WENO3方法

**原理**:
```python
# 2个stencil重构
phi^(1) = 3/2*phi_i - 1/2*phi_{i-1}  # 左偏
phi^(2) = 1/2*phi_i + 1/2*phi_{i+1}  # 右偏

# 光滑性指标
beta_1 = (phi_i - phi_{i-1})^2
beta_2 = (phi_{i+1} - phi_i)^2

# 非线性权重
alpha_k = d_k / (epsilon + beta_k)^2
omega_k = alpha_k / sum(alpha_k)

# WENO重构
phi_{i+1/2} = omega_1*phi^(1) + omega_2*phi^(2)
```

**特性**:
- 3阶空间精度（vs 1阶Godunov）
- 自动识别间断（激波）
- 无振荡（ENO性质）
- 适合激波捕捉

**应用于Test 4**:
- 水跃是强激波（h从0.7m跃升到2.8m）
- 需要高精度+激波捕捉
- WENO3是标准解决方案

### Well-Balanced方法

**问题**: Lake at Rest测试失败（变底高程3.99m扰动）

**解决方案**: Hydrostatic Reconstruction (Audusse 2004)

```python
# 1. 界面高程重构
h_L_star = h_L + z_L - z_interface
h_R_star = h_R + z_R - z_interface

# 2. 修正通量计算
F_hydrostatic = F_godunov(h_L_star, h_R_star, ...)

# 3. 源项平衡
S_hydrostatic = 0.5 * g * (h_L^2 - h_R^2)
```

**期望效果**:
- Lake at Rest扰动 < 1e-12（机器精度）
- 小扰动传播正确
- 质量守恒改善
