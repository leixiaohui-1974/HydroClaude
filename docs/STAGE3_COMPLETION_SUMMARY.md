## 🔬 技术特性

### 1. 拓扑管理

- **DFS拓扑排序**: O(V+E)复杂度
- **循环检测**: 实时检测网络中的环路
- **邻接表表示**: 高效的图数据结构

### 2. 节点类型

| 节点类型 | 功能 | 应用 |
|----------|------|------|
| BoundaryNode | 边界条件 | 入口/出口 |
| JunctionNode | 汇流计算 | Y型汇流 |
| BifurcationNode | 分流计算 | T型分流 |
| ReservoirNode | 库容计算 | 水库/湖泊 |

### 3. 耦合方法

```python
# 串联耦合
upstream.bc_right = downstream.bc_left

# 汇流耦合
ΣQ_in = ΣQ_out
E_junction = mean(E_upstream)

# 分流耦合
Q_out_i = Q_in * ratio_i
```

### 4. 求解模式

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| Sequential | 单次遍历 | 简单串联 |
| Iterative | 迭代收敛 | 复杂汇流 |

### 5. 质量守恒

- **节点级**: 每个节点ΣQ_in = ΣQ_out
- **全局级**: 系统总入流 = 总出流
- **历史记录**: 实时跟踪误差演化
