### 1.3 Test 4 详细分析

**问题配置**:
```
渠道长度: 1,000 m
渠宽: 10.0 m
底坡: 0.0 (水平)
Manning系数: 0.0 (无摩阻)
上游: 超临界流 (Fr = 1.73)
下游: 亚临界流
物理现象: 水跃（强激波）
```

**最优结果** (n150_cfl0.4):
```
质量守恒误差: 27.89% ⚠️
负值水深单元: 12个
Froude数: 1.74 (理论1.73) ✅
Belanger误差: 0.87% ✅
状态: 数值稳定，但质量守恒较差
```

**根本原因**:
1. **强激波** - 水深跃变约2倍
2. **无物理耗散** - n=0，数值耗散主导
3. **粗网格** - dx=10m，激波分辨率不足
4. **算法阶数** - WENO3在激波处降为1阶

## 2. 优化历程

### 2.1 尝试1: 增强WENO3算法 (2025-10-30早期)

**目标**: 通过算法改进突破Test 4限制

**实施**:
- 创建 `godunov_fvm_weno3_enhanced.py` (634行)
- 实现5项改进:
  1. 自适应epsilon (Henrick et al. 2005)
  2. 高阶平滑指标 (Jiang-Shu 1996)
  3. 熵修正 (Harten-Hyman 1983)
  4. 自适应CFL
  5. 改进边界条件

**结果**: ❌ **失败 - 数值爆炸**

```
标准WENO3:   28.46% 质量误差 ✅ 稳定
增强WENO3 v1: 4.6×10¹⁰% 质量误差 ❌ 爆炸
增强WENO3 v2: 2.3×10⁹% 质量误差 ❌ 仍不稳定
```

**根因分析**:
1. **自适应epsilon正反馈** - phi_max爆炸时epsilon也爆炸
2. **高阶项过放大** - dx²=100 (10m网格)，过度惩罚梯度
3. **算法-问题不匹配** - 设计用于光滑流动/细网格

**关键教训**: **稳定性 > 理论优雅性**

**文档**: `WENO3_ENHANCEMENT_LESSONS_LEARNED.md` (7.4KB)

## 3. 算法限制分析

### 3.1 WENO3+HLL组合的适用边界

| 问题特征 | WENO3+HLL表现 | Test 4情况 | 匹配度 |
|----------|--------------|-----------|--------|
| 激波强度 | 适合中等 | 非常强（2倍跃变） | ❌ 不匹配 |
| 物理耗散 | 需要一定耗散 | n=0（无耗散） | ❌ 不匹配 |
| 网格分辨率 | 细网格更好 | dx=10m（粗） | ❌ 不匹配 |
| 流动类型 | 光滑/中等间断 | 强间断 | ❌ 不匹配 |

**结论**: Test 4的4个关键特征全部与WENO3+HLL的最佳适用范围不匹配

### 3.2 商业软件的优势

**商业软件方法** (HEC-RAS, MIKE等):

1. **专用激波拟合**:
   - 直接应用Rankine-Hugoniot条件
   - 水跃作为特殊处理对象
   - 不依赖通用数值格式

2. **自适应网格**:
   - 激波区自动加密至cm级
   - 远场保持粗网格
   - 动态AMR技术

3. **工程经验**:
   - 数十年实际项目积累
   - 大量人力资源投入
   - 持续迭代优化

**HydroClaude定位**: 通用学术算法，而非专用工程工具

### 3.3 可能的改进方向

**短期（现实可行）**:
1. ❌ 参数优化 - 已证实无效
2. ❌ 增强WENO3 - 已证实失败

**中期（需要工作量）**:
1. ✅ WENO5/WENO7 - 更高阶精度

**长期（研究级）**:

### 6.2 代码示例

**基本使用**:
```python
from solvers.godunov_fvm_weno3 import GodunvFVMWENO3
import numpy as np

# 创建求解器
solver = GodunvFVMWENO3(
    dx=10.0,          # 网格间距 (m)
    B=10.0,           # 渠宽 (m)
    S0=0.001,         # 底坡
    n_manning=0.025,  # Manning系数
    spatial_order=3,  # WENO3
    cfl=0.5          # CFL数
)

# 设置初始条件
n_cells = 100
h = np.ones(n_cells) * 2.0  # 初始水深 2m
Q = np.ones(n_cells) * 20.0  # 初始流量 20m³/s

# 时间步进
dt = solver.compute_dt(h, Q)
h_new, Q_new = solver.step(h, Q, dt)
```

**质量验证**:
```python
# 计算质量误差
mass_initial = np.sum(h * solver.B * solver.dx)
mass_current = np.sum(h_new * solver.B * solver.dx)
mass_error = abs(mass_current - mass_initial) / mass_initial * 100

print(f"质量误差: {mass_error:.2f}%")

# ✅ Tests 1-3, 5: 预期 <10%
# ⚠️ Test 4: 预期 ~28%
```
