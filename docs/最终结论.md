# 闸门精度优化项目 - 最终结论

**日期**: 2025-10-23
**状态**: Phase 1-3 全部完成
**最终精度**: 2.32%（未达到0.5%目标）

---

## 一、项目回顾

### 目标
将三闸门系统的流量误差从初始2.56%降低到0.5%

### 三个阶段的尝试

| 阶段 | 方法 | 结果 | 精度 |
|-----|------|-----|------|
| **Phase 1** | 自适应smooth_weight参数优化 | ❌ 未改善 | 2.64-7.04% |
| **Phase 2** | 局部网格加密 | ❌ 严重恶化 | 88-176% |
| **Phase 3** | 有限体积法(FVM)算法升级 | ❌ 完全失败 | 545-8928% |

---

## 二、最终结果

### 最佳配置（来自Phase 1）

```python
method = 'preissmann'     # Preissmann四点隐格式
smooth_weight = 0.55      # 最优平滑权重
nx = 301                   # 网格点数
dx = 33.33m               # 均匀网格间距
```

**最终精度**: **2.32%** 最大流量误差

**与目标差距**: 1.82%（需要再提升4.6倍才能达到0.5%）

## 三、为什么所有优化都失败了？

### Phase 1失败原因：参数已达极限

- 固定smooth_weight=0.55已经是全局最优
- 自适应调整反而破坏了这个平衡点
- **结论**: 参数调优不是精度瓶颈

### Phase 2失败原因：网格细化触发数值不稳定

| 网格间距 | 误差 | 说明 |
|---------|------|------|
| dx=33.33m (301点) | 2.32% | ✓ 最佳 |
| dx=16.67m (601点) | 88.04% | ✗ 崩溃 |
| dx=8.33m (1201点) | 107.12% | ✗ 严重崩溃 |

- 任何smooth_weight都无法挽救细网格的失败
- **结论**: Preissmann差分格式在细网格上固有不稳定
- dx=33.33m是当前方法的"最佳工作点"

### Phase 3失败原因：FVM对本问题不适用

经过4次完整的FVM实施尝试，所有方法都失败：

| 尝试 | 方法 | 误差 | 问题 |
|-----|------|------|------|
| 1 | FVM显式时间步进 | 8,928% | 问题类型不匹配(IVP vs BVP) |
| 2 | FVM-FDM混合 | 35,000% | 数值爆炸，出现负流量 |
| 3 | FVM隐式(对角Jacobian) | 1.85×10¹¹% | 近似太粗糙，完全发散 |
| 4 | **FVM隐式(完整Jacobian)** | **545.79%** | **Newton迭代不收敛，负流量** |

#### 尝试4的详细失败（最终尝试）

**实施**:
- 完整Jacobian矩阵（600×600维）
- 稀疏矩阵存储和求解
- 回溯线搜索（Armijo条件）
- 使用FDM最优解作为初值
- 求解时间：148秒

**结果**:
```
迭代0:  残差=107.6, Q_avg=10.004 m³/s, 误差=0.04%  (初值很好！)
迭代20: 残差=29.2,  Q_avg=9.880 m³/s,  误差=1.20%  (开始恶化)
迭代45: 残差=3.9,   Q_avg=9.373 m³/s,  误差=6.27%  (明显恶化)
迭代50: 残差=2.8,   Q_avg=9.202 m³/s,  误差=7.98%  (未收敛)

最终: 闸门流量 = [-22.2, -22.3, -21.9] m³/s  ← 负值！完全失去物理意义
      最大误差 = 545.79%
```

**失败原因**:
1. **闸门流量公式的强非线性**: Q = Cd×a×B×√(2g×Δh)
   - sqrt项在间断处导数奇异
   - 有限差分计算Jacobian不准确

2. **公式切换导致不可微性**:
   - 淹没出流 vs 自由出流在h=a处切换
   - Jacobian在切换点不连续

3. **多闸门强耦合导致病态**:
   - 3个闸门相互影响
   - Jacobian条件数极大
   - Newton方向不可靠

4. **线搜索失败**:
   - 步长不断减小(0.25→0.001)表明找不到下降方向
   - 最后出现负流量说明数值解崩溃

## 四、核心结论

### 精度瓶颈的根本原因

**不是参数问题** ✗
**不是网格问题** ✗
**不是算法问题** ✗

**是问题本身的数学特性** ✓

三闸门稳态流动问题具有：
1. **强间断**: 3个人工设置的内部边界
2. **强非线性**: 闸门公式的sqrt和if-else切换
3. **强耦合**: 三个闸门通过水深相互影响
4. **刚性**: 稳态边值问题，不是自然演化问题

这些特性使得：
- FDM参数优化和网格加密失效
- FVM的理论优势（守恒性、间断捕捉）无法发挥
- 通用CFD方法都遇到困难

### FDM的"意外优势"

FDM虽然理论上守恒性较差，但实际表现最好：

```
FDM (Preissmann + smooth_weight=0.55):  2.32%  ← 最佳
FVM (所有4次尝试):                    >500%   ← 全部失败
```

**原因**:
- Preissmann的"平滑"抑制了振荡
- smooth_weight的人工修正稳定了闸门处的间断
- dx=33.33m避开了刚性区域
- 这些是"工程经验调优"的结果，不是理论推导

**FVM丢失了这些"意外的稳定机制"**，虽然理论更"正确"，但数值上更脆弱。
