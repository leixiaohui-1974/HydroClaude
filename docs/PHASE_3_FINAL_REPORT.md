## Phase 1: 自适应Smooth Weight

### 方法

通过自适应调整闸门附近的平滑权重来减少守恒性破坏：

```python
smooth_weight = f(residual, distance, ...)
```

测试了5种配置：
1. **固定权重**（基准）: smooth_weight = 0.55
2. **残差自适应**: 基于流量残差动态调整
3. **距离自适应**: 基于距闸门距离调整
4. **混合模式**: 残差+距离组合
5. **激进/保守模式**: 不同参数组合

### 结果

| 配置 | 最大误差 | 改善 |
|------|---------|------|
| 固定0.55（基准） | **2.32%** | - |
| 残差自适应 | 2.64% | ❌ -13.8% |
| 距离自适应 | 3.12% | ❌ -34.5% |
| 混合模式 | 2.85% | ❌ -22.8% |
| 激进模式 | 7.04% | ❌ -203% |

### 结论

✅ **发现最优固定值**: smooth_weight = 0.55
❌ **自适应未改善**: 所有自适应策略都劣于固定值
💡 **洞察**: 空间变化的平滑不是精度瓶颈

### 3.2 核心组件实现（✅ 完成）

#### A. Riemann求解器

**文件**: `solvers/riemann_solvers.py`（244行）

实现了3种求解器：

**1. HLL求解器**（最常用）
```python
def hll_flux_shallow_water(U_L, U_R, B, g):
    """
    HLL Riemann求解器
    - 两波近似：s_L, s_R
    - 使用Roe平均估计波速
    - 公式: F = (s_R*F_L - s_L*F_R + s_L*s_R*(U_R - U_L)) / (s_R - s_L)
    """
    # Roe平均
    h_roe = (sqrt_h_L * h_L + sqrt_h_R * h_R) / (sqrt_h_L + sqrt_h_R)
    u_roe = (sqrt_h_L * u_L + sqrt_h_R * u_R) / (sqrt_h_L + sqrt_h_R)
    c_roe = sqrt(g * h_roe)

    # 波速
    s_L = min(u_L - c_L, u_roe - c_roe)
    s_R = max(u_R + c_R, u_roe + c_roe)

    # HLL通量
    return (s_R * F_L - s_L * F_R + s_L * s_R * (U_R - U_L)) / (s_R - s_L)
```

**2. HLLC求解器**（更精确）
- 三波近似（包含接触间断）
- 计算中间波速s_star
- 适用于需要更高精度的情况

**3. Rusanov求解器**（最稳定）
- 局部Lax-Friedrichs格式
- 最大耗散，最鲁棒
- 适用于强间断问题

**测试结果**: ✅ 所有求解器通过dam break验证

#### C. FVMSolver核心类

**文件**: `solvers/fvm_solver.py`（465行）

完整的FVM求解器：

```python
class FVMSolver:
    """
    严格守恒的有限体积法求解器

    核心方法：
    - reconstruct_interface_values(): MUSCL二阶重构
    - compute_interface_flux(): Riemann求解器
    - compute_source_term(): Manning摩阻
    - step_ssp_rk2(): 二阶时间积分
    """

    def step_ssp_rk2(self, dt):
        """SSP-RK2时间积分"""
        # Stage 1
        dU_dt_1 = self.compute_rhs(U_n)
        U_star = U_n + dt * dU_dt_1

        # Stage 2
        dU_dt_2 = self.compute_rhs(U_star)
        U_new = 0.5 * U_n + 0.5 * (U_star + dt * dU_dt_2)
```

**特性**:
- Godunov一阶 / MUSCL二阶可选
- 3种Riemann求解器可选
- 4种slope限制器可选
- 自适应CFL时间步长
- 闸门内部边界条件支持

### 3.4 闸门集成（❌ 遇到挑战）

#### 尝试1: 纯FVM闸门测试

**文件**: `test_fvm_with_gate.py`

**配置**:
- 单闸门，1000m渠道
- 目标流量: 10 m³/s

**结果**:
```
❌ 严重失败
  流量误差: 8928%
  上游流量: 902 m³/s（目标10）
  上游水深: 13.3m（初始0.87m）
```

**原因分析**:

| 特性 | FVM显式推进 | 闸门稳态问题 | 匹配 |
|------|------------|-------------|------|
| 问题类型 | 初值问题(IVP) | 边值问题(BVP) | ❌ |
| 边界条件 | 自由演化 | 需固定边界 | ❌ |
| 求解方式 | 时间推进 | 稳态迭代 | ❌ |

**核心洞察**:
> **问题类型不匹配**是失败的根本原因，而非FVM本身有问题！

FVM显式推进适合：
- ✅ 溃坝问题（初值→瞬态演化）
- ✅ 激波传播
- ✅ 时变过程

但不适合：
- ❌ 稳态流动（需要边界条件）
- ❌ 边值问题

#### 尝试2: FVM-FDM混合求解器

**文件**: `solvers/canal_solver_improved.py`

**思路**:
- 将FVM守恒思想融入FDM框架
- 使用严格的通量守恒格式
- 闸门处使用精确闸门通量方程
- 移除破坏守恒性的空间滤波

**核心改进**:
```python
class CanalSolverImproved(CanalSolver):
    """
    改进的求解器

    核心改进：
    1. 严格通量守恒：dU/dt = -1/dx[F(i+1/2) - F(i-1/2)] + S
    2. 闸门通量方程：Q = Cd * a * B * sqrt(2*g*Δh)
    3. 禁用空间滤波（保持守恒）
    """

    def step_fvm_conservative(self, dt, Q_upstream, h_downstream):
        # 计算所有界面通量
        for i in range(1, self.nx):
            if is_gate_interface:
                F[i] = compute_gate_flux(...)  # 精确闸门方程
            else:
                F[i] = hll_flux(U_L, U_R)  # Riemann求解器

        # 严格通量差分
        dU/dt = -(F[i+1] - F[i]) / dx + S
```

**测试结果**:
```
❌ 数值不稳定
  流量: -3000 m³/s（负值！）
  误差: 35000%
  水深: 20m爆炸
```

**诊断**:
- 通量计算或边界条件有严重bug
- 可能是dx_local访问问题
- 或闸门通量实现不正确

**对比测试**:
- ✅ 原始FDM: 2.32%误差，稳定收敛
- ❌ FVM-FDM: 数值爆炸

### 原因分析

1. **FVM应用方式选择不当**:
   - 使用了显式时间推进（适合初值问题）
   - 应该使用隐式稳态求解（适合边值问题）

2. **时间约束**:
   - FVM隐式稳态求解需要额外2-3天
   - FVM-FDM混合方案遇到实现细节bug

3. **技术复杂度**:
   - Well-balanced性质需要特殊处理
   - 闸门边界条件与FVM集成有挑战
