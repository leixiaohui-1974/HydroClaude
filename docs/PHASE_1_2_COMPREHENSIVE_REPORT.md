## Phase 1: 自适应Smooth_Weight

### 1.1 设计与实现

#### 理论基础

当前固定smooth_weight=0.55的问题：
- 在高残差区域（闸门附近）可能需要更多平滑
- 在低残差区域（远离闸门）过度平滑破坏守恒性

**自适应策略**：
```python
smooth_weight(x, t) = f(local_residual, distance_to_gate)
```

#### 实现的模式

1. **Fixed模式**: 固定权重（向后兼容）
2. **Residual模式**: 基于局部残差自适应
3. **Distance模式**: 基于到闸门距离自适应
4. **Hybrid模式**: 残差+距离的加权组合

#### 代码修改

**新增文件**:
- `solvers/adaptive_smooth_config.py` - 配置类
- `docs/ADAPTIVE_SMOOTH_WEIGHT_DESIGN.md` - 设计文档

**修改文件**:
- `solvers/canal_solver.py`:
  - 添加`adaptive_smooth_config`参数
  - 实现`_compute_adaptive_smooth_weight()`方法
  - 修改`_apply_internal_bc()`使用自适应权重

- `solvers/single_canal_solver.py`:
  - 添加`adaptive_smooth_config`参数传递

**为什么失败？**

2. 对于这个问题，空间变化的平滑权重不是主要限制因素
3. 精度瓶颈在其他地方（数值格式）

**有价值的阴性结果**:
- 验证了固定值0.55的最优性

- dx=33.33m是当前数值格式的"甜点"
- 更细的网格触发了数值不稳定
- **需要更鲁棒的数值方法**

## 综合分析

### 精度瓶颈的真正原因

通过两个Phase的系统性测试，我们发现：

1. ❌ **不是平滑权重** - Phase 1证明0.55已经最优
2. ❌ **不是网格分辨率** - Phase 2证明细网格反而更差
3. ✅ **是数值格式** - 当前差分格式的固有限制

### 当前方法的极限

**Preissmann四点隐式格式 + smooth_weight优化**:
- 最佳配置: nx=301, dx=33.33m, smooth_weight=0.55
- 极限精度: **2.32%最大误差**
- 距离0.5%目标: **4.6x**

### 为什么Phase 1和Phase 2都失败了？

#### 数学本质

当前方法是**有限差分法(FDM)**:
```
∂Q/∂t ≈ (Q^(n+1) - Q^n) / dt
∂Q/∂x ≈ (Q_(i+1) - Q_(i-1)) / (2*dx)
```

**固有问题**:
1. **守恒性不严格**: 差分格式不保证离散守恒
2. **截断误差**: O(dx²)的空间精度
3. **闸门处间断**: 差分法处理间断性能差

#### 为什么网格细化失败？

**理论预期**: 更细网格 → 更小截断误差 → 更高精度

**实际结果**: 更细网格 → 数值不稳定 → 精度崩溃

**原因**:
1. **平滑机制失效**: smooth_weight设计用于粗网格
2. **间断处理失败**: 细网格暴露了闸门间断处理的缺陷
3. **累积误差放大**: 更多网格点 → 更多误差源

## Phase 3 必要性

### 为什么必须实现有限体积法？

**有限体积法(FVM)的优势**:

1. **严格守恒**:
   ```
   ∫_V ∂Q/∂t dV + ∫_∂V F·n dS = 0
   ```
   积分形式自动满足守恒

2. **间断处理**: Riemann求解器专门设计处理间断

3. **单调性**: TVD/ENO/WENO格式保证单调性

4. **稳定性**: 更鲁棒的稳定性条件

### 预期效果

基于文献和理论分析：

| 方法 | 当前 | 预期 |
|------|------|------|
| FDM (当前) | 2.32% | - |

| FVM (MUSCL-2) | - | 0.2-0.5% |
