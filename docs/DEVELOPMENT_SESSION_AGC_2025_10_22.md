##### (1) 一次调频 (Primary Frequency Control)
```python
class PrimaryFrequencyControl:
    """
    通过调速器永态调差实现自动频率响应

    原理: ΔP = -K_droop × Δf
    其中: K_droop = P_rated / (droop × f_rated)
    """
    def calculate_power_adjustment(self, frequency_deviation):
        delta_P = -self.K_droop * frequency_deviation
        return delta_P
```

**关键特性**:
- 调差系数：通常4% (2 Hz频差对应满负荷变化)
- 响应时间：秒级 (通过调速器机械响应)
- 控制原理：频率高→减出力，频率低→增出力

**测试验证**:
- ✅ 频率下降0.5 Hz → 增加25 MW (100 MW机组)
- ✅ 4%调差：2 Hz偏差对应100%功率变化

##### (2) 二次调频 (Secondary Frequency Control - AGC)
```python
class SecondaryFrequencyControl:
    """
    通过PI控制器消除稳态频率误差

    ACE = ΔP_tie + 10β×Δf
    u_AGC = Kp×ACE + Ki×∫ACE dt
    """
    def calculate_ace(self, frequency, tie_line_flow):
        delta_f = frequency - self.params.rated_frequency
        delta_P_tie = tie_line_flow - self.params.tie_line_scheduled
        ace = delta_P_tie + 10.0 * self.params.frequency_bias_factor * delta_f
        return ace
```

**关键特性**:
- ACE计算：区域控制偏差 = 联络线偏差 + 频率偏差贡献
- PI控制：比例项快速响应，积分项消除稳态误差
- 保护机制：
  - 死区 (0.5-1.0 MW) - 避免频繁调节
  - 速率限制 (5-10 MW/s) - 平滑控制动作
  - 抗饱和 - 防止积分项累积

**测试验证**:
- ✅ ACE计算精度：频率+联络线偏差正确组合
- ✅ PI控制：比例动作立即响应，积分动作累积修正
- ✅ 死区功能：小偏差不动作
- ✅ 速率限制：每秒最多变化10 MW

```
发电量 = 本地负荷 + 联络线出口

**ACE变化**:
```
ACE = ΔP_tie + 10β×Δf

t<30s: ACE = (0 - 0) + 0 = 0 MW
t=30s: ACE突变 = (0 - 50) = -50 MW (需增加发电)
t→∞:  ACE → 0 (AGC消除偏差)

## 💡 技术亮点

### 1. 多层次频率控制

```
层次1: 经济调度 (Economic Dispatch)
  └─ 目标: 负荷优化分配，效率最高
  └─ 时间尺度: 准稳态 (分钟-小时)
  └─ 方法: 等微增率准则

层次2: 一次调频 (Primary Control)
  └─ 目标: 稳定频率，防止频率崩溃
  └─ 时间尺度: 秒级 (0-30秒)
  └─ 方法: 调速器永态调差

层次3: 二次调频 (Secondary Control - AGC)
  └─ 目标: 消除频率偏差，恢复计划
  └─ 时间尺度: 分钟级 (30秒-5分钟)
  └─ 方法: PI控制ACE
```

### 2. ACE计算的物理意义

**公式**: `ACE = ΔP_tie + 10β×Δf`

**物理解释**:
- **ΔP_tie**: 联络线功率偏差
  - 正值：实际出口 > 计划 → 应减少发电
  - 负值：实际出口 < 计划 → 应增加发电

- **10β×Δf**: 本地区对系统频率的贡献
  - β: 频率偏差系数 (MW/0.1Hz)
  - Δf: 频率偏差 (Hz)
  - 10倍系数：将β从MW/0.1Hz转换为MW/Hz

**控制目标**: ACE = 0
- 联络线功率满足计划 ✅
- 本地区不产生频率偏差 ✅

### 3. 等微增率法的水电应用

**经典电力系统**:
```
火电: λ = dC/dP = a + b×P + c×P²
      (燃料成本函数求导)

多机组优化: λ₁ = λ₂ = ... = λₙ
           (所有机组边际成本相等)
```

**水电简化**:
```
水电: 无燃料成本，主要考虑效率
      效率曲线相似时 → 等容量因子近似最优

等容量因子: P₁/P₁,rated = P₂/P₂,rated = ...
           (所有机组工作在相同容量因子)
```

**本项目实现**:
- 按容量比例分配负荷
- 承诺机组保持相等容量因子
- 兼顾效率和简单性

### 4. 机组启停智能决策

**决策逻辑**:
```python
# 1. 计算最小稳定总出力
min_power = n_units × min_load_fraction × unit_capacity

# 2. 判断是否需要减少承诺机组
if demand < min_power:
    # 关停部分机组
    committed_units = select_large_units_first()

# 3. 负荷分配
for unit in committed_units:
    power[unit] = demand × (capacity[unit] / total_capacity)
```

**策略优势**:
- 大机组优先：部分负荷效率更高
- 最小化机组数：减少辅机功耗
- 满足最小稳定负荷：防止振动和效率低下

## 🔬 核心算法详解

### 算法1：ACE-PI控制器

```python
def compute_agc_control(frequency, tie_line, current_time):
    """
    AGC PI控制器实现
    """
    # Step 1: Calculate ACE
    delta_f = frequency - f_rated
    delta_P_tie = tie_line_actual - tie_line_scheduled
    ace = delta_P_tie + 10 * beta * delta_f

    # Step 2: Apply deadband
    if abs(ace) < ace_deadband:
        ace_active = 0
    else:
        ace_active = ace

    # Step 3: PI control
    dt = current_time - prev_time

    P = Kp * ace_active
    integral += ace_active * dt
    I = Ki * integral

    output = P + I

    # Step 4: Rate limiter
    max_change = max_rate * dt
    if abs(output - prev_output) > max_change:
        output = prev_output + sign(output - prev_output) * max_change

    return output, ace
```

**参数整定建议**:
- **Kp**: 30-50 (快速响应)
- **Ki**: 5-10 (积分强度适中)
- **Deadband**: 0.5-1.0 MW (避免频繁动作)
- **Rate**: 5-10 MW/s (平滑调节)

### 算法2：等微增率负荷分配

```python
def allocate_load_equal_incremental(total_demand, units):
    """
    等微增率法负荷分配（水电简化版）
    """
    # Step 1: Select committed units
    if demand < sum(min_load):
        # Need to turn off some units
        units = select_units_by_size(demand)

    # Step 2: Proportional allocation
    total_capacity = sum(capacity[u] for u in units)

    for u in units:
        fraction = capacity[u] / total_capacity
        power[u] = total_demand * fraction

        # Enforce limits
        power[u] = clip(power[u],
                       capacity[u] * min_fraction,
                       capacity[u] * max_fraction)

    return power
```

**适用条件**:
- 相似效率曲线
- 水头变化不大
- 简化计算，工程实用

## 📚 关键公式汇总

### 频率控制

```python
# 一次调频
ΔP = -K_droop × Δf
K_droop = P_rated / (droop × f_rated)

# 典型值
droop = 0.04 (4%)
f_rated = 50 Hz
→ 2 Hz偏差对应100%功率变化

# 二次调频 (AGC)
ACE = ΔP_tie + 10β×Δf

AGC输出:
u(t) = Kp×ACE + Ki×∫ACE dt

# 参数整定
Kp = 30-50 (快速响应)
Ki = 5-10 (积分适中)
```

### 多机组协调

```python
# 等微增率准则
λ₁ = λ₂ = ... = λₙ
其中: λᵢ = ∂Cᵢ/∂Pᵢ (边际成本)

# 水电简化 (等容量因子)
P₁/P₁,max = P₂/P₂,max = ... = Pₙ/Pₙ,max

# 负荷分配
Pᵢ = P_total × (Pᵢ,max / ∑Pⱼ,max)

# 约束
Pᵢ,min ≤ Pᵢ ≤ Pᵢ,max
∑Pᵢ = P_total
```

### CPS1/CPS2标准

```python
# CPS1 (Control Performance Standard 1)
CPS1 = (2 - CF) × 100%
CF = avg(ACE × Δf) / (10 × ε₁²)
要求: CPS1 ≥ 100%

# CPS2
CPS2 = (未超出限值的10分钟数 / 总10分钟数) × 100%
限值: |ACE| < L₁₀
要求: CPS2 ≥ 90%
```
