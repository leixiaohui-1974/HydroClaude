## 🔍 问题诊断

### 根本原因分析

所有涉及**干床/湿干界面**的测试都遇到**时间步长崩溃**问题：

**可能的代码问题**:

1. **CFL计算在干床处不合理**:
```python
# 当 h→0 时:
c = sqrt(g*h) → 0
u = Q/(B*h) → ∞（如果Q≠0）

# 可能导致:
dt = CFL * dx / max(|u|+c) → 0
```

2. **湿干界面检测过于敏感**:
```python
# Phase 8.2的界面检测:
if h < wet_dry_threshold:  # threshold = 1e-4
    # 触发特殊通量，可能过于保守
```

3. **正定性保持限制系数θ过小**:
```python
# 如果θ→0，完全退化为一阶格式
# 一阶格式在干床处可能过于耗散
```

### 对比：为什么RP2成功而干床失败？

| 特征 | RP2 | 干床问题 |
|------|-----|---------|
| 最小水深 | h_min = 5.0m | h_min = 0.0m |
| 速度 | u ≈ ±5 m/s | u → ±∞（干床处） |
| CFL限制 | 稳定 | **崩溃** (dt→0) |
| 测试结果 | ✅ 成功 | ❌ 失败 |

**结论**: 当前代码在**h→0区域的CFL计算有严重问题**。

## 🛠️ 需要修复的问题

### 优先级1: CFL计算修复 ⚠️ **紧急**

**问题**: 干床处时间步长崩溃

**建议修复**:
```python
def compute_dt(self):
    """计算时间步长（干床安全版本）"""
    max_speed = 0.0

    for i in range(self.n_cells):
        if self.h[i] > self.eps_dry:  # 只在湿区计算
            u = self.Q[i] / (self.B * self.h[i])
            c = np.sqrt(self.g * self.h[i])
            speed = abs(u) + c
            max_speed = max(max_speed, speed)
        else:
            # 干床：使用邻居cell的波速
            if i > 0 and self.h[i-1] > self.eps_dry:
                c_neighbor = np.sqrt(self.g * self.h[i-1])
                max_speed = max(max_speed, c_neighbor)
            if i < self.n_cells-1 and self.h[i+1] > self.eps_dry:
                c_neighbor = np.sqrt(self.g * self.h[i+1])
                max_speed = max(max_speed, c_neighbor)

    # 确保max_speed > 0
    if max_speed < 1e-6:
        max_speed = 1.0  # 默认波速

    dt = self.cfl * self.dx / max_speed
    return dt
```
