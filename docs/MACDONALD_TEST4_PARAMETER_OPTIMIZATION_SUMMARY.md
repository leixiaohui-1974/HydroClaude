## 3. 关键发现

### 3.1 网格分辨率的影响

**预期**: 更细网格 → 更好精度 → 更低质量误差

**实际结果**:
- 100网格 → 150网格：质量误差 **28.46% → 27.89-28.92%**
- 改善：**微乎其微**（仅0.6%，在误差范围内）
- 负流量：**反而恶化**（12% → 14-15%）

**结论**: ❌ 单纯增加网格**无效**

### 3.2 CFL数的影响

**100网格**:
- CFL 0.3 vs 0.4：质量误差完全相同（28.46%），负流量相同（12%）
- **结论**: 对粗网格无影响

**150网格**:
- CFL 0.3: 质量误差28.92%，负流量14.0%
- CFL 0.4: 质量误差27.89%，负流量14.7%
- **结论**: CFL 0.4略好（-1.03%质量误差），但负流量略差

**总体结论**: ⚠️ CFL影响**很小**（<1%）

### 3.3 Belanger误差

所有配置的Belanger误差都在**99-106%**范围，即水跃后水深预测误差接近**100%**！

**理论值**: h2 = 0.785m
**实际观测**: h2 ≈ 1.5-1.6m（推测）
**原因**: 水跃未充分形成或位置错误

## 4. 根本问题分析

### 4.1 为什么参数优化无效？

MacDonald Test 4的本质困难：

1. **强激波**：水跃是移动激波，WENO3虽然可以捕捉但会引入数值耗散
2. **无摩阻**：n=0，缺乏物理耗散稳定机制
3. **混合流态**：超临界→激波→亚临界，边界条件复杂
4. **质量守恒vs激波捕捉的矛盾**：
   - 精确捕捉激波 → 数值耗散 → 质量损失
   - 减少耗散 → 振荡 → 负流量增加

### 4.2 商业软件如何解决？

Mike11/HEC-RAS成功的原因（推测）：

1. **专用激波处理**:
   - 检测水跃位置
   - 局部使用Rankine-Hugoniot条件（物理激波关系）
   - 而非纯数值激波捕捉

2. **自适应策略**:
   - 在激波附近自动细化网格
   - 或使用一阶精度（更稳健）
   - 远离激波使用高阶精度

3. **混合方法**:
   - 超临界段：特征线方法
   - 激波：间断拟合
   - 亚临界段：隐式求解

4. **经验公式**:
   - 使用Belanger方程预测水跃参数
   - 引导数值解到正确状态
