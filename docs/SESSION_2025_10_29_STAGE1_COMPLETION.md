## 🎓 技术经验总结

### 1. 非线性方程的测试设计

**经验教训**：
- 浅水方程是非线性双曲守恒律
- 不能简单使用线性波的解析解
- 需要使用真实的非线性解析解或制造解法

**最佳实践**：
- 使用已知的非线性解析解（如Ritter）
- 使用国际标准测试（MacDonald）
- 或使用制造解法（MMS）验证收敛率

### 2. 数值耗散的合理预期

**1阶vs高阶格式**：
- 1阶Godunov：稀疏波RMSE ~3-4m（正常）
- 2阶MUSCL-WENO3：稀疏波RMSE ~1-2m（预期）
- 需要根据格式阶数设置合理的误差阈值

**工程应用观点**：
- 质量守恒比点值精度更重要
- 激波位置比稀疏波细节更重要
- 商业软件也有类似的耗散特性

### 3. 临时文件处理技巧

**发现的问题**：
- `tempfile.NamedTemporaryFile`可能有缓冲问题
- `np.savetxt`与文件对象的交互可能不稳定

**解决方案**：
- 使用pandas.DataFrame.to_csv()更可靠
- 或手动写入常规文件
- 显式flush()和close()

### 4. 测试文档化的重要性

**重要发现**：
- Skip的测试必须详细文档化原因
- 提供替代测试或解决方案
- 说明是"已知局限"还是"待修复bug"

**文档化内容**：
- 技术原因（为什么skip）
- 替代方案（如何验证功能）
- 未来规划（何时解决）

### A. Ritter溃坝解析解实现

```python
def ritter_solution(self, x, t, x_dam, h0, g=9.81):
    """
    Ritter (1892) 溃坝问题解析解

    左侧初始水深h0，右侧干床（h=0）
    瞬间溃坝，产生稀疏波和激波前沿
    """
    c0 = np.sqrt(g * h0)  # 初始波速

    # 激波前沿位置
    x_front = x_dam + 2 * c0 * t

    # 稀疏波尾部位置
    x_tail = x_dam - c0 * t

    h = np.zeros_like(x)
    u = np.zeros_like(x)

    for i in range(len(x)):
        if x[i] < x_tail:
            # 静水区
            h[i] = h0
            u[i] = 0.0
        elif x[i] < x_front:
            # 稀疏波区
            u[i] = (2.0/3.0) * ((x[i] - x_dam)/t + c0)
            c = (1.0/3.0) * (c0 - (x[i] - x_dam)/t)
            h[i] = (c**2) / g if c > 0 else 0.0
        else:
            # 干床区
            h[i] = 0.0
            u[i] = 0.0

    return h, u
```

def check_mass_conservation(self, solver, mass_initial):
    """检查质量守恒"""
    mass_current = np.sum(solver.h * solver.dx * solver.B)
    mass_error = abs(mass_current - mass_initial) / mass_initial * 100.0
    return mass_error

def detect_wave_front(self, h, threshold=0.1):
    """检测波前位置（h > threshold的最远位置）"""
    wet_indices = np.where(h > threshold)[0]
    if len(wet_indices) > 0:
        front_index = wet_indices[-1]
        return x[front_index]
    return x[0]
