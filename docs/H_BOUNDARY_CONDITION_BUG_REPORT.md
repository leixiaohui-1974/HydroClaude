# h边界条件Bug诊断报告

**日期**: 2025-10-29
**问题**: MacDonald Test 2显示33.6%~60.8%质量误差
**根本原因**: h边界条件实现导致流量"憋住"，无法达到稳态

---

MacDonald Test 2 (Drawdown Curve) 测试中出现严重质量误差：

### 2. h边界"憋住"了流量

**流量统计**：
```
累积流入：5917.31 m³
累积流出：2532.11 m³
流入/流出比：2.34

平均流入速率：1.9724 m³/s (接近Q_bc=2.0)
```

**理论预期**：

- 对于缓流渠道，稳态应该在t<<3000s达到
- 流入流出比应该接近1.0，而不是2.34！

### 3. 质量变化是"真实"的物理行为

h边界条件：
```python
bc_right = {'type': 'h', 'value': h_c}  # 临界水深0.7415m
```

- h边界会创造/消耗质量来维持边界水深
- 但如果流出量不足，质量会持续积累
- 这导致实际质量持续增加（5561 m³ → 8942 m³）

## 根本原因分析

### 当前h边界条件实现

当前实现通过ghost cells施加h边界：

```python
# solvers/godunov_fvm_solver.py: _setup_ghost_cells()

if self.bc_right['type'] == 'h':
    h_bc = self.bc_right['value']
    # Ghost cell设置为边界水深
    h_ghost[-1] = h_bc
    Q_ghost[-1] = Q[-1]  # 流量外推
```

### 问题所在

1. **Ghost cell方法的局限性**：
   - 固定右边界水深 = h_c
   - 流量通过外推获得：`Q_ghost = Q[-1]`
   - 但这个流量可能不足以达到稳态

2. **临界水深的特殊性**：
   - 临界水深Fr=1，是流动状态的转折点
   - 在临界状态，流量应该能够自由流出
   - 但当前实现可能限制了流出能力

3. **无法达到稳态**：
   - 流入速率：1.97 m³/s（由左边界Q条件控制）
   - 流出速率：0.84 m³/s（由右边界h条件限制）
   - 不平衡 → 质量持续积累 → 质量"误差"

## 问题定性

### 这是Bug还是正确的物理行为？

**判断：这是Bug！**

理由：
1. **稳态不平衡**：稳态时流入≠流出，违反连续性方程
2. **临界水深处理不当**：临界水深应该允许流量自由流出
3. **质量持续积累**：如果继续运行，质量会无限增长

### 正确的h边界条件应该如何工作？

对于临界水深边界（Fr=1）：
1. 固定边界水深 h = h_c
2. 但允许流量自由调整，使得：
   - Fr = 1（临界状态）
   - Q = B * h_c * sqrt(g * h_c)
3. 稳态时：流入 ≈ 流出

## 解决方案建议

### 方案1：改进ghost cells设置

对于h边界（尤其是临界水深）：
```python
if self.bc_right['type'] == 'h':
    h_bc = self.bc_right['value']
    h_ghost[-1] = h_bc

    # 对于临界水深，强制Fr=1
    Fr_c = (Q[-1] / (self.B * h_bc)) / np.sqrt(self.g * h_bc)
    if abs(Fr_c - 1.0) < 0.1:  # 临界状态附近
        # 强制临界流量
        Q_ghost[-1] = self.B * h_bc * np.sqrt(self.g * h_bc)
    else:
        Q_ghost[-1] = Q[-1]  # 外推
```

### 方案2：使用临界水深边界条件类型

添加新的边界条件类型：
```python
bc_right = {'type': 'critical', 'value': None}  # 自动计算临界水深
```

这样可以：
1. 自动维持Fr=1
2. 允许流量自由调整
3. 确保稳态平衡

### 方案3：使用特征边界条件

对于临界状态，使用特征线方法：
- 超临界（Fr>1）：所有特征线从内部向外，强制h和Q
- 临界（Fr=1）：一个特征线，只强制h或Q
- 亚临界（Fr<1）：需要两个边界条件

MacDonald Test 2的"质量误差"**不是数值方法的问题**，而是**h边界条件实现的bug**。

**核心问题**：h边界条件限制了流出能力，导致流入≠流出，系统无法达到稳态，质量持续积累。
