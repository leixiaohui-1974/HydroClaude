### 1. WaterHammerMOCSolver类 (450+ LOC)

**文件**: `solvers/water_hammer_moc_solver.py`

#### 核心功能

##### 1.1 基本方程求解

特征线法(MOC)求解Saint-Venant方程：

**控制方程**:
- 连续性方程: ∂H/∂t + (a²/gA) * ∂Q/∂x = 0
- 动量方程: ∂Q/∂t + gA * ∂H/∂x + (f*Q*|Q|)/(2*D*A) = 0

**特征线**:
- C⁺特征线: dx/dt = +a (正向传播)
- C⁻特征线: dx/dt = -a (反向传播)

**相容方程** (有限差分形式):
```
C⁺: H_P + B*Q_P = H_A + B*Q_A - R*Q_A*|Q_A|
C⁻: H_P - B*Q_P = H_B - B*Q_B + R*Q_B*|Q_B|
```

其中:
- B = a / (g*A) - 特征系数
- R = f*Δt / (2*D*A) - 摩阻系数

##### 1.2 波速计算 (Korteweg公式)

```python
a = √(K/ρ) / √(1 + (K*D)/(E*e))
```

参数:
- K: 液体体积弹性模量 (水: 2.1 GPa)
- E: 管材弹性模量 (钢: 200 GPa, 铸铁: 100 GPa)
- D: 管径
- e: 壁厚
- ρ: 液体密度

**典型波速**:
- 钢管: 1000-1200 m/s
- 铸铁管: 800-1000 m/s
- PVC管: 400-500 m/s

##### 1.3 边界条件

实现了3种边界条件:

**a) 恒定水头 (Reservoir)**
```
H_boundary = H_reservoir
Q_boundary = (CP or CM - H_boundary) / B
```

**b) 阀门 (Valve)**

非线性阀门方程:
```
Q = τ * K * √H
```

其中 τ 为阀门开度 (0-1)

求解方法: 联立C+特征线方程，转化为二次方程求解
```
y² + B*τ*K*y - CP = 0  (y = √H)
```

**c) 死端 (Dead End)**
```
Q_boundary = 0
H_boundary = CP or CM
```

##### 1.4 理论公式

**Joukowsky压力升高公式**:
```
ΔH = a * ΔV / g
```

**临界关闭时间**:
```
T_critical = 2L / a
```

**最大压力估算**:
- 直接水锤 (T_close < T_critical): ΔH = ΔH_joukowsky
- 间接水锤 (T_close > T_critical): ΔH ≈ ΔH_joukowsky * (T_critical / T_close)

## 🔬 技术亮点

### 1. 精确的MOC实现

- ✅ **CFL条件自动满足**: CFL = a*Δt/Δx = 1.0
- ✅ **特征线精确追踪**: 网格与特征线对齐
- ✅ **摩阻项正确处理**: R = f*Δt/(2*D*A)
- ✅ **边界条件准确**: 非线性阀门方程求解

### 2. 非线性阀门模型

传统简化: Q = τ * Q_prev (线性)

本实现: Q = τ * K * √H (非线性)

求解方法:
```
联立C+方程: H + B*Q = CP
阀门方程: Q = τ*K*√H

转化为二次方程: y² + B*τ*K*y - CP = 0
解析求解: y = (-b + √(b² - 4ac)) / 2a
```

**优势**:
- 物理准确
- 无需迭代
- 计算稳定

### 3. 波速计算

考虑管壁弹性的完整Korteweg公式:

```
c_fluid = √(K/ρ)          # 纯液体声速
correction = 1 + K*D/(E*e) # 管壁弹性修正
a = c_fluid / √correction  # 实际波速
```

**验证**:
- 钢管 (E=200GPa, e=10mm): a ≈ 1173 m/s ✓
- 理论范围: 1000-1200 m/s ✓

### 4. 数值稳定性

**措施**:
1. CFL条件强制检查
2. 摩阻项隐式处理
3. 边界条件物理约束
4. 浮点数安全检查
