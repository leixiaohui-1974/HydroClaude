## 🎯 核心发现

### Q边界本身没有问题！

**证据**:
1. 简单场景（无坡度）：质量守恒完美 (0.0%)
2. Ghost cell设置正确：h_ext[0]=h[0], Q_ext[0]=Q_bc
3. 边界通量精确：F_h[0] = Q_bc（0%误差）

### 真正的问题：源项处理

**MacDonald场景的特点**：
- **底坡**：S0 = 0.002 → 底高程变化1.9m
- **摩阻**：Manning n = 0.03
- **非稳态**：初始条件不是正常水深曲线

**问题机制**：

```
1. 底坡源项: S_slope = -g * h * B * dz/dx
2. 摩阻源项: S_friction = -g * n² * |Q| * Q / (h^(10/3) * B^(4/3))
3. 如果源项计算不平衡 → 虚假流动
4. 虚假流动累积 → 质量"泄漏"
```

当前求解器的源项计算：

```python
def _compute_source_term(self, h, Q, i):
    """计算源项 (只对Q方程)"""
    if h < self.eps_dry:
        return 0.0

    u = Q / (h * self.B)

    # 摩阻源项
    if self.n > 1e-12:
        R_h = (h * self.B) / (self.B + 2*h)  # 水力半径
        S_f = self.n * self.n * abs(u) * u / (R_h**(4/3))
    else:
        S_f = 0.0

    # 底坡-摩阻平衡
    S = -self.g * (S_f - self.S0[i]) * h * self.B

    return S
```

**问题：** 这个源项计算方式在非稳态、变底高程情况下可能不够精确，导致源项不平衡累积。

## 📈 质量误差的两个根源

基于所有测试结果，质量守恒问题有**两个独立的根源**：

### 1. 边界处理问题（贡献 ~3%误差）

**影响范围**: Supercritical边界
**测试案例**:
- test_boundary_enforcement.py: 2.84%误差
- test_mass_flux_analysis.py: 2.84%误差

**原因**: RK2时间积分中边界强制与通量演化的冲突

**状态**: 已识别，部分改善（2.9% → 2.84%）

### 2. 源项处理问题（贡献 ~60%误差）

**影响范围**: 有坡度+有摩阻的问题
**测试案例**:
- MacDonald Test 2: 33-61%误差
- test_q_boundary.py (MacDonald场景): 61%误差

**原因**: 底坡源项和摩阻源项的不平衡计算

**状态**: ✅ 首次识别

## 💡 解决方案

### 短期（P0）：启用Well-Balanced格式

**问题**: 当前的well_balanced选项只实现了Hydrostatic Reconstruction，仅适用于静水问题（Lake at Rest）。

**需要**: 实现适用于有流动问题的源项平衡方法

**文献参考**:
1. **Audusse et al. (2004)**: "A Fast and Stable Well-Balanced Scheme"
   - 几何源项的精确处理
   - Hydrostatic reconstruction

2. **Zhou et al. (2001)**: "Surface gradient method"
   - 处理底坡源项
   - 适用于非静水问题

3. **Xing & Shu (2005)**: "High order well-balanced finite volume WENO schemes"
   - 高精度源项平衡
   - 适用于复杂地形

**实施步骤**:
1. 实现底坡源项的平衡离散
2. 确保源项与通量的C-property（守恒性质）
3. 在MacDonald Test 2上验证

### 中期（P1）：改进边界处理（3% → <1%）

在解决源项问题后，继续改进边界处理：
- Riemann invariants方法
- 特征分解边界条件

### 长期（P2）：系统化测试框架

建立分层测试体系：
1. **单元测试**: 边界条件、源项、通量
2. **积分测试**: 简化场景（无坡度、无摩阻）
3. **基准测试**: MacDonald, SWASHES等
