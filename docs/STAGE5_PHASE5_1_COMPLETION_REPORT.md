## 🔬 技术亮点 Technical Highlights

### 1. Colebrook-White迭代算法

**问题**: Colebrook方程是隐式方程，无法直接求解

**解决方案**:
```python
# 步骤1: Swamee-Jain显式公式提供优秀初值
f_init = 0.25 / (log10(ε/D/3.7 + 5.74/Re^0.9))^2

# 步骤2: Colebrook迭代
for i in range(10):
    f_new = 1 / (-2*log10(ε/D/3.7 + 2.51/(Re*√f)))^2
    if |f_new - f| < 1e-6:
        break
```

**优势**:
- 初值极其接近真解
- 通常3-5次迭代即收敛
- 对光滑管和粗糙管都稳定

### 2. 牛顿法流量反算

**问题**: 已知h求Q，需要反解非线性方程

**解决方案**:
```python
# 迭代: Q_{k+1} = Q_k - f(Q_k) / f'(Q_k)
# 其中 f(Q) = h_calc(Q) - h_given

for i in range(50):
    h_calc = head_loss(Q)
    residual = h_calc - h_given

    # 数值导数
    dQ = Q * 1e-6
    dh_dQ = (head_loss(Q+dQ) - h_calc) / dQ

    # 更新
    Q = Q - residual / dh_dQ
```

**优势**:
- 收敛快速稳定
- 自动步长控制
- 正值约束
