## 遇到的问题

### 问题1：测试名称不匹配

**现象**:
```python
AttributeError: 'TestMacDonald' object has no attribute 'test_macdonald_3_dry_to_wet'
```

**原因**: 实际测试名称是 `test_macdonald_3_dam_break`

**解决**:
1. 使用grep查找实际测试名称
2. 更新验证脚本
3. 重新运行

**教训**: 先检查再编码

---

### 问题2：pytest未安装

**现象**: `ModuleNotFoundError: No module named 'pytest'`

**原因**: 测试文件导入pytest，但环境中未安装

**解决**:
```bash
pip3 install pytest
```

**教训**: 检查依赖环境
