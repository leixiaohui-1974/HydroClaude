# Phase 2: 高精度求解器理论分析

## 问题诊断

### 当前状态
- **阶段1误差**: 0.14% ✓ (标准求解器，dt=1.0s, 500步)
- **阶段2误差**: 发散到NaN或18% ✗ (小步长，dt=0.2-0.5s, 数千步)

### 精度损失的三大根源

#### 1. 守恒性破坏（主要原因）
**位置**: `canal_solver.py:188-196`

```python
# ⚠️ 邻近节点平滑破坏守恒性
smooth_weight = 0.1
if idx > 1:
    Q_neighbor_target = 0.5 * (self.Q[idx - 2] + Q_gate_new)
    self.Q[idx - 1] = self.Q[idx - 1] * (1 - smooth_weight) + Q_neighbor_target * smooth_weight
```

**问题**:
- 闸门位置应该严格守恒: Q[idx-1] = Q[idx] = Q[idx+1] = Q_gate
- 但平滑操作改变了Q[idx±1]，破坏了流量守恒
- 误差在长时间积分中累积

**理论影响**:
- 每步误差: ~0.1 * |Q_target - Q_current|
- 累积误差: N_steps × δQ ≈ 50000 × 0.01 = 500倍放大

#### 2. 时间积分累积误差
**当前策略**: 阶段2使用dt=0.2s，积分10000s，共50000步

**问题**:
- 显式格式时间截断误差: O(dt) = O(0.2)
- 累积误差: N × O(dt) = 50000 × 0.2 = 10000量级
- 远大于阶段1的500步

**理论分析**:
```
阶段1: 误差 = 500步 × O(1.0) = O(500)  → 0.14%
阶段2: 误差 = 50000步 × O(0.2) = O(10000) → 理论上应该更差
```

#### 3. 闸门迭代不稳定
**位置**: `canal_solver.py:147-218` (10次迭代循环)

**问题**:
- 松弛因子过小(0.5)导致收敛慢
- 自适应算法可能振荡
- 未收敛时强制退出，留下残差

## Phase 2 解决方案

### 策略1: 严格流量守恒（核心）
```python
# 在闸门节点强制守恒
Q[idx-1] = Q_gate
Q[idx] = Q_gate
Q[idx+1] = Q_gate

# 不做任何平滑！保持守恒性
```

### 策略2: 时间步长优化
```python
# 不用过小的步长
dt_stage1 = 1.0s  # 粗收敛
dt_stage2 = 1.0s  # 精细优化（不要用0.2s）
# 关键：减少迭代次数，减少累积误差
```

### 策略3: 三阶段收敛
```
阶段1: 粗收敛 (dt=1.0s, tol=1%, 快速逼近)
阶段2: 中收敛 (dt=1.0s, tol=0.1%, 守恒优化)
阶段3: 细优化 (dt=0.5s, tol=0.01%, 最终抛光, 仅100-200步)
```

### 策略4: 改进闸门内部边界条件
```python
# 使用更大的松弛因子
relax = 0.8  # 而非0.5

# 直接赋值而非平滑
Q[idx] = (1-relax)*Q[idx] + relax*Q_gate

# 强制邻近节点守恒
Q[idx-1] = Q[idx]
Q[idx+1] = Q[idx]
```
