#### 功能特性

**3种流量特性曲线**：

1. **线性特性**（闸阀 GateValve）
   ```python
   Cv(τ) = Cv_max * τ
   ```
   - 流量与开度成正比
   - 适用于：开关控制、流量粗调

2. **快开特性**（球阀 BallValve）
   ```python
   Cv(τ) = Cv_max * τ²
   ```
   - 小开度时流量快速增加
   - 适用于：快速开关、紧急切断

3. **等百分比特性**（蝶阀 ButterflyValve）
   ```python
   Cv(τ) = Cv_max * R^(τ-1)
   ```
   - 相同开度变化产生相同百分比流量变化
   - 适用于：流量精细调节、压力控制
   - R为可调范围比（典型值50）

**流量计算**：
```python
Q = Cv(τ) * √(ΔP / ρ)
```

**解析导数**（用于Jacobian）：
```python
dQ/dP_up = Cv / (2 * √(ΔP * ρ))
dQ/dP_down = -dQ/dP_up
```

**动态响应**（一阶惯性）：
```python
dτ/dt = (τ_target - τ) / T_response
```

### 3. 泵特性曲线完善 ⭐⭐⭐⭐⭐

#### 文件

#### 功能特性

**1. 抛物线型扬程-流量特性**：
```python
H = H₀ - a*Q²

其中：
- H₀ = H_rated * shutoff_head_ratio  # 零流量扬程
- a = -(H₀ - H_rated) / Q_rated²     # 特性系数
```

**2. 效率曲线**：
```python
η = η_max * (1 - ((Q - Q_opt)/Q_opt)²)
```
- 抛物线型
- 峰值在额定流量点
- η_max典型值：0.85

**3. 相似定律**（转速变化）：
```python
Q₁/Q₂ = n₁/n₂           # 流量与转速成正比
H₁/H₂ = (n₁/n₂)²        # 扬程与转速平方成正比
P₁/P₂ = (n₁/n₂)³        # 功率与转速立方成正比
```

**4. 工作点解析求解**：
```python
# 求解：H_pump(Q) = H_system
Q = √((H₀ - H_system) / a)
```
- 无需迭代
- 计算快速准确
- 处理边界条件（H_system > H₀）

**5. 功率计算**：
```python
P = ρ * g * Q * H / η
```

## 🔧 技术细节

### 阀门实现关键点

**1. 流量系数函数**
```python
def get_Cv(self, opening: float) -> float:
    tau = np.clip(opening, 0.0, 1.0)

    if self.valve_type == 'linear':
        Cv = self.Cv_max * tau
    elif self.valve_type == 'quick':
        Cv = self.Cv_max * (tau ** 2)
    elif self.valve_type == 'equal_percentage':
        Cv = self.Cv_max * (self.R ** (tau - 1))

    return Cv
```

**2. 解析导数推导**

对于流量公式：
```
Q = Cv * √(ΔP / ρ)
```

求导：
```
dQ/dP_up = Cv * (1/2) * (ΔP/ρ)^(-1/2) * (1/ρ)
         = Cv / (2 * √(ΔP * ρ))

dQ/dP_down = -dQ/dP_up
```

**3. 动态响应实现**

一阶惯性环节离散化：
```python
# 连续时间：dτ/dt = (τ_target - τ) / T
# 离散时间：τ(k+1) = τ(k) + (dt/T) * (τ_target - τ(k))

tau = dt / self.response_time
self.state.opening += tau * (target_opening - self.state.opening)
```

### 泵实现关键点

**1. 相似定律应用**
```python
# 转速修正
speed_ratio = n / n_rated

# 流量转换到额定转速
Q_rated = Q / speed_ratio

# 计算额定转速下的扬程
H_rated = H0 - a * Q_rated²

# 转换回实际转速
H = H_rated * speed_ratio²
```

**2. 工作点求解**

求解方程：
```
H_pump(Q) = H_system
H₀ - a*Q² = H_system
```

解析解：
```python
Q_rated = √((H₀ - H_system) / a)
Q = Q_rated * speed_ratio
```

**3. 边界条件处理**
```python
# 情况1：系统扬程超过零流量扬程
if H_system >= H0:
    return 0.0  # 无流量

# 情况2：特性曲线过于平坦
if abs(a) < 1e-9:
    return rated_flow * speed_ratio  # 使用额定流量

# 情况3：负值保护
if Q_rated_sq < 0:
    return 0.0
```
