# 输水系统多物理场耦合仿真与智能控制一体化架构规划

**作者**: HydroClaude Team & Manus AI
**日期**: 2026-03-27

## 1. 顶层架构愿景

现代长距离调水工程（如南水北调、引绰济辽）面临着极端的运行环境和复杂的物理约束。为了实现安全、高效、经济的自动化调度，我们需要构建一个**“仿真-降阶-辨识-控制-评估”一体化**的自主运行算法模型集合。

本架构旨在将 **HydroClaude**（高精度多物理场仿真引擎）与 **Pipedream-Hydrology-Integration-Lab**（基于 SuperLink 的高效状态空间求解与控制框架）深度融合，形成一个完整的闭环系统。

系统核心能力包括：
1. **全要素耦合仿真**：水动力（1D/2D） + 水质生化 + 冰期热力学 + 渠道边坡地下水与衬砌板扬压力。
2. **面向控制的降阶（ROM）**：将千万级自由度的偏微分方程（PDE）降阶为适合实时控制的低维状态空间模型（ODE）。
3. **在线辨识与状态估计**：基于卡尔曼滤波（KF）和系统辨识算法，实时同化 SCADA 数据，修正模型参数。
4. **先进控制算法**：基于降阶模型的模型预测控制（MPC），处理多重物理约束（水位、扬压力、冰期防冻）。
5. **软件在环（SIL）与运行域（ODD）评估**：在虚拟环境中对控制策略进行压力测试和安全边界（Safety Envelope）验证。

## 2. 渠道边坡衬砌板耦合仿真与降阶方案

渠道在水位剧烈波动（如快速降水）时，边坡外部水位下降快于内部地下水排泄，导致衬砌板承受巨大的**扬压力（Uplift Pressure）**，极易引发衬砌板破坏和边坡失稳。

### 2.1 物理耦合机制（高精度仿真）

在 HydroClaude 中，我们需要建立“明渠水流 - 边坡地下水 - 衬砌板力学”的三场耦合模型：
*   **明渠水流（Hydrodynamics）**：由 Preissmann 或 FVM 求解器提供随时间变化的边界水位 $H_{canal}(x, t)$。
*   **边坡地下水（Groundwater）**：基于 1D/2D Boussinesq 方程或 Richards 方程，以 $H_{canal}$ 为随动边界条件，求解边坡内部地下水位 $H_{gw}(x, y, t)$。
*   **扬压力与稳定分析（Geomechanics）**：计算衬砌板底部的扬压力 $P_u = \rho g (H_{gw} - H_{canal})$。当 $P_u$ 大于衬砌板自重与抗滑力之和时，触发失稳报警。

### 2.2 面向控制的降阶策略（ROM）

高精度的地下水渗流计算极其耗时，无法直接嵌入到 MPC 的优化目标函数中。必须采用模型降阶（Reduced Order Modeling, ROM）技术：

1.  **本征正交分解（POD-Galerkin）**：
    *   **离线阶段**：使用 HydroClaude 运行大量典型工况（如不同速率的降水过程），收集边坡地下水位的快照矩阵（Snapshots）。通过奇异值分解（SVD）提取前 $r$ 个主导空间模态（Modes）。
    *   **在线阶段**：将高维的 Boussinesq 方程投影到这 $r$ 个模态构成的低维子空间上，将自由度从 $10^4$ 降至 $10^1$ 级别。
2.  **平衡截断（Balanced Truncation）**：
    *   对于线性化的地下水渗流系统，计算其可控性（Controllability）和可观性（Observability）格拉姆矩阵。
    *   截断那些“既难控制又难观测”的状态变量，保留对输入（渠道水位）和输出（扬压力）最敏感的状态，生成极低维的状态空间方程。
3.  **等效传递函数（FOPDT / IDZ）**：
    *   利用 Pipedream 现有的 `reduced_order.py` 框架，将“渠道水位变化率”到“最大扬压力”的动态过程，辨识为一阶惯性加纯滞后（FOPDT）或积分加零点（IDZ）模型。

## 3. SuperLink 状态空间与多物理场集成

**SuperLink** 的核心优势在于其原生的**状态空间方程（State-Space）表达**和极高的计算效率（基于稀疏矩阵分块）。

### 3.1 统一状态空间架构

我们将水质、冰期和边坡降阶模型统一纳入 SuperLink 的状态空间框架中：

$$ \dot{x} = A x + B u + E d $$
$$ y = C x + D u $$

*   **状态向量 $x$**：包含水动力状态（流量 $Q$、水位 $H$）、水质状态（$DO$、$BOD$）、冰期状态（冰厚 $h_{ice}$）以及边坡降阶状态（$z_{gw}$）。
*   **控制输入 $u$**：闸门开度、泵站转速。
*   **扰动输入 $d$**：气温、太阳辐射、上游来水、污染源排放。
*   **系统矩阵 $A, B, C$**：通过 SuperLink 的雅可比矩阵（Jacobian）自动微分或解析推导实时线性化获得。

### 3.2 耦合求解策略

*   **强耦合（Implicit）**：水动力与水工构筑物控制（闸门、泵站）在 SuperLink 内部强耦合求解，保证大步长下的绝对稳定。
*   **弱耦合（Operator Splitting）**：水质、冰期、边坡扬压力作为算子分裂的附加步。冰期模块将复合糙率 $n_c$ 反馈给 $A$ 矩阵；边坡模块从状态向量中读取 $H$ 计算扬压力。

## 4. 辨识、估计与控制算法集合

依托 Pipedream 仓库中的 `hydroclaw_control_server`，构建完整的算法工具箱：

### 4.1 状态估计（Kalman Filtering）
*   **算法**：扩展卡尔曼滤波（EKF）或无迹卡尔曼滤波（UKF）。
*   **作用**：利用 SCADA 系统的稀疏水位/流量观测数据，反演全线的水位分布、冰盖厚度以及不可测的边坡地下水位。同时在线估计时变参数（如渠道糙率漂移）。

### 4.2 在线系统辨识（System Identification）
*   **算法**：递归最小二乘法（RLS）、子空间辨识（N4SID）。
*   **作用**：在运行过程中，根据实时输入输出数据，不断更新降阶模型（如 FOPDT）的参数（增益 $K$、时间常数 $\tau$），实现自适应控制（Adaptive Control）。

### 4.3 模型预测控制（MPC）
*   **算法**：基于 `do-mpc` 或自定义二次规划（QP）求解器。
*   **目标函数**：最小化水位偏差、最小化泵站能耗、最小化闸门动作频次。
*   **硬约束（Hard Constraints）**：
    *   **扬压力约束**：$P_u(x, t) \le P_{allowable}$（限制降水速率，防止衬砌板破坏）。
    *   **冰期约束**：控制流速 $v \le v_{critical}$，促进平稳封冻，防止冰塞形成。
    *   **水质约束**：保证交水断面 $DO \ge DO_{min}$。

## 5. 软件在环（SIL）与 ODD 评估体系

为了保证控制算法在实际工程中的绝对安全，系统内置了严格的评估框架：

1.  **高保真数字孪生（Digital Twin）**：使用 HydroClaude 的全量非线性 PDE 求解器（含 AMR 和 GPU 加速）作为“虚拟现实”，替代真实物理世界。
2.  **控制算法在环（SIL）**：将 MPC 控制器、卡尔曼滤波器打包为独立进程，通过标准接口（如 OPC UA 或 ZeroMQ 模拟）与 HydroClaude 孪生体进行闭环交互。
3.  **运行设计域（ODD）与安全包络（Safety Envelope）**：
    *   利用 `odd_definition.py` 定义控制器适用的工况范围（如：流量 10~50 m³/s，无冰期）。
    *   利用 `safety_envelope.py` 实时监控孪生体的状态，一旦预测到未来可能发生越限（如扬压力超标、漫堤），立即触发安全降级（Fallback to PID/Manual）。

## 6. 实施路线图 (Roadmap)

### Phase 1: 基础耦合与接口打通 (Month 1-2)
*   将 HydroClaude 的水质、冰期模块封装为标准 C-API 或 Python 接口。
*   在 Pipedream 的 SuperLink 求解器中增加外部源项和糙率更新接口。
*   实现 HydroClaude (高保真) 与 Pipedream (降阶控制) 的数据互通。

### Phase 2: 边坡扬压力模型与 ROM (Month 3-4)
*   在 HydroClaude 中开发 1D Boussinesq 边坡地下水求解器。
*   实现 POD-Galerkin 降阶算法，生成边坡扬压力的状态空间代理模型。
*   将扬压力代理模型集成到 Pipedream 的 `reduced_order.py` 中。

### Phase 3: 约束 MPC 与卡尔曼滤波 (Month 5-6)
*   在 `mpc_wrapper.py` 中引入扬压力下降速率约束和冰期流速约束。
*   开发基于 SuperLink 线性化矩阵的 EKF 状态估计器。
*   完成“降水防破坏”和“平稳封冻”两个典型场景的闭环控制仿真。

### Phase 4: SIL 平台与全系统验证 (Month 7-8)
*   构建完整的 SIL 自动化测试流水线。
*   引入极端工况（传感器故障、通信延迟、极端暴雨）进行压力测试。
*   输出完整的系统评估报告（WNAL Assessment）。
