### 1. 问题诊断

**根本原因**（通过详细分析发现）：
```
上游边界条件不完整：
  - F[0] = Q[0] - Q_upstream  → 仅约束Q_0
```

## 📝 技术细节

### Jacobian结构（修复后，无闸门）

```
       h_0  Q_0  h_1  Q_1  h_2  Q_2  ...  h_n  Q_n
F[0]    0    1    0    0    0    0   ...   0    0    (Q_0 = Q_upstream)
F[1]    1    0    0    0    0    0   ...   0    0    (h_0 = h_upstream) ← 新增！
F[2]    0   -a    0    b    0    a   ...   0    0    (连续性，伪瞬态)
F[3]   c1   d1   c2   d2   c3   d3  ...   0    0    (动量，伪瞬态)
...
F[2n]   0    0    0    0    0    0   ...   1    0    (h_n = h_downstream)
F[2n+1] 0    0    0    0    0    0   ...   0    e    (连续性，边界)

其中：
  a = 1/(2*dx)
  b = 1/pseudo_dt
  c_i, d_i = 动量方程的系数
  e = 1/pseudo_dt + 1/dx
```

**关键观察**：
- F[1]行现在约束h_0（之前不约束任何h变量）
- 每个变量都有至少一个约束
- 对角线非零元素与秩的关系
