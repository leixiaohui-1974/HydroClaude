#### 1.3 根本原因分析

**物理不兼容性**：

下游边界h=2.8m远高于理论水跃后h2=0.78m：
```
理论水跃：  h1=0.7m → h2=0.78m (Belanger方程)
实际边界：  h1=0.7m → h=2.8m   (物理不可能！)
差异：      2.02m (260%)
```

这样的边界条件组合在稳态下**物理不可能**，除非：
- 有额外的能量输入
- 有更复杂的流态（回流、旋涡）
- 非稳态振荡

**数值方法局限性**：

水跃是**激波**，需要特殊处理：
1. **激波捕捉**：移动激波需要特殊算法
2. **Gibbs振荡**：不连续解附近的数值振荡
3. **人工粘性**：需要抑制非物理振荡
4. **网格分辨率**：激波需要足够细的网格

当前Godunov FVM + HLL：
- ✅ 可以捕捉弱激波
- ❌ 对强激波（本例）不足
- ❌ 无人工粘性机制
- ❌ 质量守恒失败说明数值格式问题

**边界条件与守恒律的矛盾**：

- supercritical BC强制：h=0.7m, Q=20m³/s
- h边界强制：h=2.8m
- 内部流动：试图满足守恒律
- **结果**：边界强制与守恒律无法同时满足

质量误差来源：
1. 边界强制引入/移除质量（relaxation方法）
2. 激波处的数值耗散
3. 累积误差
4. 不稳定流动

## 技术总结

### 1. 激波数值模拟的挑战

**水跃（激波）的特点**：
1. 强不连续解
2. 快速变化
3. 能量耗散
4. 移动边界

**数值挑战**：
1. Gibbs振荡（过冲/欠冲）
2. 数值耗散 vs 物理耗散
3. 激波移动速度
4. 边界条件兼容性

**解决方法**（未实现）：
- ENO/WENO高阶格式
- TVD/FCT限制器
- 人工粘性
- 自适应网格

### 2. 数值精度的内在限制

**精度三角**：
```
         稳定性
          /  \
         /    \
        /      \
    精度 ―――――― 效率
```

**权衡**：
- ↑稳定性 → ↓精度（如relaxation方法）
- ↑精度 → ↓稳定性（如高阶格式）
- ↑精度 → ↓效率（如细网格）

**当前选择**：
- 优先稳定性
- 接受中等精度（15-20%）
- 保持高效率

### 3. 工程实践 vs 学术研究

**工程角度**：
- 15-20%误差：可接受
- 稳定性：关键
- 效率：重要
- 复杂度：尽量低

**学术角度**：
- 5%误差：目标
- 精度：关键
- 复杂度：可接受
- 新方法：价值

**本项目定位**：工程实践 ✅
