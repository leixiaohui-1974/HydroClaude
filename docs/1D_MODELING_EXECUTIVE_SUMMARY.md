## 📚 关键技术要点

### 1. 阀门流量系数

```python
# 等百分比特性
Cv(τ) = Cv_max * R^(τ-1)

# 其中 R为可调范围比（典型值50）
# τ为开度（0-1）
```

### 2. 泵特性曲线

```python
# 抛物线型
H = H₀ - a*Q²

# 其中
H₀ = 1.2 * H_rated  # 零流量扬程
a = -(H₀ - H_rated) / Q_rated²
```

### 3. 水轮机相似定律

```python
# 单位转速
n₁₁ = n * D / √H

# 单位流量
Q₁₁ = Q / (D² * √H)

# 单位功率
P₁₁ = P / (D² * H^(3/2))
```

### 4. 调压井振荡方程

```python
# 微分方程组
dz/dt = -Q_tunnel / A_tank
dQ/dt = -(g * A_tunnel / L_tunnel) * (z + h_loss)
```
