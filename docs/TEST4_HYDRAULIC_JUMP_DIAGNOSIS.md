## 根本原因分析

### 1. 物理不兼容性

**理论分析**：
- 上游：Fr1 = 1.09，u1 = 2.86m/s
- 理论水跃后：h2 = 0.78m（Belanger方程）
- 实际下游边界：h = 2.8m
- **差异：2.02m（260%！）**

**物理意义**：
> 下游边界水深(2.8m)远高于水跃后应有的水深(0.78m)。这样的边界条件组合在稳态下是**物理不可能**的，除非：
> 1. 有额外的能量输入
> 2. 有更复杂的流态（如回流、旋涡）
> 3. 非稳态振荡

### 2. 数值方法局限性

**水跃的数值挑战**：
1. **激波捕捉**：水跃是移动激波，需要特殊处理
2. **Gibbs振荡**：不连续解附近的数值振荡
3. **人工粘性**：需要抑制非物理振荡
4. **网格分辨率**：激波需要足够细的网格

**当前方法（Godunov FVM + HLL）**：
- ✅ 可以捕捉激波（弱激波）
- ❌ 对于强激波（如本例）可能不足
- ❌ 无人工粘性机制
- ❌ 质量守恒失败说明数值格式问题

### 3. 边界条件与内部流动的矛盾

**边界强制 vs 物理守恒**：
- supercritical BC强制上游：h=0.7m, Q=20m³/s
- h边界强制下游：h=2.8m
- 内部流动试图满足守恒律
- **矛盾**：边界强制与守恒律无法同时满足

**质量误差的来源**：
1. 边界强制引入/移除质量
2. 激波处的数值耗散
3. relaxation方法的累积误差
4. 不稳定流动导致的非守恒

## 可能的解决方案

### 方案1：调整边界条件（简单）

**思路**：使下游水深接近理论值

```python
h_upstream = 0.7
Fr_upstream = 1.09
h2_theory = 0.78  # Belanger方程

# 方案A：使用理论值
bc_right = {'type': 'h', 'value': h2_theory}

# 方案B：使用稍高的值
bc_right = {'type': 'h', 'value': 1.0}  # 介于0.78和2.8之间
```

**预期**：
- ✅ 减小边界冲突
- ⚠️  但水跃可能仍不稳定
- ⚠️  偏离MacDonald原始测试配置

### 方案2：添加人工粘性（中等）

**思路**：在激波附近添加数值粘性

```python
# 检测激波（大梯度区域）
dh_dx = np.gradient(h) / dx
shock_indicator = abs(dh_dx) > threshold

# 在激波附近添加耗散
if shock_indicator[i]:
    h[i] += artificial_viscosity * (h[i+1] - 2*h[i] + h[i-1])
```

**预期**：
- ✅ 抑制激波振荡
- ✅ 可能改善质量守恒
- ❌ 增加代码复杂度
- ⚠️  需要大量调参
