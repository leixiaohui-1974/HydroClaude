# 示例2：明渠阀门控制仿真报告

## 1. 问题背景

### 1.1 工程背景
明渠闸门控制是水利工程中最常见的调控手段，广泛应用于灌溉渠系、防洪排涝、水力发电等领域。精确模拟闸门启闭对水流的影响，对于优化调度方案、设计控制策略具有重要意义。

### 1.2 技术挑战
- 闸门动作引起边界条件快速变化
- 瞬态响应可能产生波动传播
- 需要处理流量-水深的非线性耦合
- 控制律设计需要准确的动态模型

### 1.3 研究目标
验证HydroClaude对闸门控制场景的仿真能力，测试系统对边界扰动的动态响应特性。

## 2. 数学模型

### 2.1 系统方程

**明渠控制方程** (与示例1相同):
```
∂A/∂t + ∂Q/∂x = 0  (连续性)
∂Q/∂t + ∂(Q²/A)/∂x + gA·∂h/∂x = gA(S₀ - Sf)  (动量)
```

### 2.2 闸门模型

**闸门流量公式** (堰流公式):
```
Q_gate = C_d · W · a · √(2g·Δh)

其中:
- C_d: 流量系数 (≈0.6-0.8)
- W: 闸门宽度 (m)
- a: 闸门开度 (m)
- Δh: 上下游水头差 (m)
```

**闸门开度控制**:
```
a(t) = a₀ + k_p·(h_ref - h_measured) + k_d·dh/dt

其中:
- a₀: 初始开度
- k_p: 比例增益
- k_d: 微分增益
```

### 2.3 边界条件

- **上游边界**: 恒定流量 Q_in = 5.0 m³/s
- **下游边界**: 闸门流量边界
  - 初始开度: 50%
  - 目标水深: 5.0 m
  - 控制周期: 每30秒调整

## 4. 控制策略

### 4.1 PD控制器设计

**控制律**:
```python
error = target_depth - measured_depth
error_derivative = (error - last_error) / dt

gate_opening = base_opening + kp * error + kd * error_derivative
gate_opening = np.clip(gate_opening, 0.0, max_opening)
```

## 7. 物理解释

### 7.1 波动传播分析

**波速计算**:
```
c = √(gh) = √(9.81×5.0) ≈ 7.0 m/s
```

**传播时间**:
```
t_wave = L/c = 1000/7.0 ≈ 143 s
```

**观测**: 闸门动作后约60-90s水深达到稳定，快于波动往返时间，说明系统为欠阻尼响应。

### 7.2 能量平衡

**初始状态**:
```
E_initial = h₀ + v₀²/(2g) + z₀
         = 5.0 + (0.1)²/(2×9.81) + 0
         ≈ 5.0005 m
```

**稳态**:
```
E_final ≈ 5.0005 m
```

能量损失 = 摩阻损失 + 闸门局部损失
→ 在稳态下平衡

### 7.3 Froude数分析

```
Fr = v / √(gh) = 0.1 / 7.0 ≈ 0.014
```

- Fr << 1: 缓流
- 控制从下游向上游传播
- 闸门调节对上游水位影响显著

### 8.2 参数整定

**Ziegler-Nichols法估算**:
```
临界增益 Ku ≈ 1.2
```

实际参数与经验公式吻合。

## 9. 建议与改进

### 9.1 控制算法扩展

**推荐策略**:
1. **PID控制**: 增加积分项
   ```python
   u = kp*e + ki*∫e·dt + kd*de/dt
   ```

2. **模型预测控制 (MPC)**:
   ```
   min  Σ(h[k] - h_ref)² + λ·Σ(Δu[k])²
   s.t. 动力学模型
        0 ≤ a[k] ≤ a_max
   ```

3. **模糊控制**: 处理非线性和不确定性

4. **自适应控制**: 在线辨识参数
