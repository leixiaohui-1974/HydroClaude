# 示例15：RLS参数辨识报告

## 1. 问题背景

### 1.1 工程背景
水力系统的准确建模是控制器设计、故障诊断、性能优化的基础。然而，实际系统存在：
- **参数不确定性**: 糙率、管径等测量误差
- **参数时变**: 淤积导致糙率增加、管道老化等
- **建模误差**: 简化假设、非线性未建模动态

参数辨识技术能够从输入输出数据中在线估计系统参数，为自适应控制提供模型基础。

### 1.2 技术挑战
- 水力系统高度非线性
- 噪声污染测量数据
- 实时计算资源受限
- 辨识精度与收敛速度的权衡

### 1.3 研究目标
展示HydroClaude的在线参数辨识能力，验证RLS算法在ARX模型辨识中的有效性。

## 2. 数学模型

### 2.1 ARX模型

**定义**: AutoRegressive with eXogenous input
```
A(q)·y[k] = B(q)·u[k-d] + e[k]

其中:
A(q) = 1 + a₁·q⁻¹ + ... + aₙₐ·q⁻ⁿᵃ
B(q) = b₁·q⁻¹ + ... + bₙᵦ·q⁻ⁿᵇ
d: 延迟步数
```

**展开形式**:
```
y[k] = -a₁·y[k-1] - ... - aₙₐ·y[k-na]
       + b₁·u[k-d-1] + ... + bₙᵦ·u[k-d-nb]
       + e[k]
```

**回归形式**:
```
y[k] = φ[k]ᵀ·θ + e[k]

其中:
φ[k] = [-y[k-1], ..., -y[k-na], u[k-d-1], ..., u[k-d-nb]]ᵀ
θ = [a₁, ..., aₙₐ, b₁, ..., bₙᵦ]ᵀ
```

### 2.2 递推最小二乘 (RLS)

**目标**: 最小化预测误差平方和
```
min  J = Σ λⁿ⁻ᵏ·(y[k] - φ[k]ᵀ·θ)²

其中λ是遗忘因子
```

**递推更新公式**:

```
# 1. 预测
ŷ[k] = φ[k]ᵀ·θ[k-1]

# 2. 预测误差
e[k] = y[k] - ŷ[k]

# 3. 增益计算
K[k] = P[k-1]·φ[k] / (λ + φ[k]ᵀ·P[k-1]·φ[k] + reg)

# 4. 参数更新
θ[k] = θ[k-1] + K[k]·e[k]

# 5. 协方差更新 (Joseph形式)
I_Kφ = I - K[k]·φ[k]ᵀ
P[k] = (I_Kφ·P[k-1]·I_Kφᵀ + K[k]·K[k]ᵀ·reg) / λ
```

**关键特性**:
- **递推性**: 无需存储历史数据
- **遗忘因子**: 跟踪时变参数
- **数值稳定**: Joseph形式保证P正定
- **计算效率**: O(n²)复杂度

## 3. 测试场景设置

### 3.1 真实系统

**ARX(2,2,1)模型**:
```
y[k] = 0.8·y[k-1] - 0.3·y[k-2]
       + 1.5·u[k-1] + 0.7·u[k-2]
       + e[k]

参数向量:
θ_true = [a₁, a₂, b₁, b₂]ᵀ
       = [0.8, -0.3, 1.5, 0.7]ᵀ

模型阶数:
na = 2 (AR阶数)
nb = 2 (X阶数)
d = 1 (延迟)
```

**系统特性分析**:

**稳定性**:
```
特征方程: 1 - 0.8z⁻¹ + 0.3z⁻² = 0
极点: z₁,₂ = (0.8 ± √(0.64-1.2))/2
    = 0.4 ± 0.375i
|z| = √(0.4² + 0.375²) = 0.548 < 1 ✓ 稳定
```

**频率响应**:
```
传递函数:
H(z) = (1.5z⁻¹ + 0.7z⁻²) / (1 - 0.8z⁻¹ + 0.3z⁻²)

DC增益 (z=1):
H(1) = (1.5 + 0.7) / (1 - 0.8 + 0.3) = 2.2 / 0.5 = 4.4
```

### 3.2 输入信号设计

**随机二进制序列 (PRBS)**:
```python
u[k] ∈ {-1, +1}  (幅值)
P(u[k+1] = u[k]) = 0.95  (切换概率)

特性:
- 频谱丰富 (持续激励)
- 幅值受限 (实际约束)
- 易于实现
```

**噪声**:
```
e[k] ~ N(0, σ²)
σ = 0.1  (10%噪声水平)
SNR ≈ 20 dB
```

从ARX模型直接得到:

```
     = (b₁z⁻¹ + b₂z⁻²) / (1 + a₁z⁻¹ + a₂z⁻²)

辨识结果:
H_id(z) = (1.413z⁻¹ + 0.742z⁻²) / (1 - 0.822z⁻¹ + 0.352z⁻²)

真实系统:
H_true(z) = (1.500z⁻¹ + 0.700z⁻²) / (1 - 0.800z⁻¹ + 0.300z⁻²)
```

## 7. 讨论

### 7.1 RLS算法性能

**优势**:
1. **递推性**: O(n²)复杂度，内存O(n²)
2. **在线性**: 实时更新，无需批量数据
3. **遗忘机制**: 适应时变系统
4. **数值稳定**: Joseph形式

**局限**:
1. **线性假设**: 仅适用于线性模型
2. **高斯噪声**: 最优性依赖高斯假设
3. **模型阶数**: 需预先确定na, nb, d
4. **初始化敏感**: P[0]和θ[0]影响性能

### 7.2 ARX模型适用性

**适用场景**:
- 输入输出数据充足
- 系统近似线性
- 噪声为白噪声
- 实时辨识需求

**不适用场景**:
- 强非线性系统 → 建议Hammerstein/Wiener模型
- 有色噪声 → 建议ARMAX模型
- 闭环数据 → 建议间接辨识
- 多变量耦合 → 建议MIMO模型

### 7.3 水力系统建模

**ARX模型在水力系统中的应用**:

**适用**:
```
1. 小扰动线性化
   - 工作点附近行为
   - 控制器设计

2. 降阶近似
   - Saint-Venant简化
   - 快速计算

3. 数据驱动
   - 黑盒辨识
   - 免物理建模
```

**局限**:
```
1. 大范围非线性
   → 分段线性或增益调度

2. 分布参数特性
   → 高阶ARX或传递函数矩阵

3. 时变性强
   → 小遗忘因子或自适应算法
```

### 8.2 模型结构选择

**自动定阶**:

```python
def auto_order_selection(data, max_order=10):
    best_aic = float('inf')
    best_order = None

    for na in range(1, max_order+1):
        for nb in range(1, max_order+1):
            model = ARXModel(na, nb, d=1)
            model.fit(data)

            # Akaike信息准则
            aic = model.compute_aic()

            if aic < best_aic:
                best_aic = aic
                best_order = (na, nb)

    return best_order

# 结果: ARX(2,2) for 本例 ✓
```

**模型验证**:
```python
def validate_model(model, data_test):
    # 1. 残差白化检验
    residuals = data_test.y - model.predict(data_test.u)
    is_white = check_whiteness(residuals)

    # 2. 残差独立性检验
    is_independent = check_independence(residuals, data_test.u)

    # 3. 交叉验证
    cv_score = cross_validate(model, data)

    return is_white and is_independent and cv_score > 0.9
```
