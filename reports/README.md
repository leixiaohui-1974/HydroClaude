### 示例13: 时间尺度自适应仿真 ⭐
**文件**: [example_13_report.md](example_13_report.md)

**创新点**: 根据时间步长自动选择最优模型

**四种模型对比**:

| 模型 | 时间步长 | 计算加速 | 适用场景 |
|------|---------|---------|----------|
| **高保真FVM** | 10 s | 1× | 瞬态分析、水击 |
| **传递函数** | 120 s | 50× | MPC控制设计 |
| **IDZ模型** | 900 s | 333× | 预测优化 |
| **水量平衡** | 3600 s | 2000× | 长期规划 |

**核心算法**:
```python
def select_model(dt):
    if dt < 60: return HIGH_FIDELITY
    elif dt < 600: return TRANSFER_FUNCTION
    elif dt < 3600: return IDZ
    else: return WATER_BALANCE
```

**验证结果**:
```
自动选择准确率: 100% (7/7测试)
计算效率提升: 50-2000倍
精度可控: 根据需求权衡
接口统一: 无缝切换
```

**理论基础**:

**高保真模型** (Saint-Venant):
```
∂A/∂t + ∂Q/∂x = 0
∂Q/∂t + ∂(Q²/A)/∂x + gA·∂h/∂x = gA(S₀ - Sf)
```

**传递函数模型**:
```
G(s) = K / (τs + 1)
τ = L/v, K = L/B
```

**IDZ模型**:
```
G(s) = K·exp(-τd·s) / (τ·s)
τd = L/(v+c), τ = L/v
```

**水量平衡**:
```
dV/dt = Q_in - Q_out + P - E
```

**应用价值**:
| 应用 | 推荐模型 | 时间尺度 |
|------|---------|---------|
| 实时控制 | 传递函数 | 分钟 |
| 预测优化 | IDZ | 小时 |
| 资源规划 | 水量平衡 | 天-月 |
| 安全分析 | 高保真 | 秒-分钟 |

### 示例14: 自适应MPC控制 ⭐
**文件**: [example_14_report.md](example_14_report.md)

**核心技术**: 模型预测控制 + 递推最小二乘辨识

**问题设定**:
```
系统: x[k+1] = A·x[k] + B·u[k]
目标: 跟踪 x_ref = [5.0, 3.0]ᵀ
初始: x[0] = [1.0, 0.5]ᵀ

模型误差:
‖A_init - A_true‖ = 15.0%
‖B_init - B_true‖ = 22.4%
```

**MPC优化问题**:
```
min  Σ [‖x[k] - x_ref‖²_Q + ‖u[k]‖²_R + ‖Δu[k]‖²_S]
s.t. x[k+1] = A·x[k] + B·u[k]
     x_min ≤ x[k] ≤ x_max
     u_min ≤ u[k] ≤ u_max
```

**RLS参数辨识**:
```
θ[k] = θ[k-1] + K[k]·(x[k] - φ[k]ᵀ·θ[k-1])
K[k] = P[k-1]·φ[k] / (λ + φ[k]ᵀ·P[k-1]·φ[k])
P[k] = (I - K[k]·φ[k]ᵀ)·P[k-1] / λ
```

**性能结果**:

**参数辨识精度**:
| 步数 | A误差 | B误差 |
|------|-------|-------|
| 0 | 15.0% | 22.4% |
| 10 | 8.9% | 11.5% |
| 20 | 5.3% | 6.2% |
| 30 | 2.8% | 3.2% |
| 50 | 0.5% | 0.8% ✓ |

**控制性能**:
| 指标 | 固定MPC | 自适应MPC |
|------|---------|----------|
| 超调量 | 23.5% | 1.2% ✓ |
| 稳态误差 | 15.3% | 0.0% ✓ |
| 调节时间 | 不收敛 | 35步 ✓ |

**性能提升**:
- 超调减少: 94.9%
- 稳态误差: 从15.3%降至0%
- 收敛性: 从发散到稳定收敛

**理论分析**:

**RLS收敛性**:
```
‖θ[k] - θ*‖ ≤ C·λᵏ/(1-λ)

对于λ=0.98:
- 时间常数: τ ≈ 50步
- 半衰期: t_1/2 ≈ 34步
- 实测: 35步达到2%误差 ✓
```

**MPC稳定性**:
```
V(x[k+1]) ≤ V(x[k]) - ‖x[k] - x_ref‖²_Q
→ Lyapunov稳定 ✓
```

**应用场景**:
- 灌溉渠系自适应调度
- 城市供水优化控制
- 参数时变系统
- 模型不确定性补偿
