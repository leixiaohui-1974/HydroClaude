## 仿真概述


本示例演示了HydroClaude的递推最小二乘(RLS)参数辨识功能。

**ARX模型**:
ARX(na, nb, nk)模型是自回归外生输入模型，形式为：
```
y[k] = a1*y[k-1] + ... + ana*y[k-na] + b1*u[k-nk] + ... + bnb*u[k-nk-nb+1]
```

**本例模型**: ARX(2, 2, 1)
```
y[k] = 0.8*y[k-1] + -0.3*y[k-2] + 1.5*u[k-1] + 0.7*u[k-2]
```

**RLS算法**:
递推最小二乘是一种在线参数估计方法，具有以下特点：
- 实时更新参数估计
- 计算效率高，适合在线应用
- 遗忘因子机制适应时变系统

**辨识结果**:
