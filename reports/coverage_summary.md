## 📝 如何生成覆盖率报告

### 后端覆盖率

```bash
# 生成 HTML 覆盖率报告
pytest --cov=solvers --cov=web/backend --cov=utils \
       --cov-report=html:reports/html/coverage \
       --cov-report=term-missing \
       --cov-report=xml:coverage.xml

# 查看报告
open reports/html/coverage/index.html
```

### 前端覆盖率

```bash
# Playwright 会自动记录代码执行路径
npm test -- --reporter=html

# 查看报告
npm run report
```
