### For Existing Users (Migrating from v1.2.0)

⚠️ **BREAKING CHANGES** - Action required!

1. **Update Configuration Format**:
   ```json
   # OLD (v1.2.0) - will fail
   {
     "name": "test"
   }

   # NEW (v1.3.0) - required
   {
     "name": "test",
     "config": {
       "width": 10.0,              // NOW REQUIRED
       "length": 1000.0,           // NOW REQUIRED
       "n_cells": 100,             // NOW REQUIRED
       "initial_conditions": {},   // NOW REQUIRED
       "boundary_conditions": {}   // NOW REQUIRED
     }
   }
   ```

2. **Update Manning's n**:
   ```json
   # OLD
   "manning_n": 0.0  // No longer allowed

   # NEW
   "manning_n": 0.001  // Minimum value
   ```

3. **Migration Guide**:
   - See `RELEASE_NOTES_v1.3.0.md` Section 3.0
