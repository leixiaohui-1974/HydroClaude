快速开始
================================================================

桌面应用 (推荐):
  1. 下载安装程序
  2. 双击安装
  3. 启动应用
  4. 运行第一个仿真

Web开发:
  1. git clone https://github.com/hydroclaude/hydroclaude.git
  2. cd hydroclaude/webapp
  3. npm install
  4. npm run dev

插件开发:
  1. 阅读文档 docs/plugins/getting-started.md
  2. 创建插件 plugins/my-plugin/
  3. 测试插件
  4. 发布分享

后端API:
  1. cd backend
  2. pip install -r requirements.txt
  3. python run.py
  4. 访问 http://localhost:8000/docs
