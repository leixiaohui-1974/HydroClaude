## 🎯 Workflow 1: Complete Modeling & Simulation (START HERE)

**Time**: 30-40 minutes
**Document Section**: V1.5.0_TEST_EXECUTION.md → Workflow 1

### Quick Steps

1. **Navigate**: http://localhost:5173/ → Click "建模工作台"
2. **New Model**: Press `Ctrl+N`
3. **Add Nodes**:
   - Drag "入流节点" (Inflow) from left palette to canvas
   - Drag "河道节点" (Channel) from palette to canvas
4. **Connect**: Click first node → Drag to second node
5. **Configure**: Click nodes to set properties
6. **Validate**: Click "验证" button (should see success message)
7. **Save**: Click "保存" button
8. **Simulate**:
   - Click "仿真工作台" tab
   - Set parameters (time step, duration)
   - Click "运行仿真"
9. **Results**:
   - Wait for simulation to complete
   - View time-series chart
   - Press `Space` to play/pause animation
   - Drag timeline scrubber
10. **Export**:
    - Press `Ctrl+E` to open export modal
    - Select "CSV" format
    - Click "导出"
    - Open downloaded file to verify

### ✅ Success Criteria

- [ ] Model creation works without errors
- [ ] Validation succeeds
- [ ] Model saves to localStorage
- [ ] Simulation runs and completes
- [ ] Results display correctly
- [ ] Animation plays smoothly
- [ ] Export generates valid CSV file
- [ ] All keyboard shortcuts work

### ⚠️ Watch For

- Console errors (F12)
- UI freezing during simulation
- Missing data in export
- Keyboard shortcuts not responding

## 🎯 Workflow 4: Multi-Scenario Comparison (SECOND)

**Time**: 25-30 minutes
**Document Section**: V1.5.0_TEST_EXECUTION.md → Workflow 4

### Quick Steps

1. **First Scenario**:
   - Complete Workflow 1 first
   - In "单场景结果" tab, click "添加到对比" button
   - Verify message: "已添加到对比 (1个场景)"

2. **Second Scenario**:
   - Go back to "仿真配置"
   - Change parameters (e.g., different time step)
   - Click "运行仿真" again
   - Click "添加到对比" again
   - Verify message: "已添加到对比 (2个场景)"

3. **View Comparison**:
   - Click "多场景对比" tab
   - Badge should show "(2)"
   - See both scenarios listed with different colors

4. **Test Modes**:
   - Default mode: "叠加对比" (Overlay) - charts overlaid
   - Click "并排对比" (Side-by-Side) - charts side-by-side
   - Click "差异对比" (Diff) - shows differences

5. **Manage Scenarios**:
   - Toggle scenario visibility (eye icon)
   - Remove a scenario (trash icon)
   - Add more scenarios (repeat step 2)
   - Click "清空所有场景" to clear all

### ✅ Success Criteria

- [ ] Scenarios added successfully
- [ ] Tab badge updates correctly
- [ ] Different colors assigned to scenarios
- [ ] All 3 comparison modes work
- [ ] Timeline synchronized across charts
- [ ] Visibility toggle works
- [ ] Remove scenario works
- [ ] Clear all scenarios works

**Time**: 10-15 minutes
**Document Section**: V1.5.0_TEST_EXECUTION.md → Workflow 5

Test each shortcut:

- Focus text input → `Ctrl+Z` should only affect input

- [ ] All shortcuts work as expected
- [ ] Help modal shows all shortcuts

- [ ] Input fields don't trigger global shortcuts

## 🐛 Issue Reporting

### When You Find an Issue

1. **Take Screenshot** (important!)
2. **Check Browser Console** (F12) for errors
3. **Record in V1.5.0_TEST_EXECUTION.md**:
   - Which workflow
   - What step
   - Expected behavior
   - Actual behavior
   - Screenshot filename

### Issue Severity

- **Critical** 🔴: Blocks testing, crashes app, data loss
- **Major** 🟠: Feature doesn't work, workaround exists
- **Minor** 🟡: UI glitch, typo, minor UX issue

## 💡 Pro Tips

### Speed Up Testing
- Use keyboard shortcuts as much as possible
- Keep DevTools open to catch errors immediately
- Copy/paste common configurations

### If You Get Stuck
- Check browser console for errors
- Try refreshing the page
- Check if dev server is still running
- Ask Claude for help with specific step

### Quality Over Speed
- Don't rush through steps
- Actually verify each checkpoint
- Document issues clearly with screenshots
- Better to find issues now than after release
