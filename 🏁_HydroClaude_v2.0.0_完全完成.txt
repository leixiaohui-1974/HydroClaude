快速开始
================================================================

桌面应用:
  1. 下载: github.com/hydroclaude/hydroclaude/releases
  2. 安装: 双击安装程序
  3. 启动: 开始菜单 → HydroClaude
  4. 使用: 运行第一个仿真！

Web开发:
  git clone https://github.com/hydroclaude/hydroclaude.git
  cd hydroclaude/webapp
  npm install
  npm run dev

插件开发:
  查看: docs/plugins/getting-started.md
  示例: plugins/examples/

后端API:
  cd backend
  pip install -r requirements.txt
  python run.py
  访问: http://localhost:8000/docs
