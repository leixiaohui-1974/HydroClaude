## 🎯 Workflow 1: Complete Modeling and Simulation

**Objective**: Verify the complete workflow from creating a model to exporting simulation results.

**Duration**: 30-40 minutes

### Step-by-Step Instructions

#### Phase 1: Model Creation

1. **Open Application**
   - [ ] Navigate to http://localhost:5173/
   - [ ] Verify application loads without errors
   - [ ] Confirm "建模工作台" tab is active

2. **Create New Model** (Keyboard Shortcut Test)
   - [ ] Press `Ctrl+N` (or `Cmd+N` on Mac)
   - [ ] Verify confirmation dialog appears if model exists
   - [ ] Verify canvas is cleared
   - [ ] Verify Component Palette is visible on the left

3. **Add Nodes to Canvas**
   - [ ] Drag "边界节点 (Boundary)" from palette to canvas
   - [ ] Verify node appears at drop location
   - [ ] Drag "渠道节点 (Canal)" to canvas
   - [ ] Drag another "边界节点 (Boundary)" to canvas
   - [ ] Verify all 3 nodes are visible

4. **Connect Nodes**
   - [ ] Click on first boundary node's output port
   - [ ] Drag to canal node's input port
   - [ ] Verify edge/connection is created
   - [ ] Click on canal node's output port
   - [ ] Drag to second boundary node's input port
   - [ ] Verify second connection is created

5. **Configure Node Properties**
   - [ ] Click on first boundary node
   - [ ] Verify Property Panel opens on the right
   - [ ] Set boundary type to "flow" (流量)
   - [ ] Set value to 10.0 m³/s
   - [ ] Click on canal node
   - [ ] Set width: 5.0 m
   - [ ] Set length: 100.0 m
   - [ ] Set slope: 0.001
   - [ ] Set manning_n: 0.03
   - [ ] Set n_cells: 20
   - [ ] Click on second boundary node
   - [ ] Set boundary type to "depth" (水深)
   - [ ] Set value: 1.0 m

6. **Test Undo/Redo** (Keyboard Shortcut Test)
   - [ ] Press `Ctrl+Z` to undo last change
   - [ ] Verify change is undone
   - [ ] Press `Ctrl+Y` to redo
   - [ ] Verify change is restored

#### Phase 2: Model Validation

7. **Validate Model**
   - [ ] Click "验证 Validate" button in toolbar
   - [ ] Wait for validation to complete
   - [ ] Verify success message appears
   - [ ] Verify no error messages shown
   - [ ] Check all nodes have green checkmark indicators

#### Phase 3: Model Saving

8. **Save Model to localStorage**
   - [ ] Click "保存 Save" button in ModelIO toolbar
   - [ ] Enter model name: "E2E Test Model 1"
   - [ ] Add description: "End-to-end test model"
   - [ ] Click Save
   - [ ] Verify success message: "模型已保存"

#### Phase 4: Simulation Execution

9. **Switch to Simulation Workspace**
   - [ ] Click "仿真管理 Simulation" tab
   - [ ] Verify "仿真配置" card is visible on the left
   - [ ] Verify "仿真结果" card is visible on the right

10. **Configure Simulation**
    - [ ] In simulation config form, verify model is loaded
    - [ ] Set domain length: 100 m (should match model)
    - [ ] Set duration: 100 s
    - [ ] Set time step: 0.1 s
    - [ ] Set manning coefficient: 0.03
    - [ ] Set number of cells: 20

11. **Run Simulation**
    - [ ] Click "运行仿真 Run Simulation" button
    - [ ] Verify loading indicator appears
    - [ ] Wait for simulation to complete (15-30 seconds)
    - [ ] Verify success message appears

#### Phase 5: Results Visualization

12. **View Results**
    - [ ] Verify results appear in right panel
    - [ ] Check "仿真状态" shows "completed" ✅
    - [ ] Check "任务ID" is displayed
    - [ ] Check performance metrics are shown:
      - [ ] Peak water depth
      - [ ] Peak discharge
      - [ ] Final mean depth
      - [ ] Final mean discharge

13. **Test Animation** (Keyboard Shortcut Test)
    - [ ] Locate animation controller card
    - [ ] Press `Space` key
    - [ ] Verify animation starts playing
    - [ ] Press `Space` again
    - [ ] Verify animation pauses
    - [ ] Use slider to change time
    - [ ] Verify plots update accordingly

14. **Test Visualization Tabs**
    - [ ] Click "经典图表 Classic Charts" tab
    - [ ] Verify 2D plots are displayed
    - [ ] Click "3D可视化 3D Visualization" tab
    - [ ] Verify 3D surface plot renders
    - [ ] Click "高级图表 Enhanced Charts" tab
    - [ ] Verify contour plots are displayed

#### Phase 6: Results Export

15. **Export Results** (Keyboard Shortcut Test)
    - [ ] Press `Ctrl+E` (or `Cmd+E` on Mac)
    - [ ] Verify export modal opens
    - [ ] Select format: CSV
    - [ ] Select data type: "时间序列 Time Series"
    - [ ] Set precision: 4 decimal places
    - [ ] Click "导出 Export" button
    - [ ] Verify file downloads
    - [ ] Open CSV file and verify:
      - [ ] Headers are present
      - [ ] Data is formatted correctly
      - [ ] Time column matches simulation

16. **Export as Excel**
    - [ ] Open export modal again
    - [ ] Select format: Excel (.xlsx)
    - [ ] Click Export
    - [ ] Verify .xlsx file downloads
    - [ ] Open in Excel and verify:
      - [ ] Multiple sheets present (Data, Metadata, Statistics)
      - [ ] Data is readable
      - [ ] Charts are formatted

17. **Export as JSON**
    - [ ] Open export modal again
    - [ ] Select format: JSON
    - [ ] Click Export
    - [ ] Verify .json file downloads
    - [ ] Open in text editor and verify:
      - [ ] Valid JSON structure
      - [ ] Metadata included
      - [ ] Arrays are formatted correctly

### Acceptance Criteria

- ✅ All steps complete without errors
- ✅ Model validates successfully
- ✅ Simulation runs to completion
- ✅ Results visualize correctly
- ✅ All export formats work
