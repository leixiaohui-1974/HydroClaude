All assets use content-based hashing for cache busting:

**Pattern**: `[name]-[hash].[ext]`

**Examples**:
- `index-CcCsL23-.js` (hash: CcCsL23)
- `vendor-react-Do3Bo324.js` (hash: Do3Bo324)
- `SimulationWorkspace-B2YfuQ-g.js` (hash: B2YfuQ-g)

**Benefits**:
- ✅ Long-term caching (1 year+)
- ✅ Automatic cache invalidation on changes
- ✅ CDN-friendly
- ✅ No manual versioning needed

**Cache Strategy Recommendation**:
```
# Vendor chunks (rarely change)
/assets/vendor-*.js
  Cache-Control: public, max-age=31536000, immutable

# App chunks (change with updates)
/assets/*-*.js
  Cache-Control: public, max-age=86400

# HTML (always fresh)
/index.html
  Cache-Control: no-cache
```
