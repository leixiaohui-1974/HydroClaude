🔧 故障排除

【问题1】Python未安装
  症状: 'python' 不是内部或外部命令
  解决: 从 python.org 下载安装 Python 3.8+

【问题2】依赖未安装
  症状: ModuleNotFoundError
  解决: pip install -r requirements.txt

【问题3】Playwright未安装
  症状: Executable doesn't exist
  解决: playwright install chromium

【问题4】Web应用未运行
  症状: Connection refused
  解决: cd webapp && npm run dev

【问题5】中文乱码
  症状: 控制台显示乱码
  解决: run_full_test.bat已包含chcp 65001

【问题6】端口被占用
  症状: Port 5173 is already in use
  解决: 
    netstat -ano | findstr :5173
    taskkill /F /PID <PID>
